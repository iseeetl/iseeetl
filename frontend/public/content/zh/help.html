操作说明

选择要查看的标题即可打开说明。

1. 用户注册和登录

从登录画面的“前往用户注册”开始注册。

  1. 输入用户名、电子邮件地址和密码。
  2. 阅读并同意使用条款、隐私政策和 Cookie 政策，然后选择“OK”。
  3. 临时注册后，按照收到的电子邮件说明激活账户。
  4. 输入电子邮件地址和密码，然后选择“登录”。

也可以使用 Google 或 LINE 登录。通常会打开 floor 列表；带有 floor 和 room 的登录链接会打开指定的 room。

2. 创建、更新和删除帖子
  1. 在时间线上选择“发布”，或按 N 键。
  2. 输入评论，并根据需要添加反应、快捷文本、标签或媒体。
  3. 选择“发布”发送普通帖子，或选择“连续发布”让对话框保持打开。
  4. 要更新帖子，请选择编辑按钮，修改内容并发送。
  5. 要删除帖子，请选择删除按钮并确认。

评论最多400个字符。附加媒体需要登录。可用操作取决于 room 设置和权限。

3. 创建和删除滚动帖子
  1. 在时间线上选择“滚动”，或按 M 键。
  2. 输入评论并添加所需项目。
  3. 选择“滚动”添加帖子。
  4. 要删除帖子，请选择其删除按钮并确认。

在时间线设置中启用动画后，帖子会在屏幕上移动。

4. 创建、更新和删除回复
  1. 在目标帖子或回复上选择“回复”。
  2. 确认回复对象，输入评论并添加所需项目。
  3. 选择“回复”添加普通回复。
  4. 要更新回复，请选择编辑按钮，修改内容并发送。
  5. 要删除回复，请选择删除按钮并确认。

可用操作取决于 room 设置和权限。

5. 创建和删除滚动回复
  1. 在目标帖子或回复上选择“回复”。
  2. 在回复对话框中输入评论，然后选择“滚动”。
  3. 回复会被添加，并在启用动画时在屏幕上移动。
  4. 要删除回复，请选择删除按钮并确认。
6. 创建、更新和删除附加信息
  1. 在帖子或回复上选择“附加信息”。
  2. 输入评论，根据需要添加媒体，然后选择“确定”。
  3. 要更新，请选择编辑按钮，修改内容后选择“确定”。
  4. 要删除，请选择删除按钮并确认。

可用按钮取决于登录状态、时间线设置和权限。

7. 创建、更新和删除筛选条件
  1. 选择时间线顶部的“筛选帖子”。
  2. 设置关键词、用户、标签、无标签、滚动帖子和显示方式。
  3. 选择“确定”添加时间线列。
  4. 要更新，请选择“更改筛选条件”。
  5. 要删除，请选择“删除筛选条件”。

在智能手机上，请先选择相应的时间线标签页。

8. 时间线朗读功能
  1. 在要收听的列中选择“朗读关闭”。
  2. 首次使用时阅读提示并选择“开始”。
  3. 该列中的新帖子会被朗读。
  4. 选择“朗读开启”即可停止。

可在时间线设置中更改速度。是否可用以及声音效果取决于浏览器和设备。

9. 翻译功能

当 floor 设置了目标语言时，帖子、回复和附加信息会被翻译。

  1. 像往常一样发送内容。
  2. 翻译完成后，内容会更新并显示译文。
  3. 如果没有所需译文，则显示原文或其他可用译文。

处理可能需要时间，也可能因设置或环境而无法使用。

10. AI 分析

任意房间标签都可以配置为以下五种分析类型之一。无论 AI 分析是否可用，房间标签都可以正常选择。

  • 图像分析：说明所附静态图像的内容。
  • 音频场景分析：根据所附音频或带声音的视频说明情境或场景。
  • 转录：将所附音频或带声音的视频中的语音转换为文字。
  • 视频分析：说明所附视频的内容。
  • 对话分析：根据非空的帖子或回复正文作出回应，不需要媒体。
  1. 创建或更新帖子或回复时，选择已配置分析的房间标签。
  2. 除对话分析外，请附加相应的图像、视频或音频。
  3. 以注册用户身份通过普通时间线发送。分析将异步进行，结果稍后作为普通附加信息添加。

访客发送帖子或回复时不会运行 AI 分析。如果之后有编辑权限的注册用户修改了正文等用于分析的内容，则可能运行分析。分析结果稍后会作为附加信息添加。根据设置或附件内容，可能不会生成分析结果。

快捷键列表

按键 对象 操作
? 应用内各画面 显示帮助和快捷键列表。输入时、使用 IME 时、菜单打开时或对话框显示时不会运行。
N 时间线 打开普通帖子对话框。在访客只能添加反应的 room 中不可用。
M 时间线 打开滚动帖子对话框。
R 时间线 回复当前聚焦的帖子，或可回复的最新帖子。
Ctrl + Enter 帖子对话框 发送帖子。在 macOS 上也可以使用 Command + Enter。
Ctrl + Shift + Enter 帖子对话框 发送普通帖子并继续发布。在 macOS 上也可以使用 Command + Shift + Enter。
Esc 对话框 关闭对话框。
