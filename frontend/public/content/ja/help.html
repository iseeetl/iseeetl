操作説明

確認したいタイトルを選ぶと説明が開きます。

1. ユーザ登録、ログイン

ユーザ登録はログイン画面の「ユーザ登録へ」から行います。

  1. ユーザ名、メール、パスワードを入力します。
  2. 利用許諾、プライバシーポリシー及びCookieポリシーを確認して同意し、「OK」を押します。
  3. 仮登録完了後、届いたメールの案内に従ってアカウントを有効化します。
  4. ログイン画面でメールとパスワードを入力し、「ログイン」を押します。

GoogleまたはLINEのログインも利用できます。通常はログイン後にフロア一覧へ移動し、ルーム指定付きのログインURLから入った場合は対象ルームへ移動します。

2. 投稿の作成、更新、削除
  1. タイムラインの「投稿」ボタンを押します。キーボードでは N でも開けます。
  2. コメントを入力し、必要に応じてリアクション、単語、タグ、メディアを設定します。
  3. 「投稿」を押すと通常投稿として追加されます。「連続投稿」を押すと、送信後も投稿ダイアログを続けて利用できます。
  4. 投稿を更新する場合は、対象投稿の編集ボタンを押して内容を変更し、送信します。
  5. 投稿を削除する場合は、対象投稿の削除ボタンを押し、確認ダイアログで削除します。

コメントは400文字までです。メディアの添付にはログインが必要です。ボタンの表示や利用可否は、ルーム設定と操作権限によって異なります。

3. 「流す」投稿の作成、削除
  1. タイムラインの「流す」ボタンを押します。キーボードでは M でも開けます。
  2. コメントを入力し、必要に応じてリアクション、単語、タグ、メディアを設定します。
  3. 「流す」を押すと、「流す」投稿としてタイムラインに追加されます。
  4. 削除する場合は、対象の「流す」投稿の削除ボタンを押し、確認ダイアログで削除します。

「流す」投稿は、タイムライン設定でアニメーションが有効な場合に画面上を流れて表示されます。

4. 返信の作成、更新、削除
  1. 返信先の投稿または返信にある「返信」ボタンを押します。
  2. 返信先を確認し、コメントを入力します。必要に応じてリアクション、単語、タグ、メディアを設定します。
  3. 「返信」を押すと、通常返信として追加されます。
  4. 返信を更新する場合は、対象返信の編集ボタンを押して内容を変更し、送信します。
  5. 返信を削除する場合は、対象返信の削除ボタンを押し、確認ダイアログで削除します。

返信の作成・更新・削除ができる範囲は、ルーム設定と操作権限によって異なります。

5. 「流す」返信の作成、削除
  1. 返信先の投稿または返信にある「返信」ボタンを押します。
  2. 返信ダイアログでコメントなどを入力し、「流す」を押します。
  3. 「流す」返信として追加され、アニメーションが有効な場合は画面上を流れて表示されます。
  4. 削除する場合は、対象の「流す」返信の削除ボタンを押し、確認ダイアログで削除します。
6. 付加情報の作成、更新、削除
  1. 付加情報を追加したい投稿または返信の「付加情報」ボタンを押します。
  2. コメントを入力し、必要に応じてメディアを設定して「決定」を押します。
  3. 付加情報を更新する場合は、対象の付加情報にある編集ボタンを押し、内容を変更して「決定」を押します。
  4. 付加情報を削除する場合は、対象の付加情報にある削除ボタンを押し、確認ダイアログで削除します。

付加情報の操作ボタンが表示される範囲は、ログイン状態、タイムライン設定、操作権限によって異なります。

7. 絞り込みの作成、更新、削除
  1. タイムライン上部の「投稿の絞り込みを行う」を押します。
  2. キーワード、ユーザ名、タグ、タグ無し、「流す」などの条件と、表示方法を設定します。
  3. 「決定」を押すと、条件に合った内容を表示するタイムライン列が追加されます。
  4. 条件を更新する場合は、対象列の「絞り込み条件変更」を押して設定し直します。
  5. 絞り込みを削除する場合は、対象列の「絞り込み削除」を押します。

スマートフォンでは、対象のタイムラインタブを選んでから「絞り込み条件変更」または「絞り込み削除」を利用します。

8. タイムラインの読み上げ機能
  1. 読み上げたいタイムライン列の「読み上げオフ」ボタンを押します。
  2. 初回の確認ダイアログで説明を確認し、「開始」を押します。開始音声が再生され、その列の読み上げが有効になります。
  3. 読み上げが有効な列では、新しい投稿を受信すると内容を読み上げます。
  4. 停止する場合は、同じ列の「読み上げオン」ボタンを押します。

読み上げ速度は「タイムライン設定」で変更できます。音声の利用可否や声質はブラウザと端末に依存します。

9. 翻訳機能

投稿、返信、付加情報は、フロアで自動翻訳の対象言語が設定されている場合に翻訳されます。現在の利用言語に対応する翻訳があると、原文の下に翻訳文が表示されます。

  1. 通常どおり投稿、返信、または付加情報を送信します。
  2. 翻訳処理が完了すると、対象データが更新されて翻訳文が表示されます。
  3. 対応する翻訳がない場合は、原文または利用可能な翻訳が表示されます。

翻訳結果の表示には時間がかかることがあり、自動翻訳の設定や利用環境によっては翻訳されません。

10. AI解析

ルームでは、任意のルームタグに次の5種類から解析方法を設定できます。AI解析の利用可否にかかわらず、ルームタグは通常どおり選択できます。

  • 画像解析: 添付した静止画像の内容を説明します。
  • 音解析: 添付した音声または音声付き動画から状況や情景を説明します。
  • 文字起こし: 添付した音声または音声付き動画の発話を文字にします。
  • 動画解析: 添付した動画の内容を説明します。
  • 会話解析: 空でない投稿または返信の本文をもとに応答します。メディアは不要です。
  1. 投稿または返信の作成・更新時に、解析が設定されたルームタグを選択します。
  2. 会話解析以外では、解析方法に対応する画像、動画、または音声を添付します。
  3. 登録ユーザとして通常のタイムライン操作で送信します。解析は非同期で行われ、結果は後から通常の付加情報として追加されます。

ゲストが投稿・返信を送信した時点ではAI解析されません。後から編集権限のある登録ユーザが本文などの解析対象を変更すると、解析される場合があります。解析結果は後から付加情報として追加されます。設定や添付内容によっては、解析結果が作成されない場合があります。

ショートカット一覧

キー 対象 動作
? アプリ内の各画面 ヘルプ及びショートカット一覧を表示します。入力中、IME入力中、メニュー表示中、ダイアログ表示中は動作しません。
N タイムライン 通常投稿の作成ダイアログを開きます。ゲストがリアクションのみ許可されたルームでは動作しません。
M タイムライン 「流す」投稿の作成ダイアログを開きます。
R タイムライン フォーカス中の投稿、または最新の返信可能な投稿に返信します。
Ctrl + Enter 投稿作成・編集ダイアログ 投稿を送信します。macOSでは Command + Enter でも動作します。
Ctrl + Shift + Enter 投稿作成・編集ダイアログ 通常投稿で連続投稿します。macOSでは Command + Shift + Enter でも動作します。
Esc ダイアログ ダイアログを閉じます。
