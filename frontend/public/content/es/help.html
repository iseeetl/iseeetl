Instrucciones de uso

Selecciona el título que quieras consultar para abrir la explicación.

1. Registro e inicio de sesión

Inicia el registro desde «Ir al registro de usuario» en la pantalla de inicio de sesión.

  1. Introduce el nombre de usuario, el correo electrónico y la contraseña.
  2. Revisa y acepta las condiciones de uso, la Política de privacidad y la Política de cookies, y selecciona «OK».
  3. Tras el registro provisional, sigue las instrucciones del correo para activar la cuenta.
  4. Introduce el correo y la contraseña y selecciona «Iniciar sesión».

También puedes iniciar sesión con Google o LINE. Normalmente se abre la lista de floors; un enlace que especifique floor y room abre el room correspondiente.

2. Crear, actualizar y eliminar publicaciones
  1. Selecciona «Publicar» en la línea de tiempo o pulsa N.
  2. Escribe un comentario y añade reacciones, texto rápido, etiquetas o archivos multimedia si es necesario.
  3. Selecciona «Publicar» para enviar una publicación normal o «Publicación continua» para mantener abierto el diálogo.
  4. Para actualizar, selecciona editar, modifica el contenido y envíalo.
  5. Para eliminar, selecciona eliminar y confirma la operación.

Los comentarios admiten hasta 400 caracteres. Debes iniciar sesión para adjuntar archivos. Las acciones disponibles dependen de la configuración del room y de los permisos.

3. Crear y eliminar publicaciones flotantes
  1. Selecciona «Fluir» en la línea de tiempo o pulsa M.
  2. Escribe un comentario y añade reacciones, texto rápido, etiquetas o archivos si es necesario.
  3. Selecciona «Fluir» para añadir la publicación.
  4. Para eliminarla, selecciona su botón de eliminación y confirma.

La publicación se desplaza por la pantalla cuando la animación está activada en la configuración de la línea de tiempo.

4. Crear, actualizar y eliminar respuestas
  1. Selecciona «Responder» en la publicación o respuesta correspondiente.
  2. Comprueba el destino, escribe un comentario y añade los elementos necesarios.
  3. Selecciona «Responder» para añadir una respuesta normal.
  4. Para actualizar, selecciona editar, modifica el contenido y envíalo.
  5. Para eliminar, selecciona eliminar y confirma.

Las acciones disponibles dependen de la configuración del room y de los permisos.

5. Crear y eliminar respuestas flotantes
  1. Selecciona «Responder» en la publicación o respuesta correspondiente.
  2. Escribe un comentario en el diálogo y selecciona «Fluir».
  3. La respuesta se añade y se desplaza por la pantalla si la animación está activada.
  4. Para eliminarla, selecciona eliminar y confirma.
6. Crear, actualizar y eliminar información adicional
  1. Selecciona «Información adicional» en la publicación o respuesta.
  2. Escribe un comentario, añade archivos si es necesario y selecciona «Decidir».
  3. Para actualizar, selecciona editar, cambia el contenido y selecciona «Decidir».
  4. Para eliminar, selecciona eliminar y confirma.

Los botones disponibles dependen del inicio de sesión, de la configuración de la línea de tiempo y de los permisos.

7. Crear, actualizar y eliminar filtros
  1. Selecciona «Filtrar publicaciones» en la parte superior.
  2. Configura palabra clave, usuario, etiquetas, sin etiquetas, publicaciones flotantes y modo de visualización.
  3. Selecciona «Decidir» para añadir una columna.
  4. Para actualizar, selecciona «Cambiar condiciones del filtro».
  5. Para eliminar, selecciona «Eliminar filtro».

En un teléfono, selecciona primero la pestaña de la línea de tiempo correspondiente.

8. Lectura en voz alta de la línea de tiempo
  1. Selecciona «Lectura desactivada» en la columna que quieras escuchar.
  2. En el primer uso, revisa el aviso y selecciona «Iniciar».
  3. Las nuevas publicaciones de esa columna se leen en voz alta.
  4. Selecciona «Lectura activada» para detenerla.

La velocidad se cambia en la configuración. La disponibilidad y la voz dependen del navegador y del dispositivo.

9. Traducción

Las publicaciones, respuestas e información adicional se traducen cuando el floor tiene idiomas de destino configurados.

  1. Envía el contenido normalmente.
  2. Cuando termina la traducción, el contenido se actualiza y muestra el texto traducido.
  3. Si no existe la traducción solicitada, se muestra el original u otra traducción disponible.

El proceso puede tardar y no estar disponible según la configuración o el entorno.

10. Análisis con IA

Cualquier etiqueta de sala puede configurarse con uno de los cinco tipos de análisis siguientes. Las etiquetas de sala se pueden seleccionar tanto si el análisis con IA está disponible como si no.

  • Análisis de imágenes: describe una imagen fija adjunta.
  • Análisis de escenas de audio: describe una situación o escena a partir de un audio adjunto o de un vídeo con audio.
  • Transcripción: convierte en texto el habla de un audio adjunto o de un vídeo con audio.
  • Análisis de vídeo: describe el contenido de un vídeo adjunto.
  • Análisis de conversación: responde a partir del texto no vacío de una publicación o respuesta. No requiere archivos multimedia.
  1. Al crear o actualizar una publicación o respuesta, selecciona una etiqueta de sala que tenga un análisis configurado.
  2. Excepto para el análisis de conversación, adjunta la imagen, el vídeo o el audio correspondiente.
  3. Envía el contenido por la cronología normal como usuario registrado. El análisis se ejecuta de forma asíncrona y el resultado se añade después como información adicional normal.

El análisis con IA no se ejecuta cuando un invitado envía una publicación o respuesta. Puede ejecutarse después si un usuario registrado con permiso de edición cambia el texto u otro contenido utilizado para el análisis. Los resultados del análisis se añaden después como información adicional. Según la configuración o los archivos adjuntos, puede que no se cree ningún resultado.

Lista de atajos

Tecla Destino Acción
? Pantallas de la aplicación Muestra la ayuda y los atajos. No funciona durante la escritura, el uso de IME, con el menú abierto o con un diálogo abierto.
N Línea de tiempo Abre el diálogo de publicación normal. No funciona en rooms donde los invitados solo pueden reaccionar.
M Línea de tiempo Abre el diálogo de publicación flotante.
R Línea de tiempo Responde a la publicación enfocada o a la publicación más reciente que admite respuestas.
Ctrl + Enter Diálogo de publicación Envía la publicación. En macOS también funciona Command + Enter.
Ctrl + Shift + Enter Diálogo de publicación Envía una publicación normal y continúa publicando. En macOS también funciona Command + Shift + Enter.
Esc Diálogo Cierra el diálogo.
