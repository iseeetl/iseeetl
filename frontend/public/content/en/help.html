How to use the application

Select a tutorial topic to open its instructions.

1. User registration and login

Start registration by selecting "Go to user registration" on the login screen.

  1. Enter your user name, email address, and password.
  2. Review and accept the terms, Privacy Policy, and Cookie Policy, then select "OK."
  3. After provisional registration, follow the instructions in the email to activate your account.
  4. Enter your email address and password on the login screen, then select "Login."

You can also log in with Google or LINE. A normal login opens the floor list. When the login URL specifies a floor and room, the corresponding room opens after login.

2. Create, update, and delete posts
  1. Select "Post" on the timeline. You can also press N.
  2. Enter a comment and, if needed, add reactions, quick text, tags, or media.
  3. Select "Post" to add a normal post. Select "Continue posting" to keep the dialog open after sending.
  4. To update a post, select its edit button, change the content, and send it.
  5. To delete a post, select its delete button and confirm the deletion.

Comments can contain up to 400 characters. You must be logged in to attach media. Available actions depend on the room settings and your permissions.

3. Create and delete flowing posts
  1. Select "Flow" on the timeline. You can also press M.
  2. Enter a comment and, if needed, add reactions, quick text, tags, or media.
  3. Select "Flow" to add a flowing post to the timeline.
  4. To delete it, select the delete button on the flowing post and confirm the deletion.

A flowing post moves across the screen when flowing-post animation is enabled in the timeline settings.

4. Create, update, and delete replies
  1. Select "Reply" on the post or reply you want to respond to.
  2. Check the reply target, enter a comment, and add reactions, quick text, tags, or media as needed.
  3. Select "Reply" to add a normal reply.
  4. To update a reply, select its edit button, change the content, and send it.
  5. To delete a reply, select its delete button and confirm the deletion.

Available reply actions depend on the room settings and your permissions.

5. Create and delete flowing replies
  1. Select "Reply" on the post or reply you want to respond to.
  2. Enter a comment in the reply dialog, then select "Flow."
  3. The flowing reply is added and moves across the screen when animation is enabled.
  4. To delete it, select the delete button on the flowing reply and confirm the deletion.
6. Create, update, and delete supplements
  1. Select "Supplement" on the post or reply where you want to add information.
  2. Enter a comment, add media if needed, and select "Done."
  3. To update a supplement, select its edit button, change the content, and select "Done."
  4. To delete a supplement, select its delete button and confirm the deletion.

Supplement action buttons depend on your login state, timeline display settings, and permissions.

7. Create, update, and delete filters
  1. Select "Filter posts" at the top of the timeline.
  2. Set conditions such as keywords, user name, tags, no tags, or flowing posts, then choose how to display matches.
  3. Select "Done" to add a timeline column for the filter.
  4. To update the conditions, select "Change filter conditions" on that column.
  5. To delete the filter, select "Delete filter" on that column.

On a smartphone, select the timeline tab first, then use "Change filter conditions" or "Delete filter."

8. Timeline speech
  1. Select "Speech off" on the timeline column you want to hear.
  2. Review the first-use message and select "Start." A sample plays and speech is enabled for that column.
  3. When the enabled column receives a new post, its content is read aloud.
  4. To stop speech, select "Speech on" on the same column.

You can change the speech rate in "Timeline settings." Voice availability and quality depend on the browser and device.

9. Translation

Posts, replies, and supplements are translated when the floor has automatic translation target languages. When a translation for your current language is available, it appears below the original text.

  1. Send a post, reply, or supplement normally.
  2. After translation finishes, the item is updated and the translated text appears.
  3. If the requested translation is unavailable, the original text or another available translation is shown.

Translation may take time and may be unavailable depending on the floor configuration and service environment.

10. AI analysis

Any room tag can be configured with one of the following five analysis kinds. Room tags remain selectable whether or not AI analysis is available.

  • Image analysis: describes an attached still image.
  • Audio scene analysis: describes a situation or scene from attached audio or a video with audio.
  • Transcription: converts speech in attached audio or a video with audio to text.
  • Video analysis: describes the content of an attached video.
  • Conversation analysis: responds based on non-empty post or reply text. No media is required.
  1. When creating or updating a post or reply, select a room tag that has analysis configured.
  2. For every kind except conversation analysis, attach the matching image, video, or audio.
  3. Send it through the normal timeline as a registered user. Analysis runs asynchronously, and its result is added later as a regular supplement.

AI analysis does not run when a guest submits a post or reply. It may run later if a registered user with permission to edit changes the text or other content used for analysis. Analysis results are added later as supplements. Depending on the settings or attachments, an analysis result may not be created.
