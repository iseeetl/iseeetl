# 単語グループ削除の復旧

## 概要

単語グループの削除順序と、途中で失敗した場合の再試行方法を説明します。

## 動作・適用条件

### 削除と再試行

共通・フロア・ルーム単語は、認可とグループの存在・所属を確認し、対象グループの配下単語を削除してから、最後にグループを削除します。専用の削除記録やコレクションは作成しません。

両方の削除が完了した場合だけ成功を返します。DBエラーは失敗として返し、画面は一覧と配下単語を再取得します。グループが残っていれば、同じ削除操作を再試行できます。応答が失われても実際には削除済みの場合があるため、グループが一覧から消えた場合は再試行せず一覧へ戻ります。

配下単語の削除途中、またはグループ削除で失敗した場合、一部の単語が削除済みでグループが残ることがあります。操作前の状態への復元や、複数レコードの一括更新は保証しません。削除確認は配下単語も削除することを明示し、削除・再取得中は同じ画面からの操作を抑止します。

同時の作成・削除をDB全体で排他制御するものではありません。項目作成は保存後にも親の存在を確認し、親が消えていれば作成した項目を回収しますが、すべての競合やプロセス停止後の自動回収は保証しません。
