# 通知とアクティビティ

## 対象と届け方

| 対象 | 含む更新 |
| --- | --- |
| ルームのすべての投稿 | 参加していない会話も含む、このルームの更新 |
| 自分が関わった投稿 | 投稿・返信・説明・リアクションを付けた会話の更新 |
| ベルで選んだ会話 | ベルを付けた会話全体の更新 |

各対象で「上部にも知らせる」「プッシュでも受け取る」「アクティビティ履歴」をそれぞれ、`off`（オフ）／`matching`（絞り込みに従う）／`all`（絞り込みに関係なく）から選ぶ。「関係なく」はそのルーム・対象の範囲内。返信・代替テキスト・付加情報・リアクションの更新種類も個別に選べる。

通知する更新は履歴にも残す。履歴の範囲は上部・プッシュ以上とし、通知を広げたら履歴を広げ、履歴を狭めたら通知も狭める。APIもこの大小関係を検証する。設定をオフ・変更しても既存履歴は消さない。同じ出来事が複数対象に当てはまっても、利用者につき1件の履歴とする。上部の全体スイッチは履歴・プッシュから独立する。

返信は従来どおり最上位の親投稿に属し、返信のベルも同じ会話を購読する。返信先データの変更は行わない。新規投稿自体は従来のタイムラインで表示する。既存の条件付きプッシュは別の既存設定を維持し、送信した出来事は履歴にも残す。

## 絞り込みと保存

「絞り込みに従う」は選択中のタブと全体の条件を使う。バックグラウンドでは、このルームで最後に保存した条件を使う。条件なしタブを含む全タブのORにはしない。条件を変更したときだけ同期し、定期取得だけで他端末の条件を上書きしない。複数端末では最後の条件が使われる旨を設定画面に説明する。

AI・代替テキスト・付加情報の非表示設定は、バナー・プッシュと一覧の抜粋で尊重する。履歴自体は残り、本人が明示的に開いた対象は確認できる。既に保存した履歴は現在の絞り込みから外れても失わせない。

## 表示と移動

- バナーからアクティビティ一覧を開く。プッシュからはアクティビティ内の該当更新プレビューを開く。
- 一覧の投稿をタップすると、アクティビティを閉じて該当位置へスクロールする。📺の「更新内容を確認」も残し、そこから更新箇所・親投稿への移動を選べる。
- **現在のタブで対象を表示できれば、そのタブを維持する。** 未読込の古い対象も既存の履歴取得で補う。対象の返信・説明をその条件で表示できない場合だけ、条件なしの「タイムライン」へ移動する。他の読込済みフィルターパネルを優先しない。
- 表示順・保存済みの条件を変えず、選択箇所だけ明示的に展開する。フォーカス・強調・読み上げ用の位置説明を付け、動きを減らす設定では即時スクロールする。「通知一覧に戻る」で元の一覧位置へ戻れる。
- 更新箇所の最新内容が画面内に見えている場合は上部バナーを抑える。親投稿だけ見える場合や、説明が折りたたまれている場合は見た扱いにしない。画面に見えただけでは既読にしない。
- バナーを閉じても未読・履歴は残る。自動スクロールや新着による並べ替えはしない。閲覧権限が失われた本文・削除済み本文は返さない。
- 設定はネイティブselectと対象・届け方を含むラベルを使い、キーボード操作・選択状態を提供する。実機とスクリーンリーダーの確認は自動テストと区別して行う。

## 初期値と互換性

以前の設定を読み取り時にschemaVersion 3へ正規化する。既存5対象の個人通知2行は互換処理として保持し、3対象の設定を明示保存するまで配信範囲を変えない。表示・絞り込みの自動同期だけでは互換処理を解除しない。画面に「保存すると表示中の3対象に置き換わる」と明記する。

設定がない場合、ルーム全体は履歴・上部を「絞り込みに従う」、ベルは履歴・上部を「関係なく」、関わった投稿はオフ、更新4種類はオン、新設プッシュはオフ。従来の個人プッシュ条件は互換処理で維持する。新規に有効化・拡張したチャネルは保存時以後から適用し、停止期間の通知を一斉再送しない。

## 保存データへの変更

`ActivityPreference.value.schemaVersion=3`。`scopes` に3対象×`notify/timeline/push`の範囲を保存する。内部のboolean・チャネル開始日時は互換用に維持する。`preserveOwnNotifications` は旧個人通知の維持を表し、3対象の明示保存でfalseになる。`context.columns`へ保存するのは選択中の1列。既存Chatの返信データ構造は変更しない。

設定・履歴・既読・ベルはサーバー上の利用者×ルーム単位。版番号で競合を検出する。ゲストは署名IDを使い、プッシュは許可しない。ログイン時のゲスト履歴統合は行わない。過去の出来事は削除せず、`historyStart`以前の共通履歴と以後の個人履歴を区別する。履歴は現在本文への参照であり編集前本文の保管ではない。履歴は当面自動削除せず、保存量を見て見直す。

## 配信と検証

`ACTIVITY_NOTIFICATIONS_ENABLED=true` の環境だけ有効。Chat変更とoutboxを同じ更新に保存し、受信者ごとの履歴を保存してからプッシュする。配信直前も権限・最新設定・既読・削除を確認する。結果不明は同じUUIDで最大3回、60秒後に再試行。受信者×会話×更新種類で30秒間まとめ、24時間超の未配信は送らない。本文や氏名をプッシュ配信先へ含めない。日本語・英語・中国語、他言語は英語の追加文言。
