# リリース成果物仕様

## 概要

提供される配布アーカイブの構成、識別情報、配置条件を示します。
ソースリポジトリには、製品ソース、依存定義、ビルド処理、製品テストを収録します。
配布アーカイブの作成ツールは、ソースリポジトリに含めません。

## 構成・設定項目

### 成果物と識別情報

配布物は`.tar.gz`アーカイブとSHA-256チェックサムです。
`RELEASE_INFO.json`にはパッケージ名、バージョン、タグ、40桁コミットID、UTCの作成日時を記録します。
バックエンド／フロントエンドの`package.json`と`package-lock.json`は同じバージョンとし、
フロントエンドのビルドマニフェストにも対応するタグ・コミットIDを記録します。
同名の成果物は上書きしません。

ソースからフロントエンドをビルドする手順は[フロントエンドのビルド、設定](frontend/build-and-config.md)を参照してください。

### アーカイブ構成

フロントエンドは配布パッケージ直下の`dist/`に収録します。バックエンドのproduction起動では、この配置先を`DIST_PATH`に指定します。起動前に配信先と`index.html`の存在を検証します。

アーカイブの最上位ディレクトリは`<package名>_<version>/`です。

#### バックエンド

バックエンドのルートディレクトリには次を収録します。

- `app.js`
- `createApp.js`
- `ecosystem.config.js`
- `package.json`
- `package-lock.json`

バックエンドの実装ディレクトリは`bootstrap`、`config`、`constants`、`controllers`、`integrations`、`middlewares`、`models`、`routes`、`services`、`socket`、`utils`、`validates`を収録します。`node_modules`、テスト、開発設定、`scripts/`は収録しません。

アーカイブ内のバックエンドの`package.json`にはnpmスクリプトを収録しません。配置先で実行時依存を導入し、環境ファイルを指定して`app.js`を起動します。`ecosystem.config.js`は[運用事例](../deployment/production.md)で使用するPM2設定です。PM2を使用する場合は別途導入します。

#### フロントエンド

フロントエンドの本番用ビルドはアーカイブ直下の`dist/`へ収録します。必須アセットには`index.html`、各マニフェスト、ライセンス情報、ワーカー、ビルドマニフェストを含みます。

`dist/licenses.json`にはバンドルした依存ライブラリの名前・バージョン・ライセンス名・本文を収録します。生成コードの権利表示とともに保持します。バックエンドを含む依存の確認方法は[ライブラリのライセンス](../legal/libraries.md)を参照してください。

## 動作・適用条件

### 検証と除外

サーバ用ソフトの準備とアプリの起動は[サーバへの導入](../deployment/README.md)、アプリの設定項目は[バックエンド環境変数](backend/environment-variables.md)を参照してください。プロセス切替と切り戻しは、対象環境の配置先・データ変更に合わせて実施・検証します。

配布アーカイブの作成時には、次を検証します。ソースリポジトリの`test:build`はフロントエンドのビルドを検証し、配布アーカイブの検査は含みません。

- ルート直下のファイル・ディレクトリとファイル形式は、許可リストの範囲に限定する。
- `.env`で始まるファイル、秘密情報用ディレクトリ、テスト、導入済みの依存パッケージ（`node_modules`）、内部作業用ファイルを収録しない。
- `RELEASE_INFO.json`のパッケージ名、バージョン、タグ、コミットが指定内容と一致する。
- フロントエンドの必須アセット、リリースID、ライセンス情報が揃い、未置換のプレースホルダーがない。
- アーカイブ内の項目が一つの最上位ディレクトリに収まり、絶対パス、相対移動、リンク、特殊ファイルを含まない。
- チェックサムがアーカイブと一致する。

外部機能のバックエンド設定はアーカイブへ埋め込みません。フロントエンド公開設定へ許可される値とビルド時検証は[フロントエンドのビルド、設定](frontend/build-and-config.md)、バックエンド設定は[バックエンド環境変数](backend/environment-variables.md)を参照してください。
