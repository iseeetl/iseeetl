# ルーム単語の管理ダイアログ

## 概要

ルーム単語のグループと単語を作成、編集、削除、並び替えするダイアログです。ルーム一覧の対象ルームにある「ルーム単語」から開きます。
単語データのコピーとタイムラインでの利用は「データの初期コピーと利用」を参照してください。

## 利用条件・開き方

- 利用できるのは、管理者、対象フロアを作成した現在ロールが`Editor`のユーザ、対象フロアのフロアメンバーです。ログインが必要です。
- ルーム一覧の対象ルームにある「ルーム単語」を押すと、ルーム一覧のURLとスクロール位置を維持して開きます。
- ルーム作成者やルームメンバーという関係だけでは管理できません。キック済みのログインユーザは一覧APIの利用も拒否されます。
- 独立した画面ルートはありません。旧URL `/room/:roomId/quick-text`を開くと、未定義URLの処理でフロア一覧へ移動します。

ルームの一覧取得では共通APIクライアントが認証情報を付与します。API自体の閲覧権限はルームの公開・メンバー限定設定と所属に従います。ダイアログの管理権限とは区別し、詳細は[ルーム単語API](../../backend/api/room-quicktext.md)を参照してください。

## 画面構成

- PCでは幅960pxを上限とし、896px以下では画面内をほぼ満たすダイアログを表示する
- タイトルと「対象ルーム」を表示する。対象名はルーム一覧と同じ表示名を使い、作成・編集・削除確認でも維持する
- グループと単語の原文、表示順番、原文言語、設定済みの翻訳を表示する。原文を現在の表示言語の翻訳へ置き換えない
- 一覧、グループ作成・編集、単語作成・編集を同じダイアログ内で切り替える
- PCでは一覧上部に「単語グループ作成」、下部に「閉じる」を配置する。入力中は下部の「戻る」と「作成」または「保存」を使う
- スマートフォンでは同等の操作を上部のアイコンボタンから行う
- 削除確認と未保存の変更の破棄確認は、親ダイアログに重ねて表示する

## 操作と動作

### 初期表示・再取得

- 開いた時にグループ一覧を取得し、全グループの単語を並行して取得する。言語による絞り込みは指定しない
- 読み込み中、グループ0件の「単語がありません」、取得失敗と「再試行」を区別して表示する。グループ内に単語がない場合も「単語がありません」と表示する
- 一覧取得中も閉じられる。閉じた場合や対象IDが変わった場合は古い取得応答を破棄する
- グループ・単語の作成、編集、削除に成功するたび、グループ一覧と全グループの単語を再取得する

### グループ・単語の作成と編集

- グループはタイトル、単語は名称を入力する
- 作成時の表示順番はバックエンドが同じルームまたは同じグループ内の最大値に1を加えて採番する
- 保存成功後は同じダイアログの一覧へ戻り、再取得した内容と成功スナックバーを表示する
- 保存失敗時は入力を保持し、エラーのスナックバーを表示する
- 入力を変更した状態で「戻る」やEscキーを押すか、ダイアログの外側をクリックすると、変更を破棄するか確認する。「破棄」を押すと、保存せずダイアログ内の一覧へ戻る。変更がなければ確認せず一覧へ戻る
- 入力エラー時は入力欄へフォーカスする。保存後は対象行の編集ボタンへ、対象が見つからなければ一覧見出しへ移す
- 保存・削除・並び替えの送信中は、終了と重複操作を抑止する

### 削除

- 「対象ルーム」と削除対象を確認ダイアログに表示する。グループの場合は配下の単語も削除されることを示す
- グループと配下単語、または指定単語を物理削除する。画面からは復元できない
- バックエンドは認可・存在・所属を確認し、配下単語を削除してからグループを削除する。途中失敗時は一覧を再取得して残った対象から再試行する。専用の削除記録は保存しない。詳細は[単語グループ削除の復旧](../../backend/quicktext-deletion.md)を参照する
- 削除確認中も親一覧を保持する。取消時は削除を開始したボタンへフォーカスを戻す
- 削除成功後は次の行、前の行、一覧見出しの順にフォーカス先を選ぶ。単語の場合は同じグループ内の次の単語、前の単語、親グループの編集ボタンを使う
- 削除失敗時は確認を保持して再試行できる。グループ削除失敗後の再取得で対象が存在しなければ確認を閉じる

### 並び替え

- グループと各グループ内の単語をドラッグすると、現在の配列順で1から表示順番を付け直す
- 全グループ、または対象グループ内の全単語を個別のPATCHで並行更新する
- 成功時は再取得せず、画面内の並び順を維持して成功スナックバーを表示する。失敗時は画面の並び順を操作前へ戻してエラーを表示する
- 一部の更新だけが成功した場合、バックエンドの保存状態と画面の並び順が異なる場合がある
- 並び替えはドラッグ操作だけで、キーボードによる代替操作はない

### 閉じる

一覧で「閉じる」やEscキーを押すか、ダイアログの外側をクリックすると、ダイアログを閉じます。閉じた後は、開くときに押した「ルーム単語」ボタンへフォーカスを戻します。ルーム一覧のURLは変わりません。

入力中のEscキーや外側のクリックでは入力を終了し、ダイアログ内の一覧へ戻ります。未保存の変更があれば、先に変更の破棄を確認します。

### データの初期コピーと利用

- ルーム作成時、その時点のフロア単語の全グループと単語をルーム単語へコピーする
- コピー時はグループIDをルーム用IDへ付け替え、原文、原文言語、表示順番、既存の翻訳配列をそのままコピーする
- フロア単語の作成・編集・削除は作成済みルームへ伝播しない。対象言語変更による再翻訳は、原文や表示順を変更しない
- ルーム単語はコピー後に独立して作成・編集・削除でき、元のフロア単語と同期しない
- タイムライン初期化時にルーム単語を取得し、投稿・返信・投稿付加情報・返信付加情報の入力ダイアログへ渡す

## 入力条件

- グループのタイトル（`title`）: 必須、前後の空白除去後1〜200文字
- 単語の名称（`label`）: 必須、前後の空白除去後1〜200文字
- `order`は1〜100。現在の最大値に1を加えて採番するため、最大値が100の場合は新規作成できない
- ダイアログに原文言語の選択欄はない。作成時は現在の対応言語を原文言語として送る
- 編集時は保存済みの原文言語を使う。未設定または非対応の場合は表示言語、それも使えない場合は日本語を使う。詳細は[原文言語の扱い](../style-and-i18n.md#翻訳済みデータの表示)を参照する
- 作成・更新時の翻訳は[翻訳の生成と更新](../style-and-i18n.md#翻訳の生成と更新)に従う。Google Translateが有効な場合、`title`・`label`・`lang`のいずれかを更新要求に含めると、同じ値でも翻訳を再生成する
- フロアの対象言語変更に伴う再翻訳は[フロア管理](FloorManagement.md#翻訳と下位データへの影響)を参照する

## 通信・エラー時の動作

- 一覧取得の失敗時は再試行できる。APIエラーは処理別の文言と詳細をスナックバーへ表示する
- 一覧取得の失敗では現在の画面を維持する。`INVALID_PERMISSION`はトークンの失効と区別し、ゲストトークン更新や再送を行わない
- 変更APIの認証エラーの401では、エラー表示後にログアウトしてログイン画面へ移動する。403や通信失敗では現在の画面を維持する
- フロア・ルーム作成時の単語コピーは非トランザクションであり、途中失敗では一部だけ作成される場合がある。再試行による完全復旧は保証しない

### 使用するAPI

| 用途 | Method / Path | 成功後の画面処理 |
| --- | --- | --- |
| グループ一覧 | `GET /api/rooms/:roomId/quick-text/groups` | 全グループの単語を取得して一覧表示 |
| 単語一覧 | `GET /api/rooms/:roomId/quick-text/groups/:groupId/items` | グループごとの単語を一覧表示 |
| グループ作成 | `POST /api/rooms/:roomId/quick-text/groups` | 全一覧を再取得 |
| グループ更新 | `PATCH /api/rooms/:roomId/quick-text/groups/:id` | 保存時は全一覧を再取得。並び替え時は再取得しない |
| グループ削除 | `DELETE /api/rooms/:roomId/quick-text/groups/:id` | 全一覧を再取得 |
| 単語作成 | `POST /api/rooms/:roomId/quick-text/groups/:groupId/items` | 全一覧を再取得 |
| 単語更新 | `PATCH /api/rooms/:roomId/quick-text/items/:id` | 保存時は全一覧を再取得。並び替え時は再取得しない |
| 単語削除 | `DELETE /api/rooms/:roomId/quick-text/items/:id` | 全一覧を再取得 |

変更APIにはユーザJWTが必要です。認証・権限の詳細は[ルーム単語API](../../backend/api/room-quicktext.md)を参照してください。
