# メディア入力制約

## 概要

この文書では、フロントエンドで画像・動画・音声を選択または録音するときの形式、サイズ、再生時間制約を説明します。
バックエンドが受け付けるファイルの条件と保存処理は [ファイルアップロードAPI](../backend/api/upload.md) を参照してください。
フロア画像・ルーム画像のアップロードでは、対象IDを本文とクエリに指定します。タイムライン添付ではルームIDをURLに指定し、本文にはファイルだけを送ります。どちらもバックエンドがmultipart受信前に認可します。

対象はプロフィール・フロア・ルームの画像と、投稿・返信・付加情報に添付するメディア（録音を含む）です。作成・編集の両方に適用します。

## 動作・適用条件

### 基本原則

- フロントエンドの検証は、選択時に利用者へ案内するための制御であり、信頼境界ではない
- バックエンドでもMIME、拡張子、サイズ、保存先を検証する
- フロントエンドの共通値は `frontend/src/constants/mediaConstants.js` で管理する
- バイト上限は境界値を含めて許可し、上限を超えた場合に送信を拒否する

#### 投稿・返信・付加情報のメディア切り替え

- 添付画像・動画・音声は丸形の削除ボタンから解除する。画像・動画ではプレビュー右上、音声ではプレイヤー上部に表示する。解除は編集内容に反映し、保存操作で確定する。

- 画像から動画・音声へ切り替えると、画像名、サムネイル名、代替テキストをクリアし、保存時に画像用の項目を`null`で送信する。
- 録音で音声へ切り替える場合も、録音データを受け取った時点で以前のメディア情報をクリアする。録音データを生成せずに終了した場合や録音開始に失敗した場合は、現在のメディアを保持する。
- 画像を維持したまま本文などを編集する場合は、画像の代替テキストを保持する。
- ファイル未選択で選択画面を閉じた場合や、選択した動画・音声の形式が許可対象外の場合は、現在の画像と代替テキストを保持する。

### 画像

| 項目 | 制約 |
| --- | --- |
| MIME | `image/jpg`、`image/jpeg`、`image/png` |
| 最大サイズ | 3MB |
| 再生時間 | 対象外 |

- プロフィール、フロア、ルームでは共通の形式・サイズ判定関数を使用する
- タイムラインの投稿、返信、付加情報では、画像処理後のBlobサイズも上限内であることを確認する

#### 保存済み画像の差し替えと取消

- プロフィール、フロア、ルームでは、保存済み画像名、選択中のプレビューと送信用Blob、保存済み画像の明示削除を別の状態として扱う
- 新しい画像の選択成功時には保存済み画像名を変更せず、プレビュー中だけ保存済み画像を隠す。OSのファイル選択画面を画像未選択で閉じた場合は、現在の保存済み画像・プレビュー・Blob・入力欄を変更しない
- プレビューの取消はプレビュー、Blob、ブラウザ標準のファイル入力欄だけを消して保存済み画像へ戻す。保存済み画像がなければ画像なしへ戻す。保存済み画像の削除操作だけが、次回保存する画像名を`null`にする
- 選択取消・保存済み画像の削除後は画像選択操作へフォーカスを戻し、取消・保存成功・ダイアログ終了ではブラウザ標準のファイル入力欄を空にして同じファイルを再選択可能にする
- フロア／ルームではプレビューを高さ280px以内に収め、画像の下に文字付き操作ボタンを置く。保存済み画像がない場合は「添付を取り消す」、差し替え中は「差し替えを取り消す」、保存済み画像は「画像を削除」と表示し、アクセシブルな名前も揃える。プロフィールのプレビュー取消は「アイコンにする画像・キャンセル」を維持する
- アップロードの返却名はDB更新ペイロードの候補にだけ使用し、DB更新成功後に画面の保存済み画像名として確定する。アップロードまたはDB更新に失敗した場合は、保存済み画像名と選択中のプレビュー／Blobを維持する

### 動画

| 項目 | 制約 |
| --- | --- |
| MIME | `video/mp4`、`video/ogv`、`video/webm`、`video/quicktime`、`application/octet-stream` |
| 拡張子 | `.mp4`、`.ogv`、`.webm`、`.mov` |
| 最大サイズ | 150MB |
| 最大再生時間 | 30秒 |

- MIMEと拡張子の両方が許可対象であることを確認する
- 投稿、返信、付加情報の各編集ダイアログで、送信前にサイズと再生時間を検証する

### 音声

| 項目 | 制約 |
| --- | --- |
| MIME | `audio/x-m4a`、`audio/m4a`、`audio/mp4`、`audio/webm`、`audio/ogg`、`audio/mpeg`、`audio/mp3`、`audio/wav` |
| 最大サイズ | 6MB |
| 最大再生時間 | 30秒 |

- 投稿、返信、付加情報の各編集ダイアログで、送信前にMIME、サイズ、再生時間を検証する
- ブラウザ録音で生成したBlobも同じサイズ・再生時間制約を使用する
- アップロード後にバックエンドで必要な音声変換を行う

### 字幕

- 動画字幕の受信形式、拡張子、2MBの上限は [ファイルアップロードAPI](../backend/api/upload.md) を参照してください
- 新しい動画と字幕を同時に送信できる。
- 投稿、返信、付加情報の編集では、既存動画を維持したまま字幕だけを追加・置換できる。
- 字幕だけをアップロードした場合、既存の動画名とサムネイル名を維持し、返却された字幕名だけを更新APIへ設定する。
- 字幕アップロード成功後も選択した字幕の表示名を保持する。

### フロントエンドとバックエンドの分担

| 検証 | フロントエンド | バックエンド |
| --- | --- | --- |
| 画像のMIME・サイズ | 選択・送信前に確認 | 受信時に確認 |
| 動画のMIME・拡張子・サイズ | 選択・送信前に確認 | 受信時に確認 |
| 音声のMIME・サイズ | 選択・送信前に確認 | 受信時に確認 |
| 動画・音声の再生時間 | 送信前に確認 | 通常アップロードの受理時は確認しない。AI解析時は下記の別検査を行う |
| 保存先とリソース整合性 | 送信パラメータを構成 | 受信時に確認 |

### AI解析との境界

タイムラインへ保存したメディアが設定済みタグと一致する場合、バックエンドは保存成功後の非同期処理で実ファイルを再検査し、
外部サービスへ送る縮小画像、音声、動画フレームを専用一時領域に生成する。この処理はフロントエンドのアップロード前検証や
保存形式を変更せず、通常アップロードの許可形式すべてがAI解析対象になることも意味しない。詳細は
[AI解析設定・実行仕様](../ai-analysis.md#メディアの検証と変換)を参照する。
