# 仕様（spec/）

このディレクトリには、仕様（設計・要件・決定事項）をまとめています。
フロントエンド、バックエンド、および両者にまたがる横断仕様に分けて管理します。

## 目次

- [ドメインモデル](domain-model.md)
  - ユーザ、フロア、ルーム、投稿、メンバー、タグ、単語などの関係とライフサイクル
- [ロール・権限仕様](roles-and-permissions.md)
  - ユーザロール、有効ロール、メンバー権限、ルーム入室判定
- [非機能要件](non-functional-requirements.md)
  - セキュリティ、性能、可用性、監視、データ保護、アクセシビリティ、互換性の動作と運用環境での準備
- [Socket.IO接続・イベント契約](socket-events.md)
  - 接続認証、配信グループ、イベント送受信データ、配信対象、アクセス失効・再接続
- [AI解析設定・実行仕様](ai-analysis.md)
  - 3階層設定、解析起動、外部サービス送信、通常の付加情報への保存
- [リリース成果物仕様](release-artifact.md)
  - アーカイブ構成、識別情報、収録・除外・検証契約
- [フロントエンド仕様](frontend/README.md)
  - 画面、画面横断フロー、ルーティング、状態管理、APIクライアントなど
- [バックエンド仕様](backend/README.md)
  - API、認証、データ、環境変数、運用上の考慮事項など

個別仕様の索引は、各ディレクトリの README で管理します。

## 仕様書の読み方

各文書は概要から読み、利用条件、操作・処理、入力、エラー時の動作を確認できます。実装や主要なテストへの参照は末尾の「関連資料」にまとめています。テストの実行方法は[テスト手順](../testing/README.md)を参照してください。
