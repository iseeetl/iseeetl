# フロアメンバー（FloorMember）

## このページの対象者

フロア招待へ参加し、対象フロアのフロアメンバーになっている人が対象です。

## 適用される範囲

フロアメンバーの立場は、招待されたフロアと、その配下のルームにだけ適用されます。他のフロアには引き継がれません。

## できること

### フロア・ルームの閲覧・管理

- 対象フロアが非表示の場合のフロア一覧表示
- 対象フロア配下の非表示ルームの一覧表示
- ルームの作成、編集、削除
- ルームの一括表示・一括非表示
- ルームの並び替え
- フロア・ルームのタグと単語の管理
- 所属フロアの編集・画像変更・削除・単体の表示切替
- フロア・ルームのAI解析設定の管理

### メンバー機能

- フロアメンバーの招待・一覧の閲覧・登録解除
- フロアメンバーからの脱退
- メンバー限定ルームへの入室
- ルームメンバーの招待と一覧の閲覧
- 配下ルームのメンバー削除
- ユーザのキック・解除とキック済みユーザ一覧の閲覧

### タイムライン

- タイムラインの閲覧、投稿、返信、リアクション
- メディア機能

## 利用条件

- 所属フロアとその配下に限り、フロア編集者と同じ管理操作を行えます。他のフロアメンバーも登録解除できます。
- 管理者、対象フロアの編集者・メンバーはキックできません。
- ルームメンバー操作のボタンは、主にメンバー限定ルームで表示されます。
- フロアメンバーとルームメンバーの両方に該当する場合は、フロアメンバーとして扱われます。
- 対象フロアでキック済みの場合は、フロアメンバーであってもフロアと配下ルームを利用できません。

## できないこと

フロアメンバーとしては、次の権限は得られません。別途、管理者やフロア編集ユーザのロールを持つ場合は、その権限も利用できます。

- フロアの新規作成
- フロア一覧での一括表示・非表示

脱退・登録解除後は、メンバーとしての管理権限を失います。ユーザ全体のロールは変更されません。
