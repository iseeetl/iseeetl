# フロアメンバー（FloorMember）

## このページの対象者

フロア招待へ参加し、対象フロアのフロアメンバーになっている人が対象です。

## 適用される範囲

フロアメンバーの立場は、招待されたフロアと、その配下のルームにだけ適用されます。他のフロアには引き継がれません。

## できること

### フロア・ルームの閲覧・管理

- 対象フロアが非表示の場合のフロア一覧表示
- 対象フロア配下の非表示ルームの一覧表示
- ルームの作成、編集、削除
- ルームの一括表示・一括非表示
- ルームの並び替え
- ルームタグとルーム単語の管理

### メンバー機能

- フロアメンバー一覧の閲覧
- フロアメンバーからの脱退
- メンバー限定ルームへの入室
- ルームメンバーの招待と一覧の閲覧
- 自分が作成したルームでのルームメンバー削除

### タイムライン

- タイムラインの閲覧、投稿、返信、リアクション
- メディア機能

## 利用条件

- ルームメンバーの削除は、自分が作成したルームでのみ行えます。
- ルームメンバー操作のボタンは、主にメンバー限定ルームで表示されます。
- フロアメンバーとルームメンバーの両方に該当する場合は、フロアメンバーとして扱われます。
- 対象フロアでキック済みの場合は、フロアメンバーであってもフロアと配下ルームを利用できません。

## できないこと

- 対象フロア自体の編集・削除
- フロアタグとフロア単語の管理
- 共通・フロア・ルームのAI解析設定の管理
- フロアメンバーの招待と削除
- ユーザのキック・解除とキック済みユーザ一覧の閲覧
- 管理者専用の管理画面の利用
