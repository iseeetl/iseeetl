# 管理者（Administrator）

## このページの対象者

管理者権限でログインしている人が対象です。通常画面の管理操作に加えて、システム全体の管理画面を利用できます。

## 適用される範囲

管理者の権限はシステム全体に適用され、フロアやルームごとの立場より優先されます。

## 通常画面でできること

- 非表示フロアを含むフロア一覧の閲覧
- フロアの作成、編集、削除、表示・非表示操作
- 非表示ルームを含むルーム一覧の閲覧
- ルームの作成、編集、削除、表示・非表示、並び替え
- フロアタグ、ルームタグ、フロア単語、ルーム単語の管理
- フロア・ルームのAI解析設定と付加情報を行うユーザの管理
- フロアメンバーとルームメンバーの招待、一覧、削除
- ユーザのキック・解除、キック済みユーザ一覧の閲覧（管理者自身と対象フロアを作成したフロア編集ユーザはキック対象外）
- メンバー限定ルームへの入室
- 投稿、返信、リアクション、メディア機能

## 管理画面でできること

管理画面では、次の対象をシステム全体から管理できます。

- ユーザ情報、ロール、論理削除状態
- フロアとルームの情報、表示状態、入室条件、論理削除状態
- フロアメンバーとルームメンバーの関係
- 投稿
- 共通タグ、フロアタグ、ルームタグ
- スパム
- 共通の単語
- タイムラインデータ
- 共通AI解析設定と付加情報を行うユーザ。フロア／ルーム設定は通常のルーム画面から管理する

具体的な操作は[管理画面（管理者向け）](../management/README.md)を参照してください。

タイムラインJSONとメディアZIPには、利用者やゲストの識別情報、投稿、メディアなどが含まれる場合があります。出力ファイルは必要な範囲で取り扱い、不用意に共有しないでください。

復元できる範囲は対象によって異なります。削除前に[削除・復元方法の違い](../management/README.md#削除復元方法の違い)を確認してください。

## 条件によって操作できない場合

- 管理者の権限を他のロールへ変更したり、管理者を論理削除したりする操作は[ユーザ管理](../management/user-management.md)では行えません。
- フロアやルームが削除済みの場合、通常画面では利用できません。[フロア管理](../management/floor-management.md)・[ルーム管理](../management/room-management.md)で状態を確認してください。

通信失敗などの対処は[よくある質問・困ったとき](../troubleshooting.md)を参照してください。
