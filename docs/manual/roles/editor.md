# フロア編集ユーザ（Editor）

## このページの対象者

フロアを作成する権限を持つログインユーザが対象です。

## 適用される範囲

フロア編集ユーザというユーザロールはシステム全体で保持されます。ただし、フロア内の管理権限は、そのフロアとの関係によって変わります。

## できること

- フロアの作成
- 自分が作成したフロアの表示・非表示の一括変更
- 自分が作成した非表示フロアの一覧表示
- 自分が作成したフロアの編集と削除
- 一般ユーザが利用できるプロフィール、投稿、メディアなどの機能

## 自分が作成したフロアでできること

フロア編集ユーザが自分で作成したフロアでは、[対象フロアの作成者（FloorEditor）](floor-editor.md)として扱われます。

- 対象フロア配下のルーム管理
- フロアタグとフロア単語の管理
- フロア・ルームのAI解析設定と付加情報を行うユーザの管理
- フロアメンバーの招待、一覧、削除
- メンバー限定ルームの入室とルームメンバー管理
- 非表示ルームの一覧表示
- ユーザのキック・解除、キック済みユーザ一覧の閲覧

## 他のユーザが作成したフロアでの扱い

フロア編集ユーザであることだけでは、他のユーザが作成したフロアの管理権限は得られません。

- 追加の立場がなければ、一般ユーザとして扱われる
- フロア招待へ参加するとフロアメンバーになる
- ルーム招待へ参加するとルームメンバーになる

## できないこと

- 他のユーザが作成したフロアの編集・削除
- 追加の立場がないフロアでのルーム管理
- 管理画面の利用
