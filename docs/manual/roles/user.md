# 一般ユーザ（ログイン）

## このページの対象者

ログイン済みで、対象フロアやルームに追加の立場を持っていない人が対象です。投稿者（Author）に加え、フロア編集ユーザと開発者（developer）もこの条件に当てはまる場合は一般ユーザとして扱います。管理者は対象外です。

開発者による外部APIの利用は[v1 API利用ガイド](../api/v1.md)を参照してください。

## 適用される範囲

対象フロアの作成者、フロアメンバー、ルームメンバーのいずれでもないフロア・ルームで、一般ユーザとして扱われます。

## できること

- 表示されているフロアとルームの閲覧
- 公開ルームのタイムライン閲覧
- 投稿、返信、「流す」、リアクション
- 画像・動画・音声・字幕・録音などのメディア機能
- プロフィールの更新
- 認証方式に応じたパスワードの変更と再設定
- タイムラインのフォント・文字サイズとルーム内表示設定の変更
- 入室可能なルームでの投稿の絞り込み、音を鳴らすタグ、Webプッシュ通知の設定

## 対象ごとの立場が加わった場合

招待への参加やフロア作成によって、対象内で利用できる機能が増えます。

| 立場 | 主な追加機能 |
| --- | --- |
| [対象フロアの作成者](floor-editor.md) | 対象フロア配下のルーム、タグ、単語、メンバーの管理 |
| [フロアメンバー](floor-member.md) | 対象フロア配下のルーム管理とメンバー限定ルームへの入室 |
| [ルームメンバー](room-member.md) | 対象のメンバー限定ルームへの入室 |

## できないこと

追加の立場がない場合、次の操作はできません。

ただし、フロア編集ユーザは新しいフロアを作成できます。自分が作成したフロアでは、表示・非表示の一括変更や、ルーム・メンバーの管理もできます。

- メンバー限定ルームへの入室
- 非表示フロアと非表示ルームの一覧表示
- 投稿者によるフロア作成
- 追加の立場がない対象フロアの名称・説明の編集と削除、配下ルームの作成・編集・削除
- タグ、単語、メンバー、招待の管理
- 管理画面の利用
- 共通・フロア・ルームのAI解析設定の管理

## ルーム設定による変化

- 非表示ルームは一覧表示されません。
- メンバー限定ルームには、対象フロアを作成したフロア編集ユーザ、フロアメンバー、ルームメンバーのいずれかにならない限り入室できません。
- ログインユーザには「ゲストはリアクションのみ」の投稿制限は適用されません。
- 対象フロアでキック済みの場合は、ルームへ入室できません。

設定の組み合わせと入室条件は[ルームの表示・入室・ゲスト操作](../features/room-access-settings.md)を参照してください。
