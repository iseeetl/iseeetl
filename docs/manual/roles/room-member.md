# ルームメンバー（RoomMember）

## このページの対象者

ルーム招待へ参加し、対象ルームのルームメンバーになっている人が対象です。

## 適用される範囲

ルームメンバーの立場は、招待されたルームにだけ適用されます。同じフロア内の他のルームや、他のフロアには引き継がれません。

## できること

- 対象のメンバー限定ルームへの入室
- 対象ルームのタイムライン閲覧
- 投稿、返信、「流す」、リアクション
- 画像・動画・音声・字幕・録音などのメディア機能
- ルームメンバー一覧の閲覧
- ルームメンバーからの脱退

## 利用条件

- ルームメンバー一覧のボタンは、ルーム一覧にある自身が所属するメンバー限定ルームのカードに表示されます。
- 脱退ボタンは、対象のメンバー限定ルームへ入室した後のタイムラインに表示されます。
- 対象ルームが非表示の場合、ルームメンバーであることだけではルーム一覧に表示されません。
- フロアメンバーでもある場合は、フロアメンバーとして扱われ、利用できる管理機能が増えます。

## できないこと

- ルームの作成、編集、削除
- ルームの一括表示・一括非表示
- ルームの並び替え
- フロアタグ、ルームタグ、フロア単語、ルーム単語の管理
- 共通・フロア・ルームのAI解析設定の管理
- フロアメンバーとルームメンバーの招待・削除
- 非表示フロアと非表示ルームの一覧表示
- 管理者専用の管理画面の利用

## ルーム設定による変化

ルームメンバーはメンバー限定ルームへ入室できますが、非表示ルームは一覧表示されません。設定の組み合わせ、直接移動する導線、キック時の扱いは[ルームの表示・入室・ゲスト操作](../features/room-access-settings.md)を参照してください。
