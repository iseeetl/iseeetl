# ゲストユーザ（未ログイン）

## このページの対象者

ログインせずにアプリを利用している人が対象です。ゲストユーザには、ログインユーザのようなユーザロールやメンバー権限はありません。

## 適用される範囲

ゲストとして利用している間、すべてのフロアとルームで適用されます。閲覧や投稿ができる範囲は、フロア・ルームの表示状態とルーム設定によって変わります。

## できること

- 表示されているフロアの閲覧と検索
- 表示されているルームの閲覧
- 公開ルームのタイムライン閲覧
- テキストによる投稿と返信
- 「流す」とリアクションの付与・解除
- ゲストプロフィールのユーザ名と言語の設定
- タイムラインのフォント・文字サイズとルーム内表示設定の変更
- 投稿の絞り込みと音を鳴らすタグの設定
- ユーザ登録とログイン

## 条件によってできること

| 条件 | 利用できること |
| --- | --- |
| 「ゲストはリアクションのみ」が無効な公開ルーム | テキスト投稿、返信、「流す」、リアクションを利用できる |
| ゲストはリアクションのみのルーム | 「流す」とリアクションだけを利用できる |
| ゲスト利用ルールが表示された場合 | 内容へ同意すると対象操作を続行できる |

## できないこと

- メンバー限定ルームへの入室
- 非表示フロアと非表示ルームの一覧表示
- 画像・動画・音声・字幕・録音などのメディア機能
- ログインユーザ用プロフィールの更新
- フロアやルームの作成・編集・削除
- タグ、単語、メンバー、招待の管理
- 共通・フロア・ルームのAI解析設定の管理
- 管理画面の利用

## ルーム設定による変化

- 「非表示」は一覧表示を制御する設定です。ゲストユーザには非表示ルームが一覧表示されません。
- 「メンバー限定」は入室を制御する設定です。ゲストユーザは入室できません。
- 「ゲストはリアクションのみ」が有効な場合、投稿と返信はできません。

設定の組み合わせと入室条件は[ルームの表示・入室・ゲスト操作](../features/room-access-settings.md)を参照してください。
