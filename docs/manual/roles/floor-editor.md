# 対象フロアの作成者（FloorEditor）

## このページの対象者

現在のユーザロールがフロア編集ユーザ（Editor）であり、対象フロアを自分で作成した人が対象です。

## 適用される範囲

この立場は、自分が作成したフロアと、その配下のルームにだけ適用されます。他のユーザが作成したフロアには引き継がれません。

招待によって付与されるメンバー権限ではありません。

## できること

### フロア内の管理

- 対象フロアが非表示の場合のフロア一覧表示
- 対象フロア配下の非表示ルームの一覧表示
- ルームの作成、編集、削除
- ルームの一括表示・一括非表示
- ルームの並び替え
- フロアタグとフロア単語の管理
- ルームタグとルーム単語の管理
- フロア・ルームのAI解析設定と付加情報を行うユーザの管理

### メンバー管理

- フロアメンバーの招待、一覧、削除
- ユーザのキック・解除、キック済みユーザ一覧の閲覧
- ルームメンバーの招待、一覧、削除
- メンバー限定ルームへの入室

### タイムライン

- タイムラインの閲覧、投稿、返信、リアクション
- メディア機能

## 利用条件

- 作成後にユーザロールが変わると、この立場は適用されません。
- ルームメンバー操作のボタンは、主にメンバー限定ルームで表示されます。
- フロア自体の作成、編集、削除は、システム全体のフロア編集ユーザとして行います。

## できないこと

- 他のユーザが作成したフロアを、作成者の権限で管理すること
- 管理者専用の管理画面を利用すること
