# ロールと利用できる機能

このページでは、自分の立場から利用できる機能を確認できます。

実際にできることは、ユーザロールだけでは決まりません。ログイン状態、対象フロアでの立場、対象ルームでの立場、ルーム設定を順に確認してください。

## 利用できる機能が決まる順序

1. ログインしているか確認する
2. ユーザロールを確認する
3. 対象フロアを作成したフロア編集ユーザ、またはフロアメンバーか確認する
4. 対象ルームのルームメンバーか確認する
5. ルームの設定やキック状態を確認する

複数の立場に該当する場合は、原則として次の順で扱われます。

1. 管理者（Administrator）
2. 対象フロアの作成者（FloorEditor）
3. フロアメンバー（FloorMember）
4. ルームメンバー（RoomMember）
5. 一般ユーザ

ゲストユーザは、ログインユーザとは別に扱われます。

## システム全体のユーザ種別

| このマニュアルでの呼び方 | システム上の名前 | 適用範囲 | 概要 |
| --- | --- | --- | --- |
| [ゲストユーザ](guest.md) | ゲスト | 未ログイン時 | 公開ルームを閲覧し、ゲスト操作の設定に応じてテキスト投稿やリアクションを利用できる |
| [一般ユーザ](user.md) | Author、または対象内で追加の立場がないEditor・developer | システム全体 | ログインが必要な通常機能を利用できる |
| [フロア編集ユーザ](editor.md) | Editor | システム全体 | フロアを作成でき、自分が作成したフロアではルームやメンバーも管理できる |
| [管理者](admin.md) | Administrator | システム全体 | 通常画面の管理操作と管理画面を利用できる |

フロア編集ユーザ（Editor）であっても、他者が作成したフロアを作成者の権限で管理することはできません。

開発者（developer）も通常画面では対象内の立場に応じて扱われます。外部APIの利用は[v1 API利用ガイド](../api/v1.md)を参照してください。

## 対象ごとに決まる立場

| このマニュアルでの呼び方 | システム上の名前 | 適用範囲 | 付与・判定方法 |
| --- | --- | --- | --- |
| [対象フロアの作成者](floor-editor.md) | FloorEditor | 自分が作成したフロア | フロア編集ユーザが作成者であることから判定される |
| [フロアメンバー](floor-member.md) | FloorMember | 招待されたフロア | フロア招待への参加によって付与される |
| [ルームメンバー](room-member.md) | RoomMember | 招待されたルーム | ルーム招待への参加によって付与される |

作成者の立場は、現在のロールがフロア編集ユーザである場合に適用されます。招待によって付与されるものではありません。

通常画面では、ルームメンバーの招待と一覧をメンバー限定ルームのルーム一覧カードに表示し、ルームメンバー本人の脱退を対象ルームのタイムラインに表示します。詳しい手順は[フロアメンバー操作](../features/floor-members.md)、[ルームメンバー操作](../features/room-members.md)、[招待リンクからの参加](../features/invite.md)を参照してください。

投稿後の操作とタグ・単語の使い方は[投稿・流す・リアクション](../features/timeline-post.md)を参照してください。

管理者と対象フロアを作成したフロア編集ユーザはキック対象になりません。

## ルーム設定などによる制限

ルームの「非表示」「メンバー限定」「ゲストはリアクションのみ」は、それぞれ一覧表示、入室、ゲスト操作を制御する独立した設定です。

| 条件 | 一覧表示への影響 | 入室・操作への影響 |
| --- | --- | --- |
| 非表示ルーム | ゲストユーザ、追加の立場がないログインユーザ、ルームメンバーには表示されない | 非表示だけでは入室制限にならない |
| メンバー限定ルーム | 一覧に表示されていても入室判定が行われる | ゲストユーザと追加の立場がないログインユーザは入室できない |
| ゲストはリアクションのみ | 影響なし | ゲストユーザは投稿・返信ができず、「流す」とリアクションのみ利用できる |
| キック済み | 対象フロアのルーム一覧を利用できない | ログインユーザは対象フロア配下のルームへ入室・投稿できない |
| メディア機能 | 影響なし | ゲストユーザは画像・動画・音声・録音などを利用できない |

設定の組み合わせ、変更手順、ルームメンバーからの見え方は[ルームの表示・入室・ゲスト操作を設定する](../features/room-access-settings.md)を参照してください。キックの対象と影響は[ユーザをキック・解除する](../features/kicked-users.md)を参照してください。
