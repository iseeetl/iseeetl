# ゲストプロフィール設定

## 目的

- ゲスト利用時に表示するユーザ名と言語を設定する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| ゲストプロフィール設定 | タイムラインをゲスト利用している未ログインユーザ |

ログインユーザは[プロフィール更新](profile.md)を利用してください。

## 操作前の確認

- ログインしていないことを確認してください。
- 未ログインの状態でルームのタイムラインを開いてください。
- ゲストとしての利用状態が作成されると、ヘッダーに人物アイコンが表示されます。

## 手順

1. 画面右上の人物アイコンを押す
2. 「ゲストプロフィール設定」でユーザ名を入力する
3. 表示言語を選択する
4. 「保存」を押す

表示言語は選択した時点で切り替わります。ユーザ名は「保存」を押すと確定します。

メディア機能を利用する場合は、ダイアログ内の「ログインページへ」からログインできます。フロアとルームを開いていた場合は、ログイン後の復帰先として引き継がれます。

## 操作後の状態

- ゲスト名が投稿やリアクションの表示へ使用される
- 選択した言語へ画面表示が切り替わる

## 困ったとき

- 人物アイコンが表示されない
- ユーザ名が未入力、または20文字を超えている
- 「保存」を押さずにダイアログを閉じた

人物アイコンが表示されない場合は、未ログインの状態でタイムラインを開き直してください。
