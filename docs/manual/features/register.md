# ユーザ登録

## 目的

- メール、ユーザ名、パスワードを登録して、アカウント有効化用のメールを受け取る

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| ユーザ登録 | 未ログインユーザ |

GoogleまたはLINEでログインする場合は、[ログイン](login.md)を参照してください。

## 操作前の確認

メール機能が無効な環境では、ユーザ登録を利用できません。

- 受信できるメールアドレスを用意してください。
- 利用許諾・著作権・禁止事項・免責事項、プライバシーポリシー、Cookieポリシーを確認してください。
- 登録後はメール内のリンクからアカウントを有効化する必要があります。

## 手順

1. ログイン画面から「ユーザ登録へ」を押す
2. 「ユーザ名」「メール」「パスワード」を入力する
3. 利用許諾・著作権・禁止事項・免責事項を確認する
4. プライバシーポリシーを確認する
5. Cookieポリシーを確認する
6. 利用許諾、プライバシーポリシー、Cookieポリシーへの同意チェックを付ける
7. 「OK」を押す
8. 「ユーザ仮登録完了」が表示されたら「ログインページへ」を押す
9. 登録したメールアドレスで有効化メールを確認する

## 操作後の状態

- 仮登録の完了メッセージが表示される
- 「ログインページへ」を押すとログイン画面へ移動する
- 登録したメールアドレスへ有効化用の案内が届く

仮登録の状態ではログインできません。メール内のリンクから[ユーザ本登録](user-activate.md)を完了してください。

## 困ったとき

- ユーザ名が未入力、または20文字を超えている
- メールが未入力、形式不正、または100文字を超えている
- すでに利用されているメールを入力している
- パスワードが未入力、または8〜16文字ではない
- 利用条件への同意チェックが付いていない
- 通信失敗により登録が完了しない
- 有効化メールが届かない

メールが届かない場合は、迷惑メールフォルダと入力したメールアドレスを確認してください。
