# ルーム単語の管理

## 目的

- 対象ルームの単語グループと単語を作成、編集、削除、並び替えする
- 単語と設定されている翻訳を確認する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| ルーム一覧から管理ダイアログを開く | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者 |
| 作成・編集・削除・並び替え | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者 |

ルームメンバーであることだけでは管理できません。立場の違いは[ロールと利用できる機能](../roles/README.md)を参照してください。

## 操作前の確認

- ログインしてください。
- ルーム一覧から対象ルームの「ルーム単語」を押すと、現在の一覧を離れず管理ダイアログが開きます。
- 一覧、作成・編集、削除確認には同じ「対象ルーム」が表示されます。対象ルーム名を確認してから操作してください。

## 入力項目

- 単語グループのタイトル（必須、200文字まで）
- 単語の名称（必須、200文字まで）

## 手順

1. 一覧上部右の「単語グループ作成」を押す。スマートフォンでは右上の追加ボタンを押す
2. タイトルを入力して「作成」を押すと、同じダイアログの一覧へ戻る
3. 対象グループの「単語作成」を押す
4. 単語の名称を入力して「作成」を押す
5. 必要に応じてグループや単語を編集し、削除する場合は確認画面で対象ルームと削除対象を確認して「削除」を押す
6. 並び順を変更する場合は、グループまたは単語をドラッグする

入力を変更した状態で「戻る」やEscキーを押すか、ダイアログの外側をクリックすると、変更を破棄するか確認されます。「破棄」を押すと、保存せずダイアログ内の一覧へ戻ります。変更がない場合は確認せず一覧へ戻ります。入力に誤りがある場合は入力欄へフォーカスが移ります。

一覧で「閉じる」やEscキーを押すか、ダイアログの外側をクリックすると、ダイアログが閉じます。閉じた後は、開くときに押した「ルーム単語」ボタンへフォーカスが戻ります。

一覧を取得できない場合は「再試行」を押してください。

## 操作後の状態

- 単語グループと単語が一覧表示される
- 設定されている言語と翻訳が表示される
- 作成、編集、削除、並び替えが一覧へ反映される
- 未登録の場合は「単語がありません」と表示される

## 困ったとき

- 利用できる立場ではないため、ルーム一覧に「ルーム単語」が表示されない
- ログインしていないため、管理操作を利用できない
- ログインしていても、対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者のいずれでもない
- タイトルまたは名称が未入力、または200文字を超えている
- 通信失敗により操作結果が反映されない
- メンバー限定ルームへ入室できない立場、または対象フロアでキック済みのため一覧を取得できない

## 補足

- 単語グループを削除すると、そのグループ内の単語も削除されます。
- 削除した単語グループと単語は画面から元に戻せません。削除確認では対象ルームと、対象グループまたは対象単語をよく確認してください。
