# プロフィール更新

## 目的

- ユーザ名、アイコン、表示言語、目にやさしいモード、Webプッシュ通知を設定する
- パスワード変更画面へ移動する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| プロフィールの表示・更新 | ログインユーザ |

未ログインの場合は[ゲストプロフィール設定](guest-profile.md)を利用してください。

## 操作前の確認

Webプッシュ通知の項目は、この環境で通知機能が有効な場合に表示されます。

- ログインしてください。
- アイコンを変更する場合は、[メディアの形式と上限](timeline-post.md#メディアの形式と上限)に合う画像ファイルを用意してください。
- Webプッシュ通知を利用する場合は、ブラウザの通知を許可してください。

## 手順

1. メニューの「プロフィール」、または画面右上のプロフィール画像（画像未設定時は人物アイコン）を押してプロフィールダイアログを開く
2. 必要に応じてユーザ名を変更する
3. アイコンを変更する場合は「アイコンにする画像」の画像アイコンボタンを押して画像を選択する
4. アイコンを削除する場合は「アイコンを削除する」を押す
5. 表示言語を選択する
6. 目にやさしいモードを設定する
7. Webプッシュ通知と通知種別を設定する
8. 「保存」を押す

新しいアイコンのプレビューで「キャンセル」を選ぶと、保存済みアイコンを削除せず元の表示へ戻ります。保存済みアイコンを次回保存時に削除する場合だけ「アイコンを削除する」を押してください。

パスワードを変更する場合は「パスワード変更」を押してください。プロフィールダイアログが閉じ、パスワード変更画面へ移動します。

## 操作後の状態

- 「プロフィールを更新しました」と通知される
- ユーザ名とアイコンが更新される
- 選択した言語へ表示が切り替わる
- 目にやさしいモードと通知設定が反映される
- 更新が完了するとプロフィールダイアログが閉じる

## 困ったとき

- ユーザ名が未入力、または20文字を超えている
- 対応していない画像形式を選択している
- 画像のサイズが上限を超えている
- ブラウザの通知が拒否されている
- 通信失敗によりプロフィールを更新できない

プロフィール情報の読込に失敗した場合は、ダイアログを閉じずに「再試行」を押してください。

## 設定時の注意

- 言語を変更すると画面表示はすぐに切り替わりますが、「保存」せずにダイアログを閉じると元の言語へ戻ります。
- 未保存の変更がある状態で閉じると、変更を破棄するか確認されます。
- Webプッシュ通知の開始／停止は切り替え時に保存されます。この操作で、ダイアログ内の未保存のユーザ名、言語、アイコンなどが一緒に保存されることはありません。
- Webプッシュ通知は、プロフィールの設定だけでなくブラウザ側の通知許可も必要です。
- タイムラインの絞り込み条件ごとの通知は、[投稿を絞り込み・通知する](timeline-filters.md)を参照してください。
