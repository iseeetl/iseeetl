# Cookieポリシー

## 目的

- 本サービスが使用するCookieとブラウザ保存情報を確認する
- Google Analytics 4（GA4）を含む第三者サービスへの外部送信について、送信する情報、利用目的、保持期間を確認する

## 利用できる人

Cookieポリシーはすべての利用者が確認できます。ログインは不要です。

## Cookieポリシーを開く

次のいずれかから「Cookieポリシー」を開きます。

- アプリの共通メニュー
- ログイン画面
- ユーザ登録画面
- ゲスト利用ルール
- プライバシーポリシー
- `/cookie`を直接開く

ユーザ登録時の同意欄と、メール・パスワードまたはGoogle、LINEによるログインおよびゲスト操作時の同意案内は、利用規約、プライバシーポリシー、Cookieポリシーの3文書を対象とします。

## Cookieとブラウザ保存情報

Cookieポリシーでは、次の情報と、削除または拒否した場合に影響する機能を確認できます。

- ゲスト認証の更新、保護されたメディアの表示、LINEログインに必要なCookie
- ログイン状態、表示言語、表示中のフロア／ルーム、タイムライン設定などを保持するブラウザ保存情報
- 更新後の読み込み失敗から安全に復旧するための一時的なブラウザ保存情報
- Google Analytics 4による利用状況の集計に使用するCookie

機能に必要なCookieやブラウザ保存情報をブラウザの設定で削除または拒否すると、ゲスト認証、メディア表示、LINEログイン、ログイン状態、表示設定、読み込み失敗からの自動復旧などが利用できない、または初期状態へ戻る場合があります。

## GA4によるアクセス解析

本サービスでは、利用状況を把握し、サービス改善に役立てるため、Google Analytics 4（GA4）を利用する場合があります。

送信される情報には、利用者を区別するための識別子、閲覧したページや操作の種類、フロア・ルーム・タグ・単語入力の識別情報と名称、ブラウザや端末の種類、表示言語、大まかな地域に関する一般的な情報が含まれます。

画像・動画・音声のどの種類を添付したか、絞り込み機能を使用したか、対象範囲・組合せ方法などの固定された区分は、操作情報として送信される場合があります。絞り込みの作成・変更時には、選択したタグの識別情報と、取得済みの名称を送信する場合があります。

メールアドレス、ユーザ名、投稿・返信・付加情報の本文、画像・動画・音声そのものとファイル名、認証情報、検索語、絞り込み対象の利用者名は、本サービスが独自に送信する分析情報には含めません。

フロア・ルーム・タグ・単語入力の名称には、個人情報や秘密情報を入力しないでください。

Google Analyticsでイベント単位・利用者単位に保存されるデータの保持期間は14か月、GA4 Cookieの保存期間は最大2年です。Googleでの取り扱いと削除依頼の方法は、実際のCookieポリシー本文を確認してください。

## 第三者サービスへの送信

Cookieポリシーは、Google Analytics、Google Fonts、Google／LINEログイン、OneSignal、Google Cloud Translation、OpenAI、メール配信サービス、Xへの共有、iOSの共有機能について、送信する情報の区分、目的、送信される場面を一覧で説明します。

ログインや共有など、利用者が開始する機能は、その操作を選択した場合に認証情報や共有内容を送信します。Googleログインの選択肢を表示する画面、フォント表示、プッシュ通知などでは、機能の提供に伴う通信が発生する場合があります。

## ブラウザでの管理とお問い合わせ

Cookieとブラウザ保存情報は、ブラウザの設定から確認・削除できます。ただし、機能に必要な情報を削除または拒否すると、前述の機能へ影響します。

Webプッシュ通知は、プロフィールとブラウザの通知設定から停止できます。すでにGA4へ送信された登録ユーザのデータに関する質問や削除依頼は、アプリの「お問い合わせ」画面から連絡してください。Cookieの値や認証トークンは送信しないでください。
