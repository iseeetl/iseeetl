# フロアタグの管理

## 目的

- 対象フロアのタグを作成、更新、削除する
- フロアタグをCSVで入出力し、共通タグの状態へ戻す

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| フロアタグの一覧・作成・更新・削除 | 対象フロアを作成したフロア編集ユーザ、管理者 |
| CSVインポート・エクスポート | 対象フロアを作成したフロア編集ユーザ、管理者 |
| 共通タグへ戻す | 対象フロアを作成したフロア編集ユーザ、管理者 |

フロアメンバーはフロアタグを管理できません。立場の違いは[ロールと利用できる機能](../roles/README.md)を参照してください。

## 操作前の確認

削除は取り消せません。CSV同期や親タグへ戻す操作で除外されるタグも完全に削除されます。

- ログインした状態で、対象フロアのルーム一覧を開いてください。
- 「フロアタグ」は対象フロアを作成したフロア編集ユーザまたは管理者に表示されます。
- タグ名は現在の表示言語を基準として保存され、設定されている対象言語の翻訳も一覧に表示されます。
- CSVインポートと「共通タグに戻す」は、同期元にないタグを削除します。必要に応じて事前にCSVエクスポートしてください。

## 手順

### 一覧を確認する

1. 対象フロアのルーム一覧で「フロアタグ」を押す
2. 「対象フロア」が操作するフロア名と一致することを確認する
3. 「フロアタグ一覧」で件数、表示順番、タグ名、翻訳を確認する

取得中は読み込み表示、登録がない場合は0件表示になります。取得に失敗した場合はエラー表示の「再試行」から同じダイアログ内で再取得できます。

### タグを作成する

1. 「フロアタグ一覧」で「作成」を押す
2. 表示順番を1以上100以下の整数で入力する
3. タグ名を50文字以内で入力する
4. 「作成」を押す

表示順番を入力しなかった場合は100として作成されます。

### タグを更新・削除する

1. 対象タグの「編集」または「削除」を押す
2. 更新する場合は、同じダイアログ内で表示順番とタグ名を編集して「保存」を押す
3. 削除する場合は、確認画面の「対象フロア」と「対象タグ」を確認して「削除」を押す

作成・編集で入力を変更した後に「戻る」、Escキー、ダイアログの外側を選ぶと、変更を破棄するか確認されます。変更していない場合は、そのまま一覧へ戻ります。

### CSVをエクスポートする

1. 「CSVエクスポート」を押す
2. floortag.csvが保存されたことを確認する

### CSVをインポートする

1. ヘッダーなしで、各行を「表示順番,タグ名」としたCSVを用意する
2. 表示順番を1以上100以下、タグ名を1文字以上50文字以内にする
3. 行数を1行以上100行以下にする
4. 同じタグ名が複数行にないことを確認する
5. 「CSVインポート」でCSVファイルを選択する

ファイルを選択するとインポートが始まり、現在のフロアタグはCSVの内容と同期されます。

同名の有効な既存タグはIDを維持して更新され、CSVにない有効タグは完全に削除されます。CSVにだけある名前は新しいタグとして作成されます。

### 共通タグへ戻す

1. 必要に応じて現在のタグをCSVエクスポートする
2. 「共通タグに戻す」を押す
3. 削除されるタグがあることを確認して「共通タグに戻す」を押す

## 操作後の状態

- タグが表示順番に沿って一覧表示される
- 作成、更新、削除の結果が一覧へ反映される
- CSVエクスポートでは現在のフロアタグがファイルへ出力される
- CSVインポートでは現在のフロアタグがCSVの内容と同期される
- 「共通タグに戻す」では現在のフロアタグがシステムの共通タグと同期される

## 困ったとき

- 「フロアタグ」が表示されない
  - 対象フロアを作成したフロア編集ユーザまたは管理者であることを確認してください。
- タグを保存できない
  - 表示順番が1以上100以下の整数か、タグ名が1文字以上50文字以内かを確認してください。
- CSVをインポートできない
  - ヘッダーを入れず、各行が「表示順番,タグ名」の2列になっていることを確認してください。
  - 行数、表示順番、タグ名の文字数、重複するタグ名がないことを確認してください。
  - CSVに含めなかったフロアタグが有効なフロアAI解析設定で使用されている場合は同期できません。関連するAI解析設定を削除してから再実行してください。
- CSVをエクスポートできない
  - フロアタグが1件以上登録されていることを確認してください。
- 必要なタグが消えた
  - 同期元にないタグは完全に削除され、復元できません。同名のタグを新規作成できますが、元のIDには戻りません。
- タグを削除できない
  - 有効なフロアAI解析設定で使用中のフロアタグは削除できません。画面の案内に従い、関連するAI解析設定を削除してから再実行してください。

## 補足

- CSVのタグ名にカンマまたはダブルクォートを含める場合は、タグ名をダブルクォートで囲み、タグ名内のダブルクォートを2つ重ねてください。
- 同名判定は前後の空白を除去した完全一致で、大文字小文字を区別します。CSV内で未登録のタグ名へ変更すると、旧名のタグは完全に削除され、新しい名前のタグが作成されます。画面の「編集」による名前変更では、同じタグを更新します。
- 削除したタグは通常のフロアタグ一覧に表示されなくなります。
- フロアタグを削除しても、コピーして作成済みのルームタグは削除されません。
