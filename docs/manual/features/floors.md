# フロア一覧の閲覧・検索・管理

## 目的

- フロア一覧を閲覧・検索する
- 利用できる立場の場合は、フロアの作成、編集、削除、一覧での表示状態の変更を行う

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| 表示されているフロアの閲覧・検索 | すべての利用者 |
| 非表示フロアの一覧表示 | 対象フロアを作成したフロア編集ユーザ、対象のフロアメンバー、管理者 |
| フロア作成 | フロア編集ユーザ（Editor）、管理者 |
| フロアの表示・非表示の一括変更 | フロア編集ユーザ（自分が作成したフロアのみ）、管理者（全フロア） |
| フロアの編集・削除 | 対象フロアを作成したフロア編集ユーザ、管理者 |

フロア編集ユーザは、自分が作成したフロアではルームやメンバーも管理できます。他者が作成したフロアでの管理には、別途メンバーとしての立場が必要です。詳しくは[ロールと利用できる機能](../roles/README.md)を参照してください。

## フロアの非表示について

- 「非表示」は、フロア一覧に表示する利用者を制御する設定です。
- 非表示フロアは、対象フロアを作成したフロア編集ユーザ、対象のフロアメンバー、管理者には一覧表示されます。
- ゲストユーザ、追加の立場がないログインユーザ、ルームメンバーだけの利用者には一覧表示されません。
- 非表示にしても、フロアや配下ルームへの直接アクセスを禁止する設定にはなりません。

ルーム一覧への表示と入室を制御する場合は、[ルームの表示・入室・ゲスト操作を設定する](room-access-settings.md)も確認してください。

## フロアを閲覧・検索する

1. フロア一覧画面を開く
2. 表示されているフロアを確認する
3. 検索する場合は「フロア検索」に検索語を入力する
4. 「検索」を押す
5. 利用するフロアを選択する

検索語を空にして検索すると、検索条件が解除されます。

## フロアを作成する

1. 「フロア作成」を押す
2. 必須項目と必要な設定を入力する
3. 「作成」を押す

主な入力項目は次のとおりです。

- タイトル（必須、100文字まで）
- 説明（200文字まで）
- 自動翻訳の対象言語
- フロア画像（[形式と上限](timeline-post.md#メディアの形式と上限)を参照）
- 非表示にする

画像を選ぶとプレビューが表示されます。「添付を取り消す」は画像なしへ、「差し替えを取り消す」は保存済み画像へ戻します。保存済み画像を次回保存時に削除する場合は、「画像を削除」を押してください。

入力や画像を変更した後に「キャンセル」、Escキー、ダイアログの外側を選ぶと、変更を破棄するか確認されます。変更していない場合は、そのまま閉じます。

## フロアを編集・削除する

1. 対象のフロアカードを確認する
2. 内容を変更する場合は「編集」を押し、「対象フロア」が正しいことを確認して「保存」を押す
3. 削除する場合は「削除」を押し、確認画面の「対象フロア」と影響説明を確認して「削除」を押す

作成、編集、削除などのボタンは、操作できるフロアにだけ表示されます。

フロアを削除しても、配下のルーム、タグ、単語、AI解析設定は個別に削除されません。削除中は通常操作とAI解析に利用されず、フロアを復元すると個別に削除されていない設定を再び利用できます。

管理画面から操作する場合は[フロア管理](../management/floor-management.md)を参照してください。

## フロアの一覧表示を一括で切り替える

管理者は全フロア、フロア編集ユーザは自分が作成したフロアが対象です。削除済みのフロアは変更しません。

1. 「全フロア非表示」または「全フロア表示」を押す
2. 確認画面で変更内容を確認する
3. 「非表示にする」または「表示する」を押す

この操作はフロア一覧での表示状態を一括変更します。ルームの非表示や入室条件は変更しません。

## 操作後の状態

フロアを削除すると、配下のルームを開いている全利用者はタイムラインからフロア一覧へ戻ります。ログイン状態は維持されます。

- 利用者に表示可能なフロアが一覧表示される
- 検索条件に一致するフロアだけが表示される
- 利用できる立場では、必要な管理ボタンが表示される
- 非表示フロアを確認できる利用者には「非表示中」が表示される
- 作成、編集、削除、表示状態の変更結果が一覧へ反映される

## 困ったとき

- 検索語が100文字を超えている
- 検索語を空にして検索したため、検索条件が解除された
- 利用できる立場ではないため、作成・編集・削除ボタンが表示されない
- ルームメンバーであることだけでは、非表示フロアが一覧表示されない
- 非表示にしても直接URLからアクセスできる
  - 非表示は一覧掲載の設定です。ルームへの入室を制限する場合は「招待メンバーのみ」を設定してください。
- 通信失敗により操作結果が反映されない
