# ユーザ本登録

## 目的

- 仮登録後に届くメールのリンクからアカウントを有効化する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| アカウントの有効化 | ユーザ登録を行い、有効化メールを受け取った人 |

## 操作前の確認

- [ユーザ登録](register.md)を完了してください。
- 有効化メール内のリンクを用意してください。
- リンクには有効期限があるため、メールを受け取ったら早めに操作してください。

## 手順

1. 登録したメールアドレスで有効化メールを開く
2. メール本文の有効化リンクを開く
3. 「ユーザアクティベーション結果」を確認する
4. 成功した場合は「ログインページへ」を押す
5. ルームへのリンクが表示された場合は、ログイン後に対象ルームへ移動する

## 操作後の状態

- 有効化に成功したことが表示される
- メールとパスワードでログインできるようになる
- 登録時にルームが指定されていた場合は、対象ルームへのリンクが表示される

## 困ったとき

- リンクの有効期限が切れている
- リンクが途中で欠けている、または変更されている
- 同じメールアドレスのアカウントがすでに存在している
- 通信失敗により有効化できない

通信や処理の途中で失敗した場合は、有効期限内にメールの同じリンクを開き直してください。登録済みの処理がある場合は、残りの処理を再開します。リンクの期限切れなどで再開できない場合は、「トップページへ」から戻り、ユーザ登録をやり直してください。
