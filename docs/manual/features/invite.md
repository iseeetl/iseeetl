# 招待リンクからフロア・ルームへ参加する

## 目的

- 受け取った招待リンクからフロアメンバーまたはルームメンバーとして参加する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| 招待リンクから参加 | 招待リンクを受け取ったログインユーザ |

参加後にできることは[フロアメンバー](../roles/floor-member.md)と[ルームメンバー](../roles/room-member.md)を参照してください。

## 操作前の確認

- 有効な招待リンクを用意してください。
- 招待への参加にはログインが必要です。
- 未ログインで招待リンクを開いた場合は、ログイン後に同じ招待リンクをもう一度開いてください。
- フロア招待とルーム招待では、参加後に適用される範囲が異なります。

## 手順

1. 受け取った招待リンクを開く
2. 未ログインの場合はログインする
3. 必要に応じて同じ招待リンクをもう一度開く
4. 画面の案内に従って参加を完了する
5. 「フロアへ移動する」または「ルームへ移動する」を押す

## 操作後の状態

- フロア招待では「フロアメンバー参加完了」が表示される
- ルーム招待では「ルームメンバー参加完了」が表示される
- 完了画面から対象フロアまたはルームへ移動できる
- 参加後は対象でフロアメンバーまたはルームメンバーとして扱われる

## 困ったとき

- 招待リンクの期限が切れている
- 招待リンクが無効になっている
- 未ログインのまま参加しようとしている
- ログイン後に招待リンクを開き直していない
- すでに対象のフロアメンバーまたはルームメンバーになっている
- 対象フロアの作成者がフロア招待を開いている
- 対象フロアを作成したフロア編集ユーザまたはフロアメンバーが、参加する必要のない対象ルームの招待を開いている

同じ招待リンクでも、利用者ごとの参加状態によって結果が異なります。参加できない場合は、表示されたメッセージと自分の立場を確認してください。
