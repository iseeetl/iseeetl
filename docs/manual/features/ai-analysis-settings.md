# AI解析設定を管理する

AI解析設定は、投稿または返信に付けたルームタグと、解析する内容を関連付けます。解析結果は通常の付加情報としてタイムラインへ追加されます。AI解析が利用できない場合も設定の確認・編集はできますが、新しい解析結果は作成されません。

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| 共通設定 | 管理者 |
| フロア設定・ルーム設定 | 管理者、または対象フロアを作成したフロア編集ユーザ |

フロアメンバー、ルームメンバー、一般ユーザ、ゲストは設定を変更できません。

## 解析の種類

| 表示 | 利用する内容 |
| --- | --- |
| 画像解析 | 投稿・返信の静止画像 |
| 音解析 | 音声、または音声付き動画 |
| 文字起こし | 音声、または音声付き動画 |
| 動画解析 | 動画から取り出した代表的な画像 |
| 会話解析 | 投稿・返信の本文 |

同じタグへ複数の解析種別を設定できます。同じ範囲・同じタグ・同じ解析種別の有効な設定は1件だけです。

## 付加情報を行うユーザの初期選択

環境管理者が初期ユーザを設定している場合、共通・フロア・ルーム設定の新規作成時に「付加情報を行うユーザ」が選択済みになります。そのまま使うか、検索して別のユーザを選んでください。初期ユーザが未設定・利用できない場合は空欄です。既存設定を編集するときは、保存済みのユーザを表示します。

作成・編集画面では、選択中のユーザと検索候補の名前の前にプロフィール画像を表示します。画像が未設定、または読み込めない場合は人物アイコンを表示します。

初期ユーザの取得中は、取得が終わってから検索・選択と保存を行ってください。取得に失敗した場合も、手動で検索・選択できます。

## 共通設定を管理する

1. 管理者でログインし、メニューから「AI解析設定管理」を開く。
2. 「作成」を選ぶ。
3. 共通タグ、解析種別、追加指示を指定する。
4. 「付加情報を行うユーザ」の選択を確認する。空欄または変更する場合は、ユーザ名の一部を入力して「検索」を選び、検索結果からユーザを選ぶ。AIの解析結果は、選択したユーザの付加情報として表示される。
5. 「作成」を選ぶ。

「共通AI解析設定管理」の一覧ではタグ、解析種別、追加指示、付加情報を行うユーザを確認できます。検索欄では、タグ名・翻訳名、解析種別、付加情報を行うユーザ名を検索します。

共通設定を編集する場合は、入力欄の前に表示される「対象設定」で変更前のタグと解析種別を確認します。入力を変更してから「キャンセル」、Escキー、ダイアログの外側を選ぶと破棄確認が表示されます。入力を変更していない場合と開始時の内容へ戻した場合は、そのまま閉じます。

保存済み設定のタグまたは付加情報を行うユーザが存在しない場合、その項目は「参照先なし」と表示されます。参照先が論理削除済みの場合も、その行は利用不可として表示されます。いずれの行も編集できませんが、削除できます。管理画面には参照先を修復する操作がないため、データ管理担当者へ確認してください。

## フロア設定・ルーム設定を管理する

1. 対象フロアのルーム一覧を開く。
2. フロア設定はフロアタグの隣にある「フロアAI解析設定」、ルーム設定は対象ルームのルームタグの隣にある「ルームAI解析設定」を選ぶ。
3. フロア設定では「対象フロア」、ルーム設定では「対象ルーム」が意図した対象であることを確認する。
4. 一覧画面で「作成」を選ぶ。同じダイアログ内で作成画面へ切り替わる。
5. タグ、解析種別、追加指示を指定する。
6. 「付加情報を行うユーザ」の選択を確認する。空欄または変更する場合は、ユーザ名の一部を入力して「検索」を選び、検索結果からユーザを選ぶ。
7. 「作成」を選ぶ。保存後は一覧画面へ戻り、作成した設定を確認できる。

作成・編集を中止する場合は「戻る」を選びます。入力を変更している場合は破棄確認が表示され、変更がない場合はそのまま一覧へ戻ります。Escキーまたはダイアログの外側を選んだ場合も同じです。入力に誤りがある場合は、最初に修正が必要な項目へ移動します。

一覧を取得できない場合は「再試行」を選んでください。

検索前は「検索結果」や候補は表示されません。検索しても対象がない場合は「該当するユーザが見つかりません」と表示されます。編集時は現在選択中のユーザを検索前にも確認できます。

付加情報を行うユーザを検索している間は、検索の完了を待ってから設定を保存してください。中止する場合は「戻る」、Escキー、ダイアログの外側を選ぶ操作を利用できます。

コピー元のタグ・設定がなくても、フロア・ルーム設定を作成し、付加情報を行うユーザを指定できます。

フロア・ルームの作成時にコピーされた設定は、後から個別に変更できます。付加情報を行うユーザも変更できます。コピー元を変更・削除しても、コピー先は自動で変更・削除されません。

## 共通設定を編集・削除

- 有効な行の「編集」でタグ、解析種別、追加指示、付加情報を行うユーザを変更する。
- 対象行の「削除」を選び、確認ダイアログの解析種別とタグを確認して「削除」を選ぶ。設定は完全に削除され、復元できない。
- 削除してもコピー済みのフロア・ルーム設定や保存済みAI結果は変わらない。同じ設定が再び必要な場合は「作成」から登録する。

## フロア／ルーム設定を編集・削除

1. 有効な行の「編集」を選ぶ。
2. 「対象フロア」または「対象ルーム」を確認し、タグ、解析種別、追加指示、付加情報を行うユーザを変更する。
3. 「保存」を選ぶ。保存後は一覧へ戻る。

中止時の破棄確認は[フロア設定・ルーム設定を管理する](#フロア設定ルーム設定を管理する)と同じです。

- 有効な行の「削除」を選ぶ。確認ダイアログで「対象設定」に示された解析種別・タグと、フロア設定では「対象フロア」、ルーム設定では「対象ルーム」を確認して「削除」を選ぶ。設定は完全に削除され、復元できない。
- フロア／ルーム設定に復元操作はない。同じタグ・解析種別の設定が再び必要な場合は「作成」から新しい設定として登録する。
- 設定を削除しても、対応するタグ、投稿・返信、保存済みのAI結果は削除されない。フロア設定を削除しても、既にコピーされたルーム設定は削除されない。

削除をキャンセルすると元の一覧へ戻ります。削除に成功すると一覧が更新されます。

## 編集時の注意

- コピー先の設定が残っていても、コピー元の設定は削除できる。
- 共通タグ・フロアタグ・ルームタグは、同じ階層の有効なAI解析設定で直接使用中の間は削除できない。先に関連するAI解析設定を削除する。

別の利用者が先に変更していた場合は入力画面を閉じて最新一覧へ戻り、競合の案内を表示します。入力を自動的に再送しないため、最新の行を選び直して必要な変更をもう一度行ってください。

## 追加指示の入力

追加指示は、画面に表示される上限内で入力します。文字起こしは日本語で約74文字が目安ですが、入力する文字によって上限が変わります。長すぎると案内された場合は、内容を短くしてから保存してください。

## AI結果を確認・編集する

AI結果は投稿・返信の通常の付加情報として表示されます。AI専用の表示切替はありません。操作と権限は[投稿・付加情報の編集・削除](timeline-post.md#編集削除する)、リアクションは[追加手順](timeline-post.md#リアクションを追加する)を参照してください。

保存済みの文字起こし結果が400文字を超えている場合も、閲覧時にはそのまま表示されます。編集して保存する場合は、付加情報の入力上限に収まるよう400文字以下へ短縮してください。

## 解析が実行されない場合

- 投稿・返信に、設定と一致するルームタグおよび解析に必要な本文、画像、動画、音声があるか確認する。
- 設定が有効であるか確認する。
- AI解析は、登録ユーザが通常のタイムライン画面またはv1 APIで条件を満たす投稿・返信を作成または更新した場合に実行対象となる。
- AI解析が利用できない場合、投稿・返信を保存できてもAI結果は追加されない。

関連操作は[タイムラインで投稿・返信する](timeline-post.md)、[フロアタグの管理](floor-tags.md)、[ルームタグの管理](room-tags.md)も参照してください。
