# フロアメンバーを招待・確認・削除・脱退する

## 目的

- フロア招待URLを作成して、ログインユーザをフロアメンバーとして招待する
- 対象フロアのメンバーを確認し、利用できる立場に応じて削除または脱退する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| フロア招待URLの作成 | 対象フロアを作成したフロア編集ユーザ、管理者 |
| フロアメンバー一覧の確認 | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者 |
| 他のフロアメンバーの削除 | 対象フロアを作成したフロア編集ユーザ、管理者 |
| フロアメンバーからの脱退 | フロアメンバー本人 |

フロア編集ユーザであっても、他者が作成したフロアで作成者の操作はできません。立場の違いは[ロールと利用できる機能](../roles/README.md)を参照してください。

## 操作前の確認

- ログインした状態で、対象フロアのルーム一覧を開いてください。
- 利用できる立場に応じて「フロアメンバー招待」「フロアメンバー一覧」「フロアメンバー脱退」が表示されます。
- 招待URLの有効期限は「8時間」「3日」「1ヶ月」から選択できます。
- 招待URLから参加できるのはログインユーザです。

## 手順

### 招待URLを作成する

1. 対象フロアのルーム一覧で「フロアメンバー招待」を押す
2. 「対象フロア」と「できること・できないこと」を確認して有効期限を選択する
3. 「招待URLを作成」を押す
4. 表示されたURLを「コピー」でクリップボードへコピーする
5. 招待する人へURLを伝える

「作成済み招待URL」は長いURLも複数行で全文を表示します。「コピー」を押すと、折り返しを含まないURLをコピーできます。

URLを作成した後に有効期限を変更すると、表示中のURLはコピーできなくなります。新しい有効期限で「招待URLを作成」をもう一度押してください。

招待された人の参加手順は[招待リンクから参加する](invite.md)を参照してください。

### 一覧を確認する

1. 対象フロアのルーム一覧で「フロアメンバー一覧」を押す
2. 「対象フロア」と、画面に表示されるフロアメンバーの主な操作範囲を確認する
3. 件数、表示されたユーザ名とアイコンを確認する
4. 確認が終わったら「閉じる」を押す

取得に失敗した場合は、ダイアログ内の「再試行」を押せます。メンバーがいない場合は、空の一覧ではなくその旨が表示されます。

### メンバーを削除する

1. 「フロアメンバー一覧」を開く
2. 対象メンバーの「削除」を押す
3. 確認画面で「対象フロア」と対象のユーザ名を確認する
4. 「削除」を押す

### 自分が脱退する

1. 対象フロアのルーム一覧で「フロアメンバー脱退」を押す
2. 対象フロアを確認する
3. 「脱退」を押す

## 操作後の状態

参加操作を繰り返しても所属は重複せず、「参加済み」と表示されます。脱退後は有効な招待URLから再参加できます。

- 招待URLを作成すると、選択した有効期限とURLが表示される
- 「コピー」が成功すると、クリップボードへコピーしたことが通知される
- 一覧には対象フロアへ参加しているフロアメンバーが表示される
- 削除したユーザは対象フロアでフロアメンバーとして扱われなくなる
- 脱退するとフロア一覧へ移動し、対象フロアでフロアメンバーとして扱われなくなる

## 困ったとき

- 「フロアメンバー招待」または一覧の「削除」が表示されない
  - 対象フロアを作成したフロア編集ユーザまたは管理者だけが招待と削除を行えます。
- 「フロアメンバー一覧」が表示されない
  - 対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者のいずれかであることを確認してください。
- 招待URLから参加できない
  - URLの有効期限、ログイン状態、すでに参加済みでないかを確認してください。
  - 対象フロアを作成したフロア編集ユーザは、フロアメンバーとして参加する必要がありません。
- 削除または脱退後も一部のルームへ入室できる
  - 公開ルームや、ルームメンバーなど別の立場で入室できるルームは引き続き利用できます。
- URLをコピーできない
  - URLの発行後に有効期限を変更した場合は、変更後の条件で招待URLを再発行してください。
  - 有効期限を変更していない場合は、画面に表示されたURLを選択し、ブラウザのコピー操作を利用してください。

## 補足

- 招待URLは有効期限内であれば、参加条件を満たす複数のログインユーザが利用できます。意図した相手以外へ共有しないでください。
- 削除と脱退ではフロアメンバーとしての立場だけが解除されます。ユーザアカウントは削除されません。
