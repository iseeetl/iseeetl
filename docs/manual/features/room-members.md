# ルームメンバーを招待・確認・削除・脱退する

## 目的

- ルーム招待URLを作成して、ログインユーザをルームメンバーとして招待する
- 対象ルームのメンバーを確認し、利用できる立場に応じて削除または脱退する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| ルーム招待URLの作成 | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者 |
| ルームメンバー一覧の確認 | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、対象ルームのルームメンバー、管理者 |
| 他のルームメンバーの削除 | 管理者、対象フロアを作成したフロア編集ユーザ、または対象ルームを作成したフロアメンバー |
| ルームメンバーからの脱退 | ルームメンバー本人 |

対象ルームの作成者でないフロアメンバーは、ルームメンバーを削除できません。立場の違いは[ロールと利用できる機能](../roles/README.md)を参照してください。

ルームメンバーが入室できる条件と、非表示ルームの一覧表示については[ルームの表示・入室・ゲスト操作](room-access-settings.md)を参照してください。

## 操作前の確認

- 招待と一覧を利用する場合は、ログインした状態で対象フロアのルーム一覧を開いてください。
- 招待と一覧のボタンは「招待メンバーのみ」（メンバー限定）の対象ルームカードに表示されます。「ルーム単語」の右側を確認してください。
- ルームメンバー本人が脱退する場合は、対象ルームのタイムラインを開いてください。
- 招待URLの有効期限は「8時間」「3日」「1ヶ月」から選択できます。
- 招待URLから参加できるのはログインユーザです。

## 手順

### 招待URLを作成する

1. ルーム一覧の対象ルームカードで「ルームメンバー招待」を押す
2. 「対象ルーム」と「できること・できないこと」を確認する
3. 有効期限を選択する
4. 「招待URLを作成」を押す
5. 表示された招待URLの「コピー」を押す
6. 招待する人へURLを伝える

「作成済み招待URL」は長いURLも複数行で全文を表示します。「コピー」を押すと、折り返しを含まないURLをコピーできます。

URLの作成後に有効期限を変更すると、表示中のURLはコピーできなくなり、再作成が必要であることが案内されます。新しい有効期限で「招待URLを作成」をもう一度押してください。

招待された人の参加手順は[招待リンクから参加する](invite.md)を参照してください。

### 一覧を確認する

1. ルーム一覧の対象ルームカードで「ルームメンバー一覧」を押す
2. 「対象ルーム」が意図したルームであることを確認する
3. 画面に表示されるルームメンバーの主な操作範囲を確認する
4. 表示された件数、ユーザ名、アイコンを確認する
5. 確認が終わったら「閉じる」を押す

一覧を取得できない場合は「再試行」を押してください。メンバーが0人の場合は「ルームメンバーはいません」と表示されます。

### メンバーを削除する

1. 「ルームメンバー一覧」を開く
2. 対象メンバーの「削除」を押す
3. 確認画面で、「対象ルーム」と「対象メンバー」を確認する
4. 「削除」を押す

削除をキャンセルすると元の一覧へ戻ります。削除に成功すると一覧から対象のメンバーが外れます。

### 自分が脱退する

1. 対象ルームのタイムラインで、上部の「ルームメンバー脱退」を押す
2. 確認画面で「脱退」を押す

## 操作後の状態

参加操作を繰り返しても所属は重複せず、「参加済み」と表示されます。脱退後は有効な招待URLから再参加できます。

- 一覧には対象ルームへ参加しているルームメンバーが表示される
- 削除したユーザは対象ルームでルームメンバーとして扱われなくなる
- 脱退するとルーム一覧へ移動し、対象ルームでルームメンバーとして扱われなくなる

## 困ったとき

- メンバー操作ボタンが表示されない
  - 招待と一覧はタイムライン上部ではなく、ルーム一覧の対象カードに表示されます。
  - 対象ルームが「招待メンバーのみ」（メンバー限定）であることと、自分の立場を確認してください。
  - ルームメンバーには自身が所属する対象ルームの「ルームメンバー一覧」だけが表示され、招待は表示されません。
- ルームメンバーを削除できない
  - 管理者、対象フロアを作成したフロア編集ユーザ、または対象ルームを作成したフロアメンバーだけが削除できます。
  - フロアメンバーであっても、他のユーザが作成したルームでは削除できません。
- 招待URLから参加できない
  - URLの有効期限、ログイン状態、すでに参加済みでないかを確認してください。
  - 対象フロアを作成したフロア編集ユーザとフロアメンバーはルームメンバーとして参加する必要がありません。
- 削除または脱退後も対象ルームへ入室できる
  - 公開ルームや、フロアメンバーなど別の立場で入室できる場合は引き続き利用できます。
- URLをコピーできない
  - URL作成後に有効期限を変更している場合は、新しい有効期限でURLを再作成してください。
  - 画面に表示されたURLを選択し、ブラウザのコピー操作を利用してください。

## 補足

- 招待URLは有効期限内であれば、参加条件を満たす複数のログインユーザが利用できます。意図した相手以外へ共有しないでください。
- 削除と脱退ではルームメンバーとしての立場だけが解除されます。ユーザアカウントは削除されません。
