# 投稿を絞り込み・通知する

## 目的

- 条件に一致する投稿をカラムへ分けて表示する
- タグに応じた通知音や、絞り込み条件に応じたWebプッシュ通知を設定する
- 通常の絞り込みと共有URLによる一時的な絞り込みの違いを確認する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| 絞り込みカラムの追加・変更・削除 | 対象ルームへ入室できる利用者 |
| カラムの読み上げと表示順の変更 | 対象ルームへ入室できる利用者 |
| 音を鳴らすタグの設定 | 対象ルームへ入室できる利用者 |
| 絞り込み条件ごとのWebプッシュ通知 | 対象ルームへ入室できるログインユーザ |

## 操作前の確認

Webプッシュ通知の項目は、この環境で通知機能が有効な場合に表示されます。

- 対象ルームのタイムラインへ入室してください。
- 通常の絞り込みカラム、表示順、幅、読み上げ設定は、ルームごとに現在のブラウザへ保存されます。
- ログインユーザがWebプッシュ通知を有効にした場合は、絞り込み条件が通知条件としてアカウントへ登録されます。
- 音を鳴らすタグは、ログインユーザではアカウントのルーム別設定、ゲストユーザでは現在のブラウザへ保存されます。
- Webプッシュ通知を利用する場合は、[プロフィール更新](profile.md)で通知を有効にし、ブラウザの通知を許可してください。
- [タイムライン共有URL](timeline-query-parameters.md)で開いた条件は一時適用です。表示中に変更したカラムも保存されず、Webプッシュ通知は設定できません。

## 手順

### 絞り込みカラムを追加する

1. タイムラインで「投稿の絞り込みを行う」を押す
2. キーワード、ユーザ名、タグ、「タグ無し」、「流す」から必要な条件を指定する
3. 複数のキーワードやタグを指定した場合は、OR検索またはAND検索を選ぶ
4. 条件に一致した内容を表示するか非表示にするか選ぶ
5. 関連する投稿とユーザアイコンの表示方法を選ぶ
6. ログイン中に条件ごとの通知を受け取る場合は、「Webプッシュ通知を行う」を有効にする
7. 「決定」を押す

Webプッシュ通知は、キーワード、ユーザ名、タグなどの絞り込み条件がある場合に選択できます。

### カラムを変更・削除する

1. 対象カラムの「絞り込み条件変更」を押す
2. 条件を変更して「決定」を押す
3. カラムを削除する場合は「絞り込み削除」を押す
4. カラムを読み上げる場合は、対象カラムの「読み上げ」を有効にする
5. パソコン表示で順番を変更する場合は、カラムのドラッグ用ボタンをドラッグする
6. パソコン表示で幅を変更する場合は、カラム間の境界を動かす

スマートフォン表示では複数カラムがタブになります。対象のタブを選んでから、条件変更、削除、読み上げを操作してください。

### 音を鳴らすタグを設定する

1. タイムラインで「音を鳴らすタグを選択する」を押す
2. 通知音の対象にするルームタグを選ぶ
3. 必要に応じて「一括選択」または「一括解除」を押す
4. 「決定」を押す
5. 確認画面が表示された場合は「確認」を押す。通知音を実際に鳴らすこの操作によりブラウザでの再生を許可し、端末の音量を調整する

## 操作後の状態

- 指定した条件のカラムが追加され、条件に沿って投稿が表示または非表示になる
- 通常の絞り込みカラムと読み上げ設定が、同じブラウザで対象ルームを開いたときに復元される
- 選択したタグを含む投稿を受信すると通知音が鳴る
- Webプッシュ通知が有効なログインユーザには、登録した条件に一致する内容の通知が届く
- 共有URLによる条件は通常の保存済みカラムを変更しない

## 困ったとき

- キーワードが200文字、またはユーザ名が20文字を超えている
- スマートフォン表示で別のカラムがタブに隠れている
- 別の端末やブラウザを開いたため、通常の絞り込みカラムが表示されない
- ゲストユーザのため、Webプッシュ通知の項目が表示されない
- 絞り込み条件がない、または共有URLの条件を使用中のため、Webプッシュ通知を選択できない
- プロフィールのWebプッシュ通知、またはブラウザの通知許可が無効になっている
- ルームタグがないため、音を鳴らすタグを選択できない
- 端末やブラウザの音量設定により、通知音が聞こえない
- 「通知音を再生できませんでした」と表示された場合は、ブラウザの音声または自動再生の設定を確認し、音を鳴らすタグを設定し直して確認操作をもう一度行う
