# ユーザをキック・解除する

## 目的

- 対象ユーザによるフロアと配下ルームの利用を停止する
- キック済みユーザを確認し、必要に応じてキックを解除する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| ユーザキックボタンの表示設定 | 対象フロアを作成したフロア編集ユーザ、管理者 |
| 投稿・返信からのユーザキック | 対象フロアを作成したフロア編集ユーザ、管理者 |
| キック済みユーザ一覧の閲覧と解除 | 対象フロアを作成したフロア編集ユーザ、管理者 |

キックの対象はログインユーザです。ゲストユーザの投稿や返信には、ユーザキックボタンが表示されません。

次のユーザはキックできません。

- 管理者
- 対象フロアの作成者であるフロア編集ユーザ

## 操作前の確認

- 対象ユーザの投稿または返信があるルームへ入室してください。
- 「ユーザキックボタン」を表示する設定は、自分の画面にだけ反映されます。
- キックは、操作したルームだけでなく、そのルームが属するフロア全体に適用されます。
- キックしても、対象ユーザのフロアメンバーやルームメンバーの関係は削除されません。
- メンバー自体を削除する場合は、[フロアメンバー操作](floor-members.md)または[ルームメンバー操作](room-members.md)を参照してください。

## 手順

### キックする

1. 対象ルームのタイムラインを開く
2. 「タイムライン設定」を開く
3. 「ユーザキックボタン」を有効にして「決定」を押す
4. 対象ユーザの投稿または返信に表示された「ユーザをキックする」を押す
5. 確認画面の「対象フロア」と「対象ユーザ」が意図した対象であること、および説明を確認し、「ユーザをキックする」を押す

### キックを解除する

1. 対象フロアのルーム一覧を開く
2. 「キック済みユーザ一覧」を押す
3. 「対象フロア」と件数を確認し、解除するユーザの「解除」を押す
4. 確認画面で対象フロアと対象ユーザ名を確認し、「解除」を押す

一覧の取得に失敗した場合は「再試行」を押せます。キック済みユーザがいない場合は、その旨が表示されます。

## 操作後の状態

### キック後

- 対象ユーザが対象フロアのルームを表示中の場合は、キックされたことが通知され、ルームから退出します。
- 同じフロアを複数のタブやルームで開いている場合、それらの接続も切断されます。
- 対象ユーザは、対象フロアのルーム一覧と配下のルームへアクセスできません。
- 公開ルームやメンバー限定ルームの区別にかかわらず、入室と投稿ができません。
- フロアメンバーやルームメンバーであっても利用できませんが、メンバーの関係自体は残ります。
- 別のフロアの利用には影響しません。

### 解除後

- 対象ユーザは、ほかの入室条件を満たしていれば対象フロアと配下ルームを再び利用できます。
- キック中もメンバーの関係は保持されるため、解除時に再招待する必要はありません。
- 解除時に対象ユーザの画面は自動で切り替わりません。対象ユーザは解除後にフロアへ入り直してください。

## 困ったとき

- 対象フロアを作成したフロア編集ユーザまたは管理者ではないため、ユーザキックボタンやキック済みユーザ一覧が表示されない
- タイムライン設定で「ユーザキックボタン」を表示する設定を無効にしている
- ゲストユーザの投稿または返信を対象にしている
- 管理者または対象フロアの作成者をキックしようとしている
- 対象ユーザがすでに同じフロアでキック済みになっている
- キックを解除しても、メンバー限定や非表示など別の条件により対象ルームを利用できない
