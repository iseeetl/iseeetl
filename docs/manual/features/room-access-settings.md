# ルームの表示・入室・ゲスト操作を設定する

## 目的

- ルームの「非表示」「招待メンバーのみ」「ゲストはリアクションのみ」の違いを確認する
- ルームを一覧表示する人、入室できる人、ゲストユーザが利用できる操作を設定する
- 設定の組み合わせによる影響を確認する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| ルームカードに表示された状態の確認 | 対象ルームが一覧表示される利用者 |
| ルームの設定変更 | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者 |
| 全ルームの表示・非表示 | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者 |

ルームの設定を変更できる立場は、ルームを作成、編集できる立場と同じです。ルームメンバーはメンバー限定ルームへ入室できますが、ルーム設定は変更できません。

作成・編集ダイアログの「招待メンバーのみ」は、ルームカードで「メンバー限定」と表示される設定です。

## 3つの設定の違い

| 画面上の設定 | 一覧表示への影響 | 入室への影響 | 投稿・返信への影響 |
| --- | --- | --- | --- |
| 非表示にする | ゲストユーザ、追加の立場がないログインユーザ、ルームメンバーには表示しない | この設定だけでは制限しない | この設定だけでは制限しない |
| 招待メンバーのみ | 影響しない | ゲストユーザと追加の立場がないログインユーザは入室できない | 入室できたログインユーザが利用できる |
| ゲストはリアクションのみ | 影響しない | 影響しない | ゲストユーザは投稿・返信ができず、「流す」とリアクションだけを利用できる |

「非表示」と「招待メンバーのみ」は別の設定です。非表示にしただけでは、URLを知っている利用者の入室を禁止できません。入室をメンバーに限定する場合は「招待メンバーのみ」を有効にしてください。

ログインユーザには「ゲストはリアクションのみ」の投稿制限は適用されません。

## 設定の組み合わせ

| 非表示 | 招待メンバーのみ | 一覧と入室の状態 |
| --- | --- | --- |
| 無効 | 無効 | 一覧に表示され、ゲストユーザとログインユーザが入室できる |
| 有効 | 無効 | 一覧に表示される人は制限されるが、直接URLを知っている利用者の入室は制限されない |
| 無効 | 有効 | 一覧に表示されても、所定の立場を持つログインユーザだけが入室できる |
| 有効 | 有効 | 一覧表示と入室の両方が制限される |

メンバー限定ルームへ入室できるのは、対象フロアを作成したフロア編集ユーザ、フロアメンバー、ルームメンバー、管理者です。

## 非表示ルームを一覧表示できる人

非表示ルームをルーム一覧で確認できるのは、次の利用者です。

- 対象フロアを作成したフロア編集ユーザ
- フロアメンバー
- 管理者

ルームメンバーであることだけでは、非表示ルームは一覧表示されません。招待への参加が完了した画面など、対象ルームへ直接移動できる導線を利用してください。

## ルームごとの設定を変更する

1. フロア一覧から対象フロアを開く
2. 対象ルームの「編集」を押す
3. 「非表示にする」「招待メンバーのみ」「ゲストはリアクションのみ」を必要に応じて変更する
4. 「保存」を押す
5. ルームカードに表示された状態を確認する

ルーム作成時も、作成ダイアログで同じ設定を指定できます。

## 全ルームの一覧表示を切り替える

1. 対象フロアのルーム一覧を開く
2. 「全ルーム非表示」または「全ルーム表示」を押す
3. 確認画面で変更内容を確認する
4. 「非表示にする」または「表示する」を押す

この操作が変更するのは、対象フロアの削除されていない全ルームの「非表示」だけです。「招待メンバーのみ」と「ゲストはリアクションのみ」は変更されません。

## メンバー招待・キックとの関係

- ルーム招待へ参加したログインユーザはルームメンバーになり、対象のメンバー限定ルームへ入室できます。
- 対象フロアを作成したフロア編集ユーザとフロアメンバーは、ルームメンバーにならなくても対象フロアのメンバー限定ルームへ入室できます。
- 対象フロアでキック済みのログインユーザは、フロアメンバーやルームメンバーであっても配下ルームへ入室できません。
- キックを解除しても、メンバー限定など別の条件はそのまま適用されます。

## 操作後の状態

メンバー限定へ変更すると、接続中のゲストと入室権限のない利用者はルーム一覧へ戻ります。権限のある利用者は接続を継続します。非表示設定だけの変更では退出しません。

- ルームカードに設定した状態が表示される
- 非表示ルームは、一覧表示できる立場にだけ表示される
- メンバー限定ルームでは、入室時に利用者の立場が確認される
- 「ゲストはリアクションのみ」のルームでは、ゲストユーザの投稿と返信が制限される

## 困ったとき

- 非表示なのに直接URLから入室できる
  - 入室も制限するには「招待メンバーのみ」を有効にしてください。
- 一覧にあるメンバー限定ルームへ入室できない
  - フロア・ルームでの立場を確認し、必要な招待を受けてください。
- ルームメンバーになっても非表示ルームが一覧にない
  - ルームへの直接URLや、招待参加完了画面から移動してください。
- 全ルームの表示・非表示を変えても入室・ゲスト操作の条件が変わらない
  - 条件を変える場合は、各ルームの「招待メンバーのみ」「ゲストはリアクションのみ」を編集してください。
- 対象フロアでキック済みになっている
