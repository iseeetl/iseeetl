# タイムラインのフォント・文字サイズ設定

## 目的

- メニューの「設定」から、タイムラインで使用するフォントと文字サイズを設定する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| フォント・文字サイズ設定 | すべての利用者 |

ログインは不要です。

## 操作前の確認

- この設定はアカウントではなく、現在のブラウザへ保存されます。
- 別の端末やブラウザには設定が引き継がれません。
- 読み上げ速度、表示項目、「流す」のアニメーションなどは、タイムライン画面の「タイムライン設定」で変更します。

## 手順

1. メニューから「設定」を開く
2. 「タイムライン フォント」を選択する
3. 「タイムライン フォントサイズ」を選択する
4. 「決定」を押す

## 操作後の状態

- 設定が現在のブラウザへ保存される
- フロア一覧へ移動する
- 以後に開くタイムラインへフォントと文字サイズが反映される

## 困ったとき

- 「決定」を押さずに画面を離れた
- 別の端末やブラウザで同じ設定が表示されない
- ブラウザのローカル保存が制限されている
- ブラウザのデータを削除したため設定が初期化された
