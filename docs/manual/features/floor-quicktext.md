# フロア単語の管理

## 目的

- 対象フロアの単語グループと単語を作成、編集、削除、並び替えする
- 単語と設定されている翻訳を確認する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| フロア単語ダイアログの利用・管理 | 対象フロアを作成したフロア編集ユーザ、管理者 |

フロアメンバーはフロア単語を管理できません。立場の違いは[ロールと利用できる機能](../roles/README.md)を参照してください。

## 操作前の確認

- ログインしてください。
- ルーム一覧から対象フロアの「フロア単語」を押すと、現在の一覧を離れず管理ダイアログが開きます。

## 入力項目

- 単語グループのタイトル（必須、200文字まで）
- 単語の名称（必須、200文字まで）

## 手順

1. ダイアログの「対象フロア」が操作するフロア名と一致することを確認する
2. 「単語グループ作成」を押す。スマートフォンでは右上の追加ボタンを押す
3. タイトルを入力して「作成」を押すと、同じダイアログの一覧へ戻る
4. 対象グループの「単語作成」を押す
5. 単語の名称を入力して「作成」を押す
6. 必要に応じてグループや単語を編集し、削除する場合は確認画面で確定する
7. 並び順を変更する場合は、グループまたは単語をドラッグする

入力を変更した状態で「戻る」やEscキーを押すか、ダイアログの外側をクリックすると、変更を破棄するか確認されます。「破棄」を押すと、保存せずダイアログ内の一覧へ戻ります。変更がない場合は確認せず一覧へ戻ります。

一覧で「閉じる」やEscキーを押すか、ダイアログの外側をクリックすると、ダイアログが閉じます。閉じた後は、開くときに押した「フロア単語」ボタンへフォーカスが戻ります。

一覧を取得できない場合は「再試行」を押してください。

## 操作後の状態

- 単語グループと単語が一覧表示される
- 設定されている言語と翻訳が表示される
- 作成、編集、削除、並び替えが一覧へ反映される
- 未登録の場合は「単語がありません」と表示される

## 困ったとき

- 利用できる立場ではないため、ルーム一覧に「フロア単語」が表示されない
- ログインしていない
- タイトルまたは名称が未入力、または200文字を超えている
- 通信失敗により操作結果が反映されない

## 補足

- 単語グループを削除すると、そのグループ内の単語も削除されます。
- 削除した単語グループと単語は画面から元に戻せません。削除確認では対象をよく確認してください。
