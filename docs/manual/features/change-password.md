# パスワード変更

## 目的

- ログイン中のユーザが、現在のパスワードを新しいパスワードへ変更する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| 現在のパスワードを使った変更 | パスワードを設定済みのログインユーザ |

現在のパスワードが分からない場合は[パスワード再設定](password-reset.md)を利用してください。

## 操作前の確認

- ログインしてください。
- 現在のパスワードを確認してください。
- GoogleまたはLINEだけでログインしており現在のパスワードがない場合は、登録メールを使った再設定を確認してください。

## 手順

1. プロフィールダイアログを開く
2. 「パスワード変更」を押す
3. 「現在のパスワード」を入力する
4. 「新しいパスワード」と「新しいパスワード確認」を入力する
5. 「設定」を押す

現在のパスワードが分からない場合は、「現在のパスワードが分からない場合にはこちら」から再設定リンク送信画面へ移動できます。

変更を取りやめる場合は、画面上部の「プロフィールへ戻る」を押します。最初にプロフィールを開いた画面へ戻り、プロフィールを表示します。再設定リンク送信画面を開いた場合は、戻るボタンでパスワード変更画面へ戻れます。

## 操作後の状態

- 「パスワードを変更しました」と通知される
- ログアウトしてログイン画面へ移動する
- 操作中の端末を含め、すべての端末で新しいパスワードによる再ログインが必要になる
- 別タブで開いているタイムラインの接続も切断される

通知メールが届かない場合でも、変更完了後は新しいパスワードを使ってログインしてください。通知メールの送信失敗によってパスワード変更が取り消されることはありません。

## 困ったとき

- 現在のパスワードが未入力、または登録内容と一致しない
- 新しいパスワードが未入力、または8〜16文字ではない
- 新しいパスワード確認が一致しない
- GoogleまたはLINEだけで利用しており、現在のパスワードを設定していない
- 通信失敗により変更できない
