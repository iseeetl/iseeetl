# 投稿・流す・リアクション

## 目的

- タイムラインへ投稿または「流す」を送信する
- 投稿へ返信、付加情報、リアクションを追加する
- 投稿後に内容やタグを編集し、不要なデータを削除する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| 公開ルームでのテキスト投稿・返信 | ログインユーザ、および「ゲストはリアクションのみ」が無効な場合のゲストユーザ |
| メンバー限定ルームでの投稿・返信 | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、ルームメンバー、管理者 |
| 「ゲストはリアクションのみ」のルームでの「流す」・リアクション | ゲストユーザ |
| 画像・動画・音声・字幕・録音などのメディア機能 | 入室できるログインユーザ |

立場ごとの利用条件は[ロールと利用できる機能](../roles/README.md)、ルーム設定による違いは[ルームの表示・入室・ゲスト操作](room-access-settings.md)を参照してください。

対象フロアを作成したフロア編集ユーザと管理者は、ログインユーザの投稿または返信からユーザキックを実行できます。表示条件と影響は[ユーザをキック・解除する](kicked-users.md)を参照してください。

## 操作前の確認

- 対象ルームのタイムラインへ入室してください。
- ゲストユーザは、操作開始時に[ゲスト利用ルール](guest-rules.md)への同意を求められる場合があります。
- 「ゲストはリアクションのみ」のルームでは、ゲストユーザに「投稿」が表示されません。

## 手順

### 投稿する

1. タイムラインで「投稿」を押す
2. コメントを入力し、必要に応じてタグやリアクションを選択する
3. ログイン中は、必要に応じて「録音開始」やメディア添付を利用する。添付ファイルの[形式と上限](#メディアの形式と上限)を確認する
4. 「投稿」を押す

### 流す

1. タイムラインで「流す」を押す
2. コメントを入力するか、表示されたリアクションを選択する
3. 「流す」を押す

「流す」にはメディアを添付できません。「ゲストはリアクションのみ」のルームをゲストで利用する場合は、用意されたリアクションから選択します。任意のコメント入力や、タグ・単語の選択はできません。

### 返信する

1. 対象投稿の「返信」を押し、内容を入力する
2. ログイン中に返信をルーム内の全員へ知らせる場合は、「全員へ通知する」を選ぶ
3. 「返信」を押す

「全員へ通知する」を選んだ返信は、画面内通知が有効なルームへ接続中の他ユーザに通知カードとして表示されます。同じ返信を通知付きで編集した場合も、編集操作ごとに新しいカードが表示されます。Webプッシュ通知ではなく、不在中の通知はあとから再表示されません。

### リアクションを追加する

対象の投稿・返信・付加情報の「リアクション」を押し、リアクションを選択します。

### 付加情報を追加する

ログインユーザは、対象の投稿・返信の「情報付加」を押し、内容を入力して「決定」を押します。付加情報にもメディアを添付できます。

### 編集・削除する

1. 対象の投稿・返信・付加情報の「編集」または「削除」を押す
2. 編集する場合は内容を変更し、ダイアログの確定ボタン（「投稿」「流す」「返信」「決定」）を押す
3. 削除する場合は、確認画面で対象と影響を確認して「削除」を押す

ログインユーザは自分のデータを編集・削除できます。管理者、対象フロアを作成したフロア編集ユーザ、フロアメンバーは、他者のデータも編集・削除できます。ルームメンバーという理由だけでは他者のデータを操作できず、ゲストは自分の投稿も編集・削除できません。

通常画面に復元操作はありません。管理者による[投稿管理](../management/post-management.md)で復元できるデータもありますが、削除されたメディアファイルは復元されません。

### タグ・単語を使う

- 投稿・返信の作成画面では「タグ」からタグを選択します。自分の投稿・返信のタグは編集画面で変更し、ログインユーザが他者やゲストのタグを変更する場合は「タグ更新」を使います。
- 入力画面で単語グループを開いて単語ボタンを押すと、コメントの入力位置へ挿入できます。ゲストがリアクションだけを利用する場合の制限は、[流す](#流す)を参照してください。

## メディアの形式と上限

画面で添付できるファイルの主な条件は次のとおりです。

| 種類 | 形式 | 上限 |
| --- | --- | --- |
| 画像 | PNG、JPEG | 3MB |
| 動画 | MP4、OGV、WebM、MOV | 150MB、30秒 |
| 音声 | M4A、MP4、WebM、OGG、MP3、WAV | 6MB、30秒 |
| 動画字幕 | SRT、VTT | 2MB |

1つの投稿・返信・付加情報に付けられる主メディアは、画像・動画・音声のいずれか1種類です。字幕は動画に添付します。形式の判定などの詳細は[メディア入力仕様](../../spec/frontend/media-input.md)を参照してください。

## 操作後の状態

- 投稿または「流す」がタイムラインへ追加される
- 返信・付加情報・リアクションが対象へ追加される
- 編集・削除した結果が表示へ反映される

## 困ったとき

- コメントが400文字を超えている
- ゲスト制限により「投稿」が表示されない
- ゲストユーザがメディア機能を利用しようとしている
- ゲスト利用ルールへ同意していない
- 通信失敗により投稿やリアクションが反映されない

## 「流す」とは

- 「流す」は、タイムラインへ「流す投稿」として送信する形式です。
- タイムライン設定に応じてアニメーション表示されます。
- 再生中または一時停止中の本文をTabで選び、Enter・Spaceで一時停止・再開できます。本文のクリックでも切り替えられます。
- 流す投稿・返信は右から左へ3回移動すると非表示になり、表示されていた場所の余白もなくなります。その後、スクロールで画面外へ出てから戻ると、再び3回移動します。
- 絞り込み条件の「流す」を使用して、表示対象を切り替えられます。
