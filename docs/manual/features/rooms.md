# ルーム一覧の閲覧・管理

## 目的

- 対象フロアのルーム一覧を閲覧する
- 利用できる立場の場合は、ルームの作成、編集、削除、並び替えを行う
- ルーム一覧で表示状態と利用条件を確認する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| 表示されているルームの閲覧 | すべての利用者 |
| 非表示ルームの一覧表示 | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者 |
| ルームの作成・編集・削除・並び替え | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者 |
| 全ルームの表示・非表示 | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者 |
| メンバー限定ルームへのルームメンバー招待 | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者 |
| メンバー限定ルームのルームメンバー一覧 | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、対象ルームのルームメンバー、管理者 |

立場ごとの違いは[ロールと利用できる機能](../roles/README.md#フロアルーム内の早見表)を参照してください。

「非表示」「招待メンバーのみ」「ゲストはリアクションのみ」は、それぞれ影響する範囲が異なります。設定の意味と変更手順は[ルームの表示・入室・ゲスト操作を設定する](room-access-settings.md)を参照してください。

## ルーム一覧を閲覧する

1. フロア一覧から対象フロアを開く
2. ルーム一覧と各ルームの状態を確認する
3. 入室するルームを選択する

ルームカードには、設定に応じて「非表示中」「メンバー限定」「ゲストはリアクションのみ」「外部SNS連携」などが表示されます。ルームが一覧に表示されていても、メンバー限定の場合は入室時に権限が確認されます。

メンバー限定ルームでは、利用できる立場に応じて「ルーム単語」の右側に「ルームメンバー招待」と「ルームメンバー一覧」が表示されます。招待と一覧の詳しい手順は[ルームメンバー操作](room-members.md)を参照してください。ルームメンバー本人の脱退は対象ルームのタイムラインから行います。

## ルームを作成する

1. 「ルーム作成」を押す
2. 「ルームを作成」で、「基本情報」「画像」「参加・投稿設定」「表示・通知」の各項目を入力する
3. 「作成」を押す

主な入力項目は次のとおりです。

- タイトル（必須、100文字まで）
- 説明（200文字まで）
- ルーム画像（[形式と上限](timeline-post.md#メディアの形式と上限)を参照）
- ゲストはリアクションのみ
- 招待メンバーのみ
- タイムライン最上部に通知する
- 外部SNS連携ボタンを表示する
- 非表示にする

画像を選ぶとプレビューが表示されます。「添付を取り消す」は画像なしへ、「差し替えを取り消す」は保存済み画像へ戻します。保存済み画像を次回保存時に削除する場合は、「画像を削除」を押してください。

表示状態と利用条件に関する3項目は、組み合わせを確認してから設定してください。

## ルームを編集・削除する

1. 対象のルームカードを確認する
2. 内容や設定を変更する場合は「編集」を押す。「対象ルーム」に変更前の表示名が示されるので、対象を確認してから編集し、「保存」を押す
3. 削除する場合は「削除」を押す。「対象ルーム」と影響の説明を確認して「削除」を押す

編集内容を変更した後にキャンセル、Escキー、ダイアログの外側を選ぶと、変更を破棄するか確認されます。変更していない場合、または開始時と同じ内容へ戻した場合は確認されません。入力に誤りがある場合は、最初に修正が必要な項目へ移動します。

削除したルームはルーム一覧から外れ、通常操作ではそのルームとタイムラインを利用できなくなります。ルーム内の投稿、タグ、単語、AI解析設定、メディアを同時に個別削除する操作ではありません。ルームを復元すると、個別に削除されていないAI解析設定を再び利用できます。

管理画面から操作する場合は[ルーム管理](../management/room-management.md)を参照してください。

## ルームを並び替える

1. 並び替えるルームカードをドラッグする
2. 目的の位置へ移動する
3. 一覧へ反映された順序を確認する

## 全ルームの一覧表示を切り替える

対象フロアの削除されていない全ルームを一括で表示・非表示にできます。入室やゲスト操作の条件は変わりません。[一括変更の手順](room-access-settings.md#全ルームの一覧表示を切り替える)を参照してください。

## 操作後の状態

メンバー限定へ変更すると、入室権限のない利用者とゲストはタイムラインからルーム一覧へ戻ります。ルームを削除すると、そのルームの全利用者がルーム一覧へ戻ります。ログイン状態は維持されます。

- 利用者に表示可能なルームが一覧表示される
- 各ルームの表示状態と利用条件が表示される
- 利用できる立場に応じて、管理ボタンが表示される
- 作成、編集、削除、並び順、表示状態の変更が一覧へ反映される
- 既存ルームのダイアログでは、ルームカードと同じ表示名を「対象ルーム」で確認できる

## 困ったとき

- 利用できる立場ではないため、作成・編集・削除などのボタンが表示されない
- 非表示ルームを一覧表示できる立場ではない
- 一覧に表示されたメンバー限定ルームへ入室する立場を持っていない
- ルームメンバーであることだけでは、非表示ルームが一覧表示されない
- 一括表示・一括非表示を行っても入室条件が変わらない
  - 一括操作は一覧掲載だけを変更します。入室条件は各ルームの「招待メンバーのみ」で変更してください。
- 通信失敗により操作結果が反映されない
