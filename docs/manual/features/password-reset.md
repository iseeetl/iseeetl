# パスワード再設定

## 目的

- 登録メールアドレスへパスワード再設定リンクを送信する
- メール内のリンクから新しいパスワードを設定する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| 再設定リンクの送信 | 登録メールアドレスを利用できる人 |
| 新しいパスワードの設定 | 有効な再設定リンクを受け取った人 |

ログイン中に現在のパスワードが分かる場合は、[パスワード変更](change-password.md)も利用できます。

## 操作前の確認

メール機能が無効な環境では、再設定リンクの送信を利用できません。

- 登録に使用したメールアドレスを確認してください。
- 再設定メールを受信できることを確認してください。
- メール内のリンクには有効期限があり、一度再設定に使用したリンクは再利用できません。

## 手順

### 再設定リンクを送信する

1. ログイン画面の「パスワードが分からない方はこちらへ」を押す
2. 「登録しているメール」を入力する
3. 「パスワード再設定リンクを送信」を押す
4. 送信完了の通知を確認する
5. 受信したメールを開く

### 新しいパスワードを設定する

1. メール本文の再設定リンクを開く
2. 「読み込み中です」が消え、リンクが有効であることの確認が終わるまで待つ
3. 「パスワード」と「パスワード確認」を入力する
4. 「再設定」を押す
5. 完了メッセージを確認し、「ログインページへ」から新しいパスワードでログインする

## 操作後の状態

再設定すると、すべての端末で再ログインが必要になります。開いているタイムラインの接続も切断されます。

- 再設定リンクの送信を受け付けたことが表示される
- 再設定に成功すると「パスワードを再設定しました」と表示される
- 再設定後は新しいパスワードでログインできる

登録されていないメールアドレスを入力した場合も、画面には同じ送信完了メッセージが表示されます。

## 困ったとき

- メールが未入力、形式不正、または100文字を超えている
- メールが届かない
- 短時間に繰り返し送信したため、回数上限のメッセージが表示される
- リンクの有効期限が切れている
- すでに使用したリンクを開いている
- パスワードが未入力、または8〜16文字ではない
- パスワード確認が新しいパスワードと一致しない
- 通信失敗により再設定できない

メールが届かない場合は、迷惑メールフォルダ、入力したメールアドレス、最後に送信したメールを確認してください。

## 再設定リンクを確認できない場合

- リンクの確認に失敗した場合は「再試行」を押すと、同じリンクをもう一度確認できます。
- 再試行中はエラー、入力欄、ログインページへのリンクに代わって「読み込み中です」が表示されます。
- 再試行してもリンクが無効または期限切れの場合は、ログインページへのリンクが表示されます。
- 再設定リンク送信画面へ戻り、新しいリンクを送信してください。
