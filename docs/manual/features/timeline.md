# タイムラインの閲覧・ルーム内設定

## 目的

- ルームの投稿と返信を閲覧する
- ルーム情報を確認し、読み上げや表示方法を設定する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| 公開ルームの閲覧 | ゲストユーザ、ログインユーザ |
| メンバー限定ルームの閲覧 | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、ルームメンバー、管理者 |
| ルーム情報の確認・ルーム内のタイムライン設定 | 入室できる利用者 |
| 投稿・返信からのユーザキック | 対象フロアを作成したフロア編集ユーザ、管理者 |

立場ごとの利用条件は[ロールと利用できる機能](../roles/README.md)、ルーム設定による違いは[ルームの表示・入室・ゲスト操作](room-access-settings.md)を参照してください。

投稿の絞り込み、カラムの読み上げ、音を鳴らすタグ、Webプッシュ通知は[投稿を絞り込み・通知する](timeline-filters.md)を参照してください。

ルームメンバーの招待・一覧・削除はルーム一覧カードから、ルームメンバー本人の脱退は対象ルームのタイムラインから行います。詳しくは[ルームメンバー操作](room-members.md)を参照してください。

ユーザキックボタンの表示条件と操作後の影響は[ユーザをキック・解除する](kicked-users.md)を参照してください。

## 操作前の確認

- ルーム一覧から対象ルームを開いてください。
- ゲストユーザは、操作開始時に[ゲスト利用ルール](guest-rules.md)への同意を求められる場合があります。
- 「ゲストはリアクションのみ」のルームでは、ゲストユーザの投稿・返信が制限されます。

## 手順

1. ルーム一覧から対象ルームを開く
2. タイムラインの投稿と返信を確認する
3. 投稿、返信、付加情報の画像を拡大表示する場合や動画を再生する場合は、画像または動画サムネイルを押す。AI解析結果も通常の付加情報として表示される
4. 音声を保存する場合は音声プレイヤー右のダウンロードアイコンを押す。開いた画像または動画を保存する場合は画面左上のダウンロードアイコンを押す
5. ルーム情報を確認する場合は「ルーム情報」を押す
6. 読み上げ速度や表示項目を変更する場合は「タイムライン設定」を開き、項目を変更して「決定」を押す
7. スマートフォン表示で複数カラムがある場合は、タブから表示するカラムを選ぶ
8. ルーム一覧へ戻る場合は「ルーム一覧へ戻る」を押す

動画は原寸を上限に画面中央へ表示します。画面に収まらない場合だけ、縦横比を保って縮小します。

iPhoneのホーム画面からアプリとして画像を拡大表示している場合、ダウンロードアイコンを押すとiOSの共有画面が開きます。表示された保存先（「画像を保存」「ファイルに保存」など）を選んでください。保存しない場合は共有画面を閉じると、画像を拡大した画面へ戻ります。

## 操作後の状態

- タイムラインに投稿と返信が表示される
- 投稿、返信、付加情報の画像を拡大表示し、動画を再生できる。画像、音声、動画は端末へ保存できる
- iPhoneのホーム画面アプリでは、画像の共有画面を閉じると拡大表示へ戻る
- ルーム情報を確認できる
- 読み上げや表示設定が現在のブラウザへ保存される

## 困ったとき

- メンバー限定ルームへ入室する立場を持っていない
- ゲスト制限により「投稿」が表示されず、「流す」だけが表示される
- 保存済みまたは共有URLの絞り込み条件によって投稿が表示されない
- 別の端末やブラウザで同じタイムライン設定が表示されない
- 通信失敗により絞り込みや設定が反映されない
- 画像の保存先や保存後の操作は、使用しているブラウザやOSによって異なる

## ルーム情報

主に次の情報が表示されます。

- フロアタイトル
- ルームタイトル
- ルーム説明
- ルーム作成者
- ルーム作成日

## ルーム内のタイムライン設定

- 読み上げ速度
- 投稿者、日付、タグ、付加情報、アクションボタンの表示。AI解析結果だけを分ける表示切替はない
- 「流す」のアニメーション
- 「流す」の速度
- ユーザキックボタンの表示

これらの設定は現在のブラウザへ保存され、以後に開くタイムラインへ反映されます。別の端末やブラウザには引き継がれません。

AI解析設定と結果が追加されない場合の確認は[AI解析設定を管理する](ai-analysis-settings.md)を参照してください。

メニューの「設定」で変更するフォントと文字サイズは、[タイムラインのフォント・文字サイズ設定](settings.md)を参照してください。

ユーザキックボタンは、管理者または対象フロアを作成したフロア編集ユーザの場合に設定できます。ボタンから実行する操作は[ユーザをキック・解除する](kicked-users.md)を参照してください。
