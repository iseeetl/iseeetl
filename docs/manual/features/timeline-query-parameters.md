# タイムライン共有URL（複数カラムの絞り込み）

## 目的

- URLを共有するだけで、タイムライン全体またはカラムごとに異なる絞り込み条件を一時適用する
- 同じ条件・カラム構成のタイムラインをほかの利用者にも開いてもらう

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| 共有URLによる一時的な絞り込み | 対象ルームへ入室できる利用者 |

## 操作前の確認

- 対象ルームのタイムラインURLを開けること
- URLの基本部分が `/floor/FLOOR_ID/room/ROOM_ID` の形式であること
- タグを指定する場合は、ルームに登録されているタグ名または翻訳名を使用すること
- 通常の保存可能な絞り込みを設定する場合は、[投稿を絞り込み・通知する](timeline-filters.md)を参照すること

## URLの基本規則

- 条件が付いていない基本URLに、`?` と最初の条件を追加する。既に `?` がある場合は既存の条件を整理し、追加条件を `&` でつなぐ
- 2つ目以降の条件は `&` でつなぐ
- カラム番号なしの条件は、表示するすべてのカラムへ適用する
- `col1_`〜`col10_`を付けた条件は、その番号のURL指定カラムだけへ適用する
- 全体条件とカラム別条件を同時に指定した場合は、両方を満たす投稿が表示される

```text
各カラムの表示条件 = 全体条件 AND そのカラムの条件
```

`colN_`付きの条件を指定すると、条件なしカラム1本に加えて、有効なURL指定カラムが番号順に表示されます。たとえば`col1_`と`col2_`を指定した場合は、合計3カラムです。

## 指定できる絞り込み条件

| 条件 | 全体へ指定 | 1番目のURLカラムへ指定 | 値 |
| --- | --- | --- | --- |
| キーワード | `keyword` | `col1_keyword` | 1〜200文字。空白で複数指定でき、引用符で囲んだ語句は1つのキーワードとして扱う |
| キーワードの組み合わせ | `logicalOperator` | `col1_logicalOperator` | `or`（いずれか）/ `and`（すべて） |
| タグ | `tag` | `col1_tag` | タグ名を指定。複数の場合はカンマで区切る（最大100件） |
| タグの組み合わせ | `tagOperator` | `col1_tagOperator` | `or`（いずれか）/ `and`（すべて） |
| ユーザ名 | `userName` | `col1_userName` | 完全一致するユーザ名（1〜20文字） |
| タグ無し | `noTags` | `col1_noTags` | `true` / `false` |
| 「流す」投稿 | `animation` | `col1_animation` | `true` / `false` |
| 一致結果の表示 | `filterMode` | `col1_filterMode` | `include`（表示）/ `exclude`（非表示） |
| 関連投稿の表示範囲 | `showRange` | `col1_showRange` | `all`（関連投稿を含む）/ `target`（一致対象のみ） |

カラム番号なしの`showRange`を指定した場合は、各カラムの`colN_showRange`より優先されます。

## 手順

1. 共有したいルームのタイムラインを開く
2. 既存の条件を確認し、[URLの基本規則](#urlの基本規則)に従って条件を追加する
3. 複数条件を指定する場合は`&`でつなぐ
4. EnterキーなどでURLを開き、表示されたカラムと投稿を確認する
5. アドレスバーから適用後のURLをコピーして共有する

条件値の記号はURLエンコードしてください。たとえば、値に含まれる`&`は`%26`、`#`は`%23`、空白は`%20`にします。`keyword=研究%26開発`なら「研究&開発」を1つの値として指定できます。アドレスバーからのコピーだけでは、区切りとして解釈された記号は修復できません。

カンマを含むタグ名は、共有URLで1つのタグとして指定できません。通常の[絞り込み画面](timeline-filters.md)を使用してください。

## 使用例

### 全カラムへ同じキーワードを適用する

```text
/floor/FLOOR_ID/room/ROOM_ID?keyword=重要
```

保存済みのカラム構成を保ったまま、すべてのカラムへキーワード「重要」を一時適用します。

### 2つのURLカラムへ異なる条件を適用する

```text
/floor/FLOOR_ID/room/ROOM_ID?col1_keyword=重要&col2_userName=山田
```

- 条件なしカラム
- キーワード「重要」のカラム
- ユーザ名「山田」のカラム

の合計3カラムを表示します。

### 全体タグとカラム別条件を組み合わせる

```text
/floor/FLOOR_ID/room/ROOM_ID?tag=災害&col1_keyword=重要&col2_userName=山田
```

- 条件なしカラムを含む全カラム: タグ「災害」
- 1番目のURLカラム: タグ「災害」ANDキーワード「重要」
- 2番目のURLカラム: タグ「災害」ANDユーザ名「山田」

として表示します。

### 複数タグをすべて含む投稿だけを表示する

```text
/floor/FLOOR_ID/room/ROOM_ID?col1_tag=災害,重要&col1_tagOperator=and&col1_showRange=target
```

1番目のURLカラムへ、2つのタグを両方含む一致対象だけを表示します。

### 一致する投稿を非表示にする

```text
/floor/FLOOR_ID/room/ROOM_ID?col1_keyword=社外秘&col1_filterMode=exclude
```

1番目のURLカラムでは、指定したキーワードに一致する投稿を非表示にします。

## 組み合わせ可能な表示設定

| 設定 | 指定例 | 挙動 |
| --- | --- | --- |
| 表示言語 | `lang=ja` | 表示言語を一時変更する |
| 返信を隠す | `reply=no` | 返信を非表示にする |
| 付加情報を隠す | `info=no` | 投稿・返信の付加情報を非表示にする |
| 文字を見やすくする | `eyeFriendlyMode=on` | 文字を大きくし、テキストアニメーションを停止する |
| AR表示 | `armode=on` | AR用レイアウトへ切り替える |
| ARですべてのカラムを表示 | `armode=on&cols=all` | PCのAR表示ですべてのカラムを表示する |

## 操作後の状態

- URLを開くと、全体条件とカラム別条件に沿った投稿が表示される
- `colN_`を指定した場合は、条件なしカラムとURL指定カラムが番号順に表示される
- 同じ画面でURLの条件だけを変更した場合も、新しい条件でカラムが更新される
- URL条件をすべて外すと、保存済みのカラム構成へ戻る

## 困ったとき

- 症状: 指定したカラムが表示されない
  - 原因: カラム番号が`col1`〜`col10`の範囲外、条件値が不正、または条件が空になっている
  - 対処: カラム番号と値を確認し、同じパラメータを重複して指定しない
- 症状: タグ条件が反映されない
  - 原因: ルームに存在しないタグ名、または表示されている名前と一致しない値を指定している
  - 対処: ルームの絞り込み画面でタグ名を確認し、同じ名前を指定する
- 症状: 保存していた絞り込みカラムが見えなくなった
  - 原因: `colN_`付きのURL条件を開いている間は、保存済みカラムの代わりにURL指定カラムを表示する
  - 対処: URLから絞り込み条件をすべて削除する。保存済みカラム自体は削除されていない
- 症状: URLを開いて変更した絞り込みが次回に残らない
  - 原因: URL由来の条件と、その表示中に行ったカラム操作は一時適用である
  - 対処: 継続利用する条件は、クエリパラメータのないタイムラインで通常の絞り込みとして保存する
- 症状: Webプッシュ通知を設定できない
  - 原因: URL条件指定中は「Webプッシュ通知を行う」のチェック欄が表示されていても、変更できない
  - 対処: URLから絞り込み条件を外してから通知条件を設定する

## 補足

- 共有URLやブラウザ履歴には、指定したキーワードやユーザ名が残る。個人情報や機密情報を条件値へ含めない
- URL由来の条件は一時適用であり、保存済みの絞り込み条件を変更しない
- URLから`webPush`、読み上げ、PushFilter IDは指定できない
- 不正な値や存在しないタグは無視され、適用できない条件がある場合は警告が表示される
- 投稿詳細URLで開いた対象投稿は、絞り込み条件に一致しない場合も条件なしカラムへ表示される
