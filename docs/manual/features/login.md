# ログイン

## 目的

- メールとパスワード、Google、またはLINEを使用してログインする
- ログイン後に、フロア一覧または指定されていたルームへ移動する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| メールとパスワードでログイン | メールとパスワードを登録済みの未ログインユーザ |
| Googleでログイン | Googleアカウントを利用する未ログインユーザ |
| LINEでログイン | LINEアカウントを利用する未ログインユーザ |

ログイン後に利用できる機能は[一般ユーザ](../roles/user.md)を参照してください。

## 操作前の確認

Google・LINEログインは、この環境で有効な方式だけ表示されます。

- インターネットへ接続してください。
- メールとパスワードでログインする場合は、アカウントの有効化を完了してください。
- 招待やルームからログイン画面へ移動した場合は、そのままログインすると元のルームへ戻れる場合があります。
- ログイン画面の同意案内から、利用許諾・著作権・禁止事項・免責事項、プライバシーポリシー、[Cookieポリシー](cookie-policy.md)を確認できます。
- メールとパスワード、Google、LINEのいずれでログインする場合も、ログインを続けると3文書へ同意したものとして扱われます。個別のチェックボックスは表示されません。

## 手順

### メールとパスワードでログインする

1. ログイン画面を開く
2. 同意案内にある3文書のリンクを開き、内容を確認する
3. 「メール」と「パスワード」を入力する
4. 「ログイン」を押す

### GoogleまたはLINEでログインする

1. ログイン画面を開く
2. 同意案内にある3文書のリンクを開き、内容を確認する
3. GoogleまたはLINEのログインボタンを押す
4. 各サービスの画面で認証する
5. アプリへ戻るまで待つ

LINEの認証画面を別画面で開けない環境では、現在の画面からLINEへ移動します。

## 操作後の状態

- 成功時に「ログインしました」と通知される

- 通常はフロア一覧へ移動する
- ログイン前のURLにフロアとルームの指定がある場合は、対象ルームのタイムラインへ移動する
- ログイン中のユーザ情報が画面へ反映される

## ログアウトする

メニューの「ログアウト」を押します。成功すると「ログアウトしました」と通知され、フロア一覧へ移動します。失敗した場合はメニューの案内から再試行してください。

## 困ったとき

- メールが未入力、形式不正、または100文字を超えている
- パスワードが未入力、または8〜16文字ではない
- アカウントの有効化が完了していない
- 入力したメールまたはパスワードが登録内容と一致しない
- 短時間にログインを繰り返したため、時間を置く必要がある
- GoogleまたはLINEの認証画面を途中で閉じた
- 通信失敗によりログインできない
