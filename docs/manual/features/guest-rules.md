# ゲスト利用ルール

## 目的

- ゲストユーザが投稿、返信、「流す」、リアクションを行う前に利用条件を確認する

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| ゲスト利用ルールへの同意 | タイムラインをゲスト利用している未ログインユーザ |

ログインユーザには、この確認は表示されません。

## 操作前の確認

- 未ログインの状態でルームのタイムラインを開いてください。
- 利用許諾・著作権・禁止事項・免責事項、プライバシーポリシー、Cookieポリシーを確認してください。
- CookieポリシーにはCookieと外部送信の内容が記載され、ゲスト操作の「同意したとみなす」文に含まれます。

## 手順

1. タイムラインで投稿、返信、「流す」、またはリアクションを開始する
2. 「ゲストでの利用ルール」が表示されたら内容を確認する
3. 必要に応じて同意案内文中の利用許諾、プライバシーポリシー、Cookieポリシーのリンクを開く
4. 続行する場合は「同意する」を押す
5. 操作を中止する場合は「キャンセル」を押す

メディア機能を利用する場合は、ダイアログ内の「ログインページへ」からログインしてください。

## 操作後の状態

- 「同意する」を押すと、開始した投稿、返信、「流す」、リアクションの操作を続行できる
- 「キャンセル」を押すと、開始した操作が中止される

## 困ったとき

- 同意せずにダイアログを閉じたため、操作を続行できない
- 「ゲストはリアクションのみ」のルームで投稿や返信を行おうとしている
- メディアを添付しようとしている

## ルーム設定による違い

- 「ゲストはリアクションのみ」が無効な公開ルームでは、同意後にゲストユーザがテキスト投稿、返信、「流す」、リアクションを利用できます。
- 「ゲストはリアクションのみ」のルームでは、同意後も投稿と返信は利用できません。
- 同意状態はタイムラインを開いている間の状態です。画面を開き直した場合は再度表示されることがあります。
