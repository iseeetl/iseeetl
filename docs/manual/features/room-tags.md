# ルームタグの管理

## 目的

- 対象ルームのタグを作成、更新、削除する
- ルームタグをCSVで入出力し、フロアタグの状態へ戻す

## 利用できる人

| 操作 | 利用できる人 |
| --- | --- |
| 公開ルームのタグ一覧の閲覧 | ゲストユーザ、ログインユーザ。ただしキック済みのログインユーザは除く |
| メンバー限定ルームのタグ一覧の閲覧 | 対象ルームへ入室できるログインユーザ |
| ルームタグの作成・更新・削除 | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者 |
| CSVインポート・エクスポート | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者 |
| フロアタグへ戻す | 対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者 |

ルームメンバーであることだけではルームタグを管理できません。立場の違いは[ロールと利用できる機能](../roles/README.md)を参照してください。

## 操作前の確認

- タグを閲覧する場合は、対象ルームのタイムラインへ入室してください。
- 管理する場合は、ログインした状態で対象フロアのルーム一覧を開いてください。
- 各ルームの「ルームタグ」は対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者に表示されます。
- タグ名は現在の表示言語を基準として保存され、設定されている対象言語の翻訳も一覧に表示されます。
- CSVインポートと「フロアタグに戻す」は、同期元にないタグを一覧から外します。必要に応じて事前にCSVエクスポートしてください。

## 手順

### タグを閲覧する

タイムラインで「投稿の絞り込みを行う」を開き、「タグ」欄を確認してください。絞り込みを適用する場合は[投稿を絞り込み・通知する](timeline-filters.md)を参照してください。

### 管理用の一覧を確認する

1. 対象ルームの「ルームタグ」を押す
2. 「対象ルーム」が意図したルームであることを確認する
3. 「ルームタグ一覧」で件数、表示順番、タグ名、翻訳を確認する

一覧を取得できない場合は「再試行」を押してください。

### タグを作成する

1. 「ルームタグ一覧」で「作成」を押す
2. 表示順番を1以上100以下の整数で入力する
3. タグ名を50文字以内で入力する
4. 同じダイアログ内の「ルームタグを作成」で対象ルームを確認し、「作成」を押す

表示順番を入力しなかった場合は100として作成されます。

### タグを更新・削除する

1. 対象タグの「編集」または「削除」を押す
2. 編集する場合は同じダイアログ内の「ルームタグを編集」で対象ルームを確認し、表示順番とタグ名を編集して「保存」を押す
3. 削除する場合は確認画面で「対象ルーム」と「対象タグ」を確認し、「削除」を押す

作成・編集で入力を変更してから「戻る」、Escキー、ダイアログの外側を選ぶと、変更を破棄するか確認されます。変更がない場合は確認せず一覧へ戻ります。作成・保存・削除に成功すると一覧が更新されます。

### CSVをエクスポートする

1. 「CSVエクスポート」を押す
2. roomtag.csvが保存されたことを確認する

### CSVをインポートする

1. ヘッダーなしで、各行を「表示順番,タグ名」としたCSVを用意する
2. 表示順番を1以上100以下、タグ名を1文字以上50文字以内にする
3. 行数を1行以上100行以下にする
4. 同じタグ名が複数行にないことを確認する
5. 「CSVインポート」でCSVファイルを選択する

ファイルを選択するとインポートが始まり、現在のルームタグはCSVの内容と同期されます。

同名の既存タグはIDを維持して更新・復元され、CSVにない有効タグは論理削除されます。CSVにだけある名前は新しいタグとして作成されます。

### フロアタグへ戻す

1. 必要に応じて現在のタグをCSVエクスポートする
2. 「フロアタグに戻す」を押す
3. フロアタグにないルームタグが一覧から外れることを確認し、実行する

## 操作後の状態

- タグが表示順番に沿って一覧表示される
- 作成、更新、削除の結果が一覧へ反映される
- CSVエクスポートでは現在のルームタグがファイルへ出力される
- CSVインポートでは現在のルームタグがCSVの内容と同期される
- 「フロアタグに戻す」では現在のルームタグが対象フロアのフロアタグと同期される

## 困ったとき

- 「ルームタグ」が表示されない
  - 対象フロアを作成したフロア編集ユーザ、フロアメンバー、管理者のいずれかであることを確認してください。
- タグ一覧を取得できない
  - メンバー限定ルームへ入室できる立場か、対象フロアでキックされていないかを確認してください。
- タグを保存できない
  - 表示順番が1以上100以下の整数か、タグ名が1文字以上50文字以内かを確認してください。
- CSVをインポートできない
  - ヘッダーを入れず、各行が「表示順番,タグ名」の2列になっていることを確認してください。
  - 行数、表示順番、タグ名の文字数、重複するタグ名がないことを確認してください。
  - CSVに含めなかったルームタグが有効なルームAI解析設定で使用されている場合は同期できません。関連するAI解析設定を削除してから再実行してください。
- CSVをエクスポートできない
  - ルームタグが1件以上登録されていることを確認してください。
- 必要なタグが消えた
  - 同期元にないタグは論理削除され、通常の一覧から外れます。同じ名前を含むCSVを再インポートするか、同名のフロアタグへ戻すと復元されます。
- タグを削除できない
  - 投稿・返信・通知で使用中でも論理削除でき、参照は残ります。有効なルームAI解析設定で使用中のルームタグは削除できません。画面の案内に従い、関連するAI解析設定を削除してから再実行してください。

## 補足

- CSVのタグ名にカンマまたはダブルクォートを含める場合は、タグ名をダブルクォートで囲み、タグ名内のダブルクォートを2つ重ねてください。
- 同名判定は前後の空白を除去した完全一致で、大文字小文字を区別します。CSV内で未登録のタグ名へ変更すると、旧名のタグは論理削除され、新しい名前のタグが作成されます。画面の「編集」による名前変更では、同じタグを更新します。
- 削除したタグは通常のルームタグ一覧に表示されなくなります。
