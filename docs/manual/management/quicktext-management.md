# 単語管理（管理画面）

## 目的

- 共通の単語グループと単語を一覧表示する
- 単語グループと単語を作成・編集・削除・並び替える

## 前提

- 管理者でログインしている

## 画面を開く

1. 画面左上の「メニュー」を開く
2. 「単語管理」を選ぶ

## 画面構成

- 検索条件: なし
- 単語グループ: グループ名、表示順番、言語、単語作成、グループの削除・編集操作
- 単語: 名称、表示順番、言語、削除・編集操作
- 並び替え: 単語グループと、各グループ内の単語をドラッグで並び替える

グループや単語の読み込み状況、登録がないこと、取得エラーは画面内に表示されます。取得に失敗した場合は「再試行」を選んでください。

## 手順

### 単語グループを作成・編集する

1. 作成する場合は「単語グループ作成」を押す
2. 編集する場合は対象グループの「編集」を押す
3. 編集時は「単語グループ名」で変更前の対象を確認する
4. タイトルを入力する
5. 作成時は「作成」、編集時は「保存」を押す

タイトルは必須で、200文字以内です。新しいグループは一覧の末尾へ追加されます。

### 単語を作成・編集する

1. 作成する場合は、追加先グループの「単語作成」を押す
2. 編集する場合は対象単語の「編集」を押す
3. 「単語グループ名」で追加先を確認し、編集時は「名称」で変更前の対象も確認する
4. 名称を入力する
5. 作成時は「作成」、編集時は「保存」を押す

名称は必須で、200文字以内です。新しい単語は対象グループの末尾へ追加されます。

作成時の言語は画面の表示言語です。編集時は保存済みの言語を維持し、未設定または非対応の場合だけ画面の表示言語を使用します。画面の表示言語も非対応なら日本語を使用します。作成・編集ダイアログで言語を個別に選択することはできません。

入力を変更してから「キャンセル」、Escキー、ダイアログの外側を選ぶと、変更内容の破棄確認が表示されます。入力を変更していない場合と開始時の内容へ戻した場合は、そのまま閉じます。

### 単語グループと単語を並び替える

1. 対象のドラッグ用アイコンをつかんで目的の位置へ移動する
2. 更新完了の通知を確認する

単語グループはグループ一覧内、単語は同じグループ内で並び替えられます。

### 単語を削除する

1. 対象単語の「削除」を押す
2. 確認ダイアログの「単語グループ名」と「名称」を確認する
3. 「削除」を押す

### 単語グループを削除する

1. 対象グループの「削除」を押す
2. 確認ダイアログの「単語グループ名」と、配下の単語も削除されることを確認する
3. 「削除」を押す

## 操作後の状態

- 単語グループと単語の作成・編集結果が一覧へ反映される
- 削除した単語グループまたは単語が一覧から消える
- 並び替え結果が表示順番へ反映される

## 困ったとき

- 単語を意図しないグループへ追加しそうになる
  - 追加先グループ内の「単語作成」を押したか確認してください。
- 並び替えに失敗した、または表示順番が意図と異なる
  - 通信エラーでは画面上の順番も操作前へ戻ります。表示を確認し、必要に応じてもう一度並び替えてください。
- 作成・編集時の言語が意図と異なる
  - 作成時は画面の表示言語、編集時は対象の保存済み言語を確認してください。画面の表示言語を変えても、保存済みの言語は変更されません。
- 削除したグループや単語を元に戻したい
  - 削除は物理削除のため復元できません。必要な場合は作成し直してください。

## 注意事項

- 並び替えの保存中は、ドラッグ、作成、編集、削除ボタンを使用できません。完了またはエラー通知を待ってください。
- 共通の単語は、通常画面のフロア単語・ルーム単語とは別に管理されます。
