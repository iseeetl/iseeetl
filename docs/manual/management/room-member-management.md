# ルームメンバー管理（ルームメンバー一覧）

## 目的

- システム全体のルームメンバー関係を一覧で確認する
- 対象ユーザをルームメンバーから削除する

## 前提

- 管理者でログインしている

## 画面を開く

1. 画面左上の「メニュー」を開く
2. 「ルームメンバー管理」を選ぶ

## 画面構成

- 検索条件: なし
- 一覧: ルーム名、ユーザ名、作成日
- 操作: 行内の「削除」からルームメンバー削除ダイアログを開く
  - 対象は「対象ルーム」と「対象ユーザ」に分けて表示される

## 手順

### ルームメンバーを確認する

1. 一覧でルーム名とユーザ名を確認する
2. 必要に応じてページを切り替える

### ルームメンバーを削除する

1. 一覧から対象の「削除」を押す
2. 削除ダイアログの「対象ルーム」と「対象ユーザ」を確認する
3. 「削除」を押す
4. 対象が一覧から除かれたことを確認する

## 削除後の影響

- ルームメンバーの関係そのものが削除されます。
- 対象ルームがメンバー限定の場合、対象ユーザのアクセスは再判定されます。
- 対象フロアを作成したフロア編集ユーザ、フロアメンバーなど別の有効な立場がある場合は、メンバー限定ルームを引き続き利用できます。
- 公開ルームは、ルームメンバーでなくても引き続き利用できます。
- ユーザアカウント、フロア、ルーム、投稿は削除されません。

## 操作後の状態

- ルームメンバー関係が削除され、一覧が更新される
- 対象ユーザの対象ルームでの立場と利用範囲が更新される

## 困ったとき

- 削除対象を判断できない
  - 削除ダイアログの「対象ルーム」と「対象ユーザ」を確認してください。
- 削除後も対象ユーザがルームへ入室できる
  - 公開ルーム、対象フロアを作成したフロア編集ユーザ、フロアメンバーなど別の条件によって利用できる場合があります。
- 削除した関係を復元したい
  - 管理画面には復元操作がないため、通常画面から改めてルームへ招待してください。

## 注意事項

- この操作は論理削除ではなく、ルームメンバー関係の削除です。
- 対象ユーザ自身が行う「脱退」と、管理者が行う削除は、どちらもルームメンバーの関係を解除します。
