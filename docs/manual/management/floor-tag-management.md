# フロアタグ管理

## 目的

- フロアタグを一覧・検索する
- 既存のフロアタグを編集し、削除を別操作で行う

## 前提

- 管理者でログインしている

## 画面を開く

1. 画面左上の「メニュー」を開く
2. 「フロアタグ管理」を選ぶ

## 画面構成

- 検索条件: タグ名、2〜10文字
- 一覧: 表示順番、タグ名、所属フロア名、作成日、更新日
- 操作: 各行に削除・編集を表示

## 手順

### フロアタグを検索する

1. 検索欄へタグ名の一部を入力する
2. 「検索」を押す
3. 一覧に表示された対象を確認する

検索語を空にして検索すると、検索条件を解除できます。

### フロアタグを編集する

1. 有効な対象の「編集」を押す
2. ダイアログの対象フロアと対象タグが目的の行と一致することを確認する
3. 表示順番またはタグ名を変更する
4. 「保存」を押す

変更後に「キャンセル」、Escキー、ダイアログ外を押した場合は破棄確認が表示されます。「キャンセル」で編集へ戻り、「破棄」で保存せず閉じます。

編集できる項目は次のとおりです。

- 表示順番: 1〜100の整数。未入力の場合は100
- タグ名: 必須、50文字以内

### フロアタグを削除する

1. 削除する場合は有効な対象の「削除」を押す
2. 確認ダイアログのタグ名と所属フロアを確認し、「削除する」を押す

## 操作後の状態

- 検索条件に一致するフロアタグが一覧表示される
- 編集内容が一覧へ反映される
- 削除するとタグは完全に削除され、一覧から消える。復元できない

## 困ったとき

- フロアタグを検索できない
  - 検索語が2文字未満または10文字を超えていないか確認してください。
- 表示順番を保存できない
  - 1〜100の整数を入力してください。未入力で保存した場合は100になります。
- フロアタグを削除できない
  - 有効なフロアAI解析設定で使用中のフロアタグは削除できません。画面の案内に従い、関連するAI解析設定を削除してから、もう一度操作してください。
- 新しいフロアタグを作成するボタンがない
  - 現在の管理画面には作成操作がありません。対象フロアの通常画面から作成してください。

## 注意事項

- フロアタグを削除しても、コピーして作成済みのルームタグは削除されません。
- 管理画面のフロアタグと、通常画面で対象フロアを選んで管理するフロアタグは同じ対象です。
