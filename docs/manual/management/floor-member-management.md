# フロアメンバー管理（フロアメンバー一覧）

## 目的

- システム全体のフロアメンバー関係を一覧で確認する
- 対象ユーザをフロアメンバーから削除する

## 前提

- 管理者でログインしている

## 画面を開く

1. 画面左上の「メニュー」を開く
2. 「フロアメンバー管理」を選ぶ

## 画面構成

- 検索条件: なし
- 一覧: フロア名、ユーザ名、作成日
- 操作: 行内の「削除」からフロアメンバー削除ダイアログを開く
  - 対象は「対象フロア」と「対象ユーザ」に分けて表示される
- 論理削除済みフロアに残っているメンバー関係も一覧へ表示され、同じ「削除」操作で整理できる

## 手順

### フロアメンバーを確認する

1. 一覧でフロア名とユーザ名を確認する
2. 必要に応じてページを切り替える

### フロアメンバーを削除する

1. 一覧から対象の「削除」を押す
2. 削除ダイアログの「対象フロア」と「対象ユーザ」を確認する
3. 「削除」を押す
4. 対象が一覧から除かれたことを確認する

## 削除後の影響

- フロアメンバーの関係そのものが削除されます。
- 対象ユーザは、フロアメンバーとしてのルーム管理機能を利用できなくなります。
- メンバー限定ルームへのアクセスは再判定され、フロアメンバー以外の有効な立場がなければ利用できなくなります。
- 公開ルームやルームメンバーとして利用できるルームは、引き続き利用できる場合があります。
- ユーザアカウント、フロア、ルーム、投稿は削除されません。

## 操作後の状態

- フロアメンバー関係が削除され、一覧が更新される
- 対象ユーザのフロア内での立場と利用範囲が更新される

## 困ったとき

- 削除対象を判断できない
  - 削除ダイアログの「対象フロア」と「対象ユーザ」を確認してください。
- 削除後も対象ユーザがルームへ入室できる
  - 公開ルーム、ルームメンバー、別の有効な立場によって利用できる場合があります。
- 削除した関係を復元したい
  - 管理画面には復元操作がないため、通常画面から改めてフロアへ招待してください。

## 注意事項

- この操作は論理削除ではなく、フロアメンバー関係の削除です。
- 対象ユーザ自身が行う「脱退」と、管理者が行う削除は、どちらもフロアメンバーの関係を解除します。
