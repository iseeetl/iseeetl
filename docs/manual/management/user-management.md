# ユーザ管理

## 目的

- ユーザを状態別に一覧・検索する
- ユーザ情報とロールを編集し、論理削除・復元を別操作で行う

## 前提

- 管理者でログインしている

## 画面を開く

1. 画面左上の「メニュー」を開く
2. 「ユーザ管理」を選ぶ

## 画面構成

- 検索条件: ユーザ名またはメールの部分一致、2〜20文字
- 状態: すべて、未削除、削除済み（初期表示はすべて）
- 一覧: ユーザ名、メール、権限、状態表示、作成日、更新日、削除日
- 操作: 有効な行は「削除」「編集」、削除済み行は「復元」を表示

## 手順

### ユーザを検索する

1. 検索欄へユーザ名またはメールの一部を入力する
2. 「検索」を押す
3. 一覧に表示された対象を確認する

検索語を空にして検索すると、検索条件を解除できます。

### ユーザ情報を編集する

1. 有効な対象ユーザの「編集」を押す
2. 必要な項目を変更する
3. 「保存」を押す
4. 一覧へ更新結果が反映されたことを確認する

編集できる項目は次のとおりです。

- ユーザ名（必須、2〜20文字）
- メール
- 新しいパスワード（変更する場合のみ、8〜16文字）
- 権限

選択できる権限は「投稿者」「フロア編集者」「開発者」です。管理者を新たに割り当てることはできません。
編集ダイアログには対象ユーザ名が表示されます。新しいパスワードは変更しない場合は空欄のままにし、
変更する場合だけ8〜16文字で入力します。入力後に閉じると、未保存の変更を破棄するか確認されます。

### ユーザを論理削除・復元する

1. 削除する場合は「未削除」または「すべて」から対象の「削除」を押す
2. 復元する場合は「削除済み」または「すべて」から対象の「復元」を押す
3. 確認ダイアログのユーザ名を確認し、「削除する」または「復元する」を押す

論理削除したユーザは通常利用の対象から外れますが、管理画面の一覧には残ります。
論理削除すると対象ユーザのログイン状態が失効し、開いているタイムラインの接続が切れます。復元後も削除前のログイン状態は再利用できないため、対象ユーザは改めてログインする必要があります。

## 管理者を編集する場合

- 権限は読み取り専用になり、管理者以外へ変更できません。
- 行に「削除」「復元」ボタンは表示されません。
- ユーザ名、メール、新しいパスワードは更新できます。

## 操作後の状態

- 検索条件に一致するユーザが一覧表示される
- ユーザ情報と権限の変更が一覧へ反映される
- 論理削除すると削除日が表示され、復元すると削除日が解除される
- 新しいパスワードを設定した場合、対象ユーザの既存のログイン状態が無効になり、開いているタイムラインの接続も切断される

## 困ったとき

- 検索できない
  - 検索語が2文字未満または20文字を超えていないか確認してください。
- メールを保存できない
  - メール形式と、他のユーザが同じメールを使用していないか確認してください。
- パスワードを変更したくない
  - 「新しいパスワード」は未入力のまま送信してください。
- 管理者の権限や論理削除を変更できない
  - 管理者を管理画面から降格・論理削除することはできません。
- 削除できない
  - 対象ユーザが有効なAI解析設定で「付加情報を行うユーザ」として使用中の場合は、先にAI解析設定を変更または削除してください。
- メールが未設定のユーザを更新したい
  - 外部認証でメールを取得していないユーザは、メールを未設定のまま他の項目を更新できます。

## 注意事項

- この画面からユーザを新規作成することはできません。
- ユーザの論理削除と、フロアメンバー・ルームメンバー関係の削除は別の操作です。
