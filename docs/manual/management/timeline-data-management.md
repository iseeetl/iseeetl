# タイムラインデータ管理

## 目的

- フロアとルームを一覧・検索し、ルームごとのタイムラインJSONまたはメディアZIPをダウンロードする
- 投稿データとメディアファイルを用途に応じて取得する

## 前提

- 管理者でログインしている

## 画面を開く

1. 画面左上の「メニュー」を開く
2. 「タイムラインデータ管理」を選ぶ

## 画面構成

### フロア一覧

- 検索条件: フロア名または説明、2〜10文字
- 一覧: フロア名、作成ユーザ名、作成日、更新日、削除日、有効／削除済みと表示／非表示の状態表示
- 操作: 「ルーム一覧」から対象フロアのルーム一覧を開く

### ルーム一覧

- 検索条件: ルーム名または説明、2〜100文字
- 一覧: ルーム名、作成ユーザ名、作成日、更新日、削除日、有効／削除済み、表示／非表示、公開／メンバー限定の状態表示
- 操作: 「JSON」「メディアZIP」「フロア一覧へ戻る」

削除済みデータは状態表示と削除日で判別できます。

## 出力形式と収録対象

| 形式 | 収録対象 | 削除済みフロア・ルームの扱い |
| --- | --- | --- |
| タイムラインJSON | 論理削除されていない投稿・返信・付加情報と、関連するフロア・ルーム・タグ・ユーザの情報。投稿は新しい順 | 選択・出力できる。フロア・ルーム自体の削除状態だけでは空にならない |
| メディアZIP | 対象ルームの保存領域に残るファイル一式。JSONから未参照のファイルや、削除済みデータに由来するファイルを含む場合がある | 保存領域が残っていれば出力できる。物理削除済みのファイルは含まれない |

## 手順

### 対象フロアとルームを探す

1. 必要に応じてフロア一覧の検索欄へフロア名または説明の一部を入力し、「検索」を押す
2. 対象フロアの「ルーム一覧」を押す
3. 必要に応じてルーム一覧の検索欄へルーム名または説明の一部を入力し、「検索」を押す
4. 対象ルームの名前とメンバー限定状態を確認する

検索語を空にして検索すると、検索条件を解除できます。別のフロアを選ぶ場合は「フロア一覧へ戻る」を押してください。

### タイムラインJSONをダウンロードする

1. 対象ルームの「JSON」を押す
2. ダイアログの概算サイズを確認し、「ダウンロード」を押す。中止する場合は「キャンセル」を押す
3. ダウンロード完了まで待つ
4. `フロア名_ルーム名_timeline.json` が保存されたことを確認する

### メディアZIPをダウンロードする

1. 対象ルームの「メディアZIP」を押す
2. ダイアログの概算サイズを確認し、「ダウンロード」を押す。中止する場合は「キャンセル」を押す
3. ダウンロード完了まで待つ
4. `フロア名_ルーム名_media.zip` が保存されたことを確認する

概算が100 MiB以上の場合、メモリ不足や画面停止の可能性を警告します。処理には表示サイズ以上のメモリが必要な場合があり、小さい出力でも安全を保証するものではありません。データの更新により実際のサイズは変わることがあります。

ファイル名に使用できない記号は `_` へ置き換えられます。

## 操作後の状態

- 選択したフロアに所属するルームだけが一覧に表示される
- 対象ルームのタイムラインJSONまたはメディアZIPが、フロア名とルーム名を含むファイル名で保存される
- 一度に開始できるダウンロードは1件に制限される

## 困ったとき

- 検索できない
  - フロア検索は2〜10文字、ルーム検索は2〜100文字で入力してください。
- 「ルーム一覧」を押せない
  - フロア一覧の取得中です。完了後に再度操作してください。
- 「JSON」または「メディアZIP」を押せない
  - ルーム一覧の取得中、フロア情報の取得前、サイズ確認・確認ダイアログの表示中、または別のダウンロード中です。
- JSONが空だった
  - 対象ルームに論理削除されていない投稿がない場合は、空の配列が出力されます。
- メディアZIPの取得に失敗する
  - 対象ルームのメディア保存領域がないか、ZIPの生成に失敗した可能性があります。画面を再読み込みして再度確認してください。
- ダウンロードが始まらない
  - ブラウザのダウンロード許可、ポップアップ制限、拡張機能を確認してください。
- 完了まで時間がかかる
  - タイムラインJSONは対象データを全件取得し、メディアZIPは対象領域をまとめて出力します。操作を繰り返さず完了を待ってください。

## 注意事項

- タイムラインJSONには期間や件数の指定がありません。長期間利用しているルームでは、生成やブラウザの保存に時間がかかる場合があります。
- メディアZIPとタイムラインJSONでは収録対象が異なるため、ファイルの件数が一致しない場合があります。
- 出力には投稿内容、ユーザ情報、メディアなどが含まれます。必要な範囲で取り扱い、不用意に共有しないでください。
