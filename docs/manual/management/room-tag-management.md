# ルームタグ管理

## 目的

- ルームタグを状態別に一覧・検索する
- 既存のルームタグを編集し、論理削除・復元を別操作で行う

## 前提

- 管理者でログインしている

## 画面を開く

1. 画面左上の「メニュー」を開く
2. 「ルームタグ管理」を選ぶ

## 画面構成

- 検索条件: タグ名、2〜10文字
- 状態: すべて、未削除、削除済み（初期表示はすべて）
- 一覧: 表示順番、タグ名、所属フロア名、所属ルーム名、作成日、更新日、削除日、状態表示
- 操作: 有効な行は削除・編集、削除済み行は復元を表示

## 手順

### ルームタグを検索する

1. 検索欄へタグ名の一部を入力する
2. 「検索」を押す
3. 一覧に表示された対象を確認する

検索語を空にして検索すると、検索条件を解除できます。

### ルームタグを編集する

1. 有効な対象の「編集」を押す
2. ダイアログの対象フロア、対象ルーム、対象タグが目的の行と一致することを確認する
3. 表示順番またはタグ名を変更する
4. 「保存」を押す

変更後に「キャンセル」、Escキー、ダイアログ外を押した場合は破棄確認が表示されます。「キャンセル」で編集へ戻り、「破棄」で保存せず閉じます。

編集できる項目は次のとおりです。

- 表示順番: 1〜100の整数。未入力の場合は100
- タグ名: 必須、50文字以内

### ルームタグを論理削除・復元する

1. 削除する場合は有効な対象の「削除」を押す
2. 復元する場合は状態を「削除済み」または「すべて」にし、対象の「復元」を押す
3. 確認ダイアログのタグ名と所属フロア／ルームを確認し、「削除する」または「復元する」を押す

## 操作後の状態

- 検索条件に一致するルームタグが一覧表示される
- 編集内容が一覧へ反映される
- 論理削除すると削除日が表示され、復元すると削除日が解除される

## 困ったとき

- ルームタグを検索できない
  - 検索語が2文字未満または10文字を超えていないか確認してください。
- 表示順番を保存できない
  - 1〜100の整数を入力してください。未入力で保存した場合は100になります。
- ルームタグを削除できない
  - 投稿・返信・通知で使用中でも論理削除でき、参照は残ります。有効なルームAI解析設定で使用中のルームタグは削除できません。画面の案内に従い、関連するAI解析設定を削除してから、もう一度操作してください。
- ルームタグを復元できない
  - 所属フロアとルームを先に復元してください。ルームの所属フロアが一致しない場合も復元できません。一覧でこれらの削除や所属不一致を確認できる行は復元ボタンが無効になり、取得後に状態が変わった場合も復元が拒否されます。コピー元のフロアタグは削除済みまたは存在しない状態でも復元できます。
- 新しいルームタグを作成するボタンがない
  - 現在の管理画面には作成操作がありません。対象ルームの通常画面から作成してください。

## 注意事項

- 管理画面のルームタグと、通常画面で対象ルームを選んで管理するルームタグは同じ対象です。
