# ルーム管理（ルーム一覧）

## 目的

- ルームを状態別に一覧・検索する
- ルーム情報、公開・入室条件を編集し、論理削除・復元を別操作で行う

## 前提

- 管理者でログインしている

## 画面を開く

1. 画面左上の「メニュー」を開く
2. 「ルーム管理」を選ぶ

## 画面構成

- 検索条件: タイトルまたは説明の部分一致、2〜100文字
- 状態: すべて、未削除、削除済み（初期表示はすべて）
- 一覧: ルーム名、フロア名、作成者のユーザ名、作成日、更新日、削除日、有効／削除済み、表示／非表示、公開／メンバー限定の状態表示
- 操作: 有効な行は削除・編集、削除済み行は復元を表示

## 手順

### ルームを検索する

1. 検索欄へタイトルまたは説明の一部を入力する
2. 「検索」を押す
3. 一覧に表示された対象を確認する

検索語を空にして検索すると、検索条件を解除できます。

### ルーム情報を編集する

1. 有効な対象ルームの「編集」を押す
2. 必要な項目を変更する
3. 「保存」を押す
4. 一覧へ更新結果が反映されたことを確認する

編集できる主な項目は次のとおりです。

- タイトル（必須、100文字まで）
- 説明（200文字まで）
- ルーム画像
- ゲストはリアクションのみ
- 招待メンバーのみ
- タイムライン最上部に通知する
- 外部SNS連携ボタンを表示する
- 非表示にする

画像を選ぶとプレビューが表示されます。「添付を取り消す」は画像なしへ、「差し替えを取り消す」は保存済み画像へ戻します。保存済み画像を次回保存時に削除する場合は、「画像を削除」を押してください。

「非表示にする」「招待メンバーのみ」「ゲストはリアクションのみ」は、それぞれ一覧表示、入室、ゲスト操作へ異なる影響があります。

### ルームを論理削除・復元する

1. 削除する場合は「未削除」または「すべて」から対象の「削除」を押す
2. 復元する場合は「削除済み」または「すべて」から対象の「復元」を押す
3. 確認ダイアログのルーム名を確認し、「削除する」または「復元する」を押す

ルームを論理削除すると通常画面から利用できなくなります。ルームのAI解析設定が有効でも削除でき、設定自体は削除されません。ルームを復元すると、有効な設定を再び利用できます。所属フロアが論理削除中の場合は利用できません。
所属フロアが削除済みの場合、復元ボタンは使用できません。先にフロアを復元してください。

## 操作後の状態

メンバー限定へ変更すると、ゲストと入室権限のない利用者はルーム一覧へ戻ります。削除では対象ルームの全利用者がルーム一覧へ戻り、ログイン状態は維持されます。

- 検索条件に一致するルームが一覧表示される
- ルーム情報、表示状態、入室条件の変更が反映される
- 論理削除すると削除日が表示され、復元すると削除日が解除される

## 困ったとき

- 検索できない
  - 検索語が2文字未満または100文字を超えていないか確認してください。
- ルームが一覧に表示されるのに入室できない
  - 「招待メンバーのみ」と対象ユーザの立場を確認してください。
- 復元してもルームを利用できない
  - 所属フロアの論理削除状態と、ルームの非表示・入室条件を確認してください。
- 画像を更新できない
  - 選択した画像の形式とサイズを確認してください。

## 注意事項

- この画面からルームを新規作成することはできません。
- 「非表示にする」と「論理削除」は異なる操作です。
- 表示状態と入室条件の組み合わせは[ルームの表示・入室・ゲスト操作](../features/room-access-settings.md)を参照してください。
