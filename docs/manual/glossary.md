# 用語集

マニュアル内で使用する用語を、利用者向けに説明します。

## 画面とデータ

- **フロア（Floor）**: ルームをまとめる単位。フロア一覧から選択して配下のルーム一覧へ移動する。
- **ルーム（Room）**: タイムラインを利用する単位。ルームごとに入室条件やゲスト制限などの設定がある。
- **タイムライン（TimeLine）**: ルーム内の投稿を時系列で閲覧する画面。
- **投稿（Post）**: タイムラインに追加する書き込み。コメントと、必要に応じてメディアを含む。
- **返信（Reply）**: 既存の投稿に紐づく書き込み。
- **付加情報（Supplement）**: 投稿や返信に紐づく追加情報。
- **タグ（Tag）**: 投稿に付けるラベル。通知対象や絞り込み条件として利用する。

データ同士の技術的な関係は[ドメインモデル](../spec/domain-model.md)を参照してください。

## ユーザ種別

- **ゲストユーザ**: ログインしていない利用者。一覧表示とルーム設定に応じて閲覧、テキスト投稿、リアクションなどを利用できる。
- **一般ユーザ**: ログイン済みで、対象フロアやルームに追加の立場を持っていない利用者。
- **フロア編集ユーザ（Editor）**: フロアを作成できるユーザロール。自分が作成したフロアでは、配下のルームやメンバーも管理できる。管理画面の権限欄では「フロア編集者」と表示する。
- **管理者（Administrator）**: システム全体の管理機能と管理画面を利用できるユーザロール。

## 対象ごとに決まる立場

- **対象フロアの作成者（FloorEditor）**: フロア編集ユーザが自分で作成したフロア内で得る立場。ルーム、タグ、単語、メンバーを管理できる。
- **フロアメンバー（FloorMember）**: フロア招待への参加によって得る立場。対象フロア配下のルーム管理や、メンバー限定ルームへの入室ができる。
- **ルームメンバー（RoomMember）**: ルーム招待への参加によって得る立場。対象のメンバー限定ルームへ入室できる。

Editorはシステム全体のユーザロール、FloorEditorは対象フロア内での立場を表すシステム上の名前です。FloorEditorに該当するには、現在のロールがEditorであり、対象フロアの作成者本人である必要があります。

## 管理画面の操作

- **管理画面**: 管理者だけが利用できる、システム全体のデータやユーザを管理する画面。
- **共通タグ（カテゴリタグ）**: 管理画面でシステム全体を対象に管理し、各フロアのフロアタグを「共通タグに戻す」ときの置換元として利用するタグ。
- **論理削除**: 通常の利用対象から外す一方でデータ自体は残し、管理画面から復元できる削除方式。
- **物理削除**: データそのものを削除し、管理画面から復元できない削除方式。
- **メンバー関係の削除**: ユーザ、フロア、ルーム自体は削除せず、フロアメンバーまたはルームメンバーの関係だけを削除する操作。管理画面からの復元操作はない。

## ルームの公開・利用条件

- **公開ルーム**: 入室をメンバーに限定していないルーム。ゲストの投稿可否は「ゲストはリアクションのみ」で別に設定する。

- **非表示**: ルームを一覧表示する利用者を制限する状態。入室制限ではない。
- **メンバー限定**: 所定の立場を持つログインユーザだけが入室できるルーム設定。
- **ゲストはリアクションのみ**: ゲストユーザが投稿・返信を行えず、「流す」とリアクションだけを利用できるルーム設定。
- **キック済み**: ログインユーザが対象フロアのルームへ入室できない状態。
- **外部SNS連携ボタン**: ルーム設定によって表示される外部SNS連携用のボタン。

表示状態と利用条件の組み合わせは[ルームの表示・入室・ゲスト操作を設定する](features/room-access-settings.md)を参照してください。

## タイムラインの操作

- **流す**: 「流す」投稿としてタイムラインへ送信する形式。設定に応じてアニメーション表示される。
- **絞り込み（Filter）**: キーワード、ユーザ名、タグ、タグなし、流すなどの条件で表示する投稿を絞る機能。
- **OR検索**: 複数条件のいずれかに一致する投稿を対象とする検索方法。
- **AND検索**: 複数条件のすべてに一致する投稿を対象とする検索方法。
- **表示する・表示しない**: 絞り込み条件に一致した投稿を表示するか、隠すかを選ぶ設定。
- **関連する投稿を表示**: 条件に一致した投稿に加えて、親子関係にある投稿や返信も表示する設定。
- **読み上げ**: タイムラインの内容を読み上げる機能。
- **単語（クイックテキスト）**: 入力に利用する定型文。
- **共通の単語**: 管理画面でシステム全体を対象に管理する単語。フロア作成時のコピー元になる。
- **フロア単語**: フロアに紐づく単語。
- **ルーム単語**: ルームに紐づく単語。

## 表示・通知

- **Webプッシュ通知**: ブラウザへ通知を表示する機能。プロフィールや絞り込み条件から設定する。
- **目にやさしいモード**: タイムラインの文字を大きくし、アニメーションを停止する設定。
- **ARモード**: URLの指定によって切り替えるタイムライン表示モード。
- **ローカル設定**: ブラウザ内に保存される端末ごとの設定。アカウントには保存されない。
