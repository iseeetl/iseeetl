# はじめて使う・画面の移動

このページでは、初めて利用する人向けに、タイムラインを開くまでの流れと利用条件を説明します。

## 画面の移動

1. フロア一覧で利用するフロアを選ぶ
2. ルーム一覧で利用するルームを選ぶ
3. タイムラインを閲覧し、利用できる操作を確認する

画面内の戻るボタンは、次の一覧や画面へ移動します。

| 現在の画面 | 戻り先 |
| --- | --- |
| タイムライン | 対象フロアのルーム一覧 |
| ルーム一覧 | フロア一覧 |
| 設定、ヘルプ、チュートリアル、規約類、お問い合わせ | フロア一覧 |

ブラウザの戻る・進むは、閲覧した順に移動します。ログイン・登録画面の規約類は別タブで開くため、入力中の操作は元のタブで続けてください。

## 最初に自分の立場を確認する

### ログインしていない場合

ゲストユーザとして、表示されているフロア・ルームと、入室制限のないタイムラインを利用できます。

詳しくは[ゲストユーザ](roles/guest.md)を参照してください。

### ログインしている場合

一般ユーザとしてログインが必要な機能を利用できます。フロア編集ユーザ、管理者、フロアメンバー、ルームメンバーなどの立場がある場合は、利用できる管理機能や入室範囲が増えます。

詳しくは[ロールと利用できる機能](roles/README.md)を参照してください。

## ルームの表示を確認する

ルームカードに表示される状態によって、一覧表示や入室後の操作が変わります。

| 表示・設定 | 意味 |
| --- | --- |
| 非表示中 | 一覧へ表示する利用者を制限している。入室制限とは別の設定 |
| メンバー限定 | 所定の立場を持つログインユーザだけが入室できる |
| ゲストはリアクションのみ | ゲストユーザは投稿・返信ができず、「流す」とリアクションだけを利用できる |

3つの設定は、それぞれ一覧表示、入室、ゲスト操作の異なる範囲に影響します。組み合わせと詳しい利用条件は[ルームの表示・入室・ゲスト操作](features/room-access-settings.md)を参照してください。

## タイムラインでできる主な操作

- 投稿と返信を読む
- 条件を指定して投稿を絞り込む
- 投稿、返信、「流す」、リアクションを行う
- ログインしている場合はメディア機能を利用する
- 表示項目、読み上げ、アニメーションなどを設定する

利用できる操作は、[タイムライン](features/timeline.md)と[投稿・流す・リアクション](features/timeline-post.md)を参照してください。

## ボタンが表示されない場合

次の順に確認してください。

1. ログインが必要な操作ではないか
2. 対象フロアの作成者またはフロアメンバーである必要がないか
3. 対象ルームのルームメンバーである必要がないか
4. ルームがメンバー限定、非表示、ゲストはリアクションのみになっていないか
5. 対象フロアでキック済みになっていないか

詳しくは[ロールと利用できる機能](roles/README.md)と[よくある質問・困ったとき](troubleshooting.md)を参照してください。
