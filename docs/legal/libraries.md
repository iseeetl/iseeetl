# ライブラリのライセンス

依存ライブラリには各公開元のライセンスが適用されます。本プロジェクトのApache License 2.0やCC BY 4.0で一括して扱うものではありません。画像・音声・ロゴ等は[アセットの利用条件と第三者表示](assets.md)を参照してください。

## 確認する場所

| 対象 | 確認先 |
| --- | --- |
| 直接の依存 | [フロントエンド](../../frontend/package.json)と[バックエンド](../../backend/package.json)の`dependencies`・`devDependencies` |
| 間接依存を含むバージョン | 各ディレクトリの`package-lock.json` |
| ライセンス本文・著作権表示 | 導入したパッケージの`LICENSE`・`COPYING`・`NOTICE`等と、公開元の該当バージョン |
| ブラウザへ配信するライブラリ | ビルド成果物の`licenses.json`と、生成コード内の権利表示 |

`package.json`やlockファイルのライセンス名だけでは、原文に含まれる条件や権利表示をすべて確認できません。

## フロントエンドのビルド

[ビルドコマンド](../spec/frontend/build-and-config.md#ビルド)を実行すると、Viteがバンドルした依存ライブラリの情報から、`dist/licenses.json`を自動生成します。別の生成コマンドは不要です。

- 名前、バージョン、ライセンス名、ライセンス本文を収録する。
- パッケージに複数のライセンス本文や`NOTICE`があれば、その原文も収録する。
- ライセンスを示すコードコメントは、圧縮後も残す。
- 必要な情報を確認できない場合は、ビルドを失敗させる。

パッケージに本文がないものは、[補完資料](../../LICENSES/third-party/frontend.json)で該当バージョンの原文と公開元を対応付けています。依存を更新する際は、本文の同梱状況と補完資料の対応バージョンも確認してください。ビルド時に外部サイトから原文を取得することはありません。

`licenses.json`は生成コードと一緒に配置・配布します。この一覧には、バンドルされない開発・テスト用依存、バックエンドの依存、外部URLから読み込むSDK・フォントを含みません。自動検査は情報の欠落を検出するもので、個々の再配布条件の確認を代替するものではありません。

## バックエンドと再配布

[配布アーカイブ](../spec/release-artifact.md)にはバックエンドの`node_modules`を含めません。依存は配置先で導入し、各パッケージのライセンス本文と権利表示を保持します。

`node_modules`や実行環境を含むコンテナ等を再配布する場合は、間接依存とネイティブライブラリも含めて条件を確認します。特に、画像処理のsharpが使用するlibvips等や、別途導入するFFmpegは、構成に応じた条件の確認が必要です。

- [sharpのライセンスと依存ライブラリ](https://sharp.pixelplumbing.com/#licensing)
- [FFmpegのライセンス](https://ffmpeg.org/legal.html)

依存の追加・更新や第三者コードの取り込みでは、ライセンス本文、著作権表示、必要な`NOTICE`やソース提供条件を確認し、配布する内容へ反映してください。
