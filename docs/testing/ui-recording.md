# UIの記録方法

## 比較に使うデータ

公開用の画面は、公開可能な素材と合成投稿を使います。名前だけ置き換えた実投稿を合成データとは呼びません。本文・画像・音・動画・アイコン・URL・ルーム名・日時・アカウント情報に加え、タブやプロフィール名、OS通知、権限ダイアログ、EXIF等のメタデータも確認します。人物の顔・声は合成素材、または公開許諾を確認したものに限ります。原本は非公開の保存先で保持し、公開リポジトリ・Issue・PRには置きません。公開するのは確認済みの派生ファイルのみとし、位置情報・撮影者名・端末情報などの非公開メタデータを除去した後、残存がないことを確認します。公開済み論文の図も、そのまま再配布可能とはみなさず権利条件を確認します。

## 同じ条件で保存する

1. 比較する公開commit、合成fixture、言語、権限、AI/表示設定を指定する。
2. PCとスマホでブラウザ名/版、OS版、画面幅、OS文字サイズ・ブラウザズーム・配色を記録する。PCはタイムライン列の幅も記録する。
3. 原則として同じ投稿・同じ操作段階で撮影する。上限拡張など仕様変更のため追加した試験データは、追加理由と対応版を記録し、共通条件の比較と区別する。
4. 表示だけでなく、選択、保存、取消、再読込、キー操作とフォーカスを確認する。
5. 画像ごとに版・シナリオ・取得条件・公開許諾/素材の由来を記録する。

アクセシビリティツリーに名前があること、キーボードで操作できること、VoiceOverの実発話を確認したことは別の確認項目です。実際に確認した範囲だけを記載します。

## 最小シナリオ

対象commitに存在しない機能は「該当なし」と記録し、不具合や検証漏れと区別します。

| シナリオ | 保存する場面 |
|---|---|
| 投稿入力 | PCとスマホ、上部/下部操作、送信可能/不可能状態 |
| メディア | ライブラリ・カメラ・ファイル・録音の入口と選択後 |
| 代替テキスト | 閲覧、編集開始、保存/取消、権限に応じた表示 |
| 付加情報 | 長文の折りたたみ/展開、AIのタグ別表示設定 |
| 返信 | 新しい返信と親投稿の接続、説明の位置 |
| 絵文字 | 狭い列・広い列、末尾候補への到達、開いたままの列幅変更 |
| 支援技術・キー操作 | 読み上げ名称/選択状態、フォーカス順、VoiceOver実発話の確認有無 |

保存回答はライブAI出力と区別します。同じ条件の画面比較でも、利用者の評価結果や改善効果とは別の資料です。
