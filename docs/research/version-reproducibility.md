# バージョンと再現条件の記録

同じ機能名でも、ソース、設定、外部AIサービスによって動作は変わります。研究や利用評価では、使用した版を明示します。

## 公開する最小項目

| 項目 | 内容 |
|---|---|
| ソース | 40桁の公開commit ID、対応するPR・リリースタグ（存在する場合） |
| ビルド | 公開配布物とビルドマニフェストの識別情報・SHA-256 |
| 依存 | lockfile、Node・DB・メディア処理ツールの版、DBスキーマ/マイグレーション版、公開可能な合成初期データ、基盤OS・使用する場合はコンテナイメージdigest、タイムゾーン・ロケール |
| 設定 | 公開可能な非秘密設定、利用機能、AIモデルID（alias/固定版の別）・API/SDK版・生成パラメータ・入力変換・出力上限・プロンプト版・取得日 |
| 素材 | 公開可能な合成fixture・メディアと、その識別情報・SHA |
| 画面 | 言語、ブラウザ/OSの版、画面幅、タイムライン列幅、文字サイズ・ズーム・配色、権限、閲覧設定 |
| 検証 | 実施した操作、期待結果、確認結果、未確認事項 |

実際に使用した項目を記録し、使用しない項目は「該当なし」、特定できない項目は「不明」とします。モデルの固定版が提供されない場合も明記します。

研究で用いた実環境との対応記録と、公開可能な製品情報は区別します。原データ・実ユーザーの識別子・資格情報・実環境のGA測定IDは公開記録に含めません。GAのイベント定義や集計方法と、実際の収集データを区別します。設定が変わった場合、ソースcommitが同じでも設定版を更新します。

## 過去版の確認

既存作業や稼働環境を上書きせず、空の検証環境へ対象commitを展開します。対応する依存定義で構築し、合成データで確認します。過去版を本番へ戻す場合は、後続のデータ変更との互換性と退避の復元を別に検証します。

ソースの復元、ビルドの再作成、実行環境の再現、研究結果の再計算は別の検証です。ソースを復元できるだけで、過去の環境全体が完全再現できたとは扱いません。外部AIの出力は同じモデルIDでも変わり得るため、入力条件・取得時期・評価方法を明記します。

配布物の識別情報と収録範囲は、[リリース成果物仕様](../spec/release-artifact.md)に従います。実際のホスト・配置先・接続方法・秘密値は含めません。
