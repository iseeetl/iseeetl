# ISeeeTimeLine

ISeee TimeLineは、スポーツイベントに参加してリアルで観戦している人たちが、互いにタイムライン（TL）上で情報交換、情報保障を行なうためのウェブアプリケーションです。リアルタイム性の高いスポーツで利用できるように、従来のSNSにはない投稿したらすぐに利用者に共有される応答性を備えています。また、文や画像だけでなく、日本語以外の言語、音声やビデオなどの様々な方法で投稿できるようにし、さらに投稿された内容を相互に変換する機能も実装していきます。これによって、障害者や高齢者、外国人でもリアルスポーツイベントの情報が保障される環境を構築していきます。

最初はスポーツ観戦への応用から始まりましたが、ISeee TimeLineは博物館の観覧やカフェでのイベントなど、さまざまな場面にも応用することができます。

タイムライン本文のリンクは、暗い背景で読める水色と下線を使い、スマートフォンでは長いURLを折り返します。表示仕様は[UI規約](docs/spec/frontend/style-and-i18n.md#タイムライン本文のリンク)を参照してください。

スマートフォン幅の「流す」「投稿」ボタンは、ブラウザのバー開閉に追随するアプリ領域の下部へまとめて配置します。画面高とスクロールは[フロントエンド概要](docs/spec/frontend/overview.md#画面の高さとスクロール)、ボタンの位置は[タイムラインの通常表示](docs/spec/frontend/screens/Timeline.md#通常表示)を参照してください。

AI対応タグには色と「AI」の目印を表示し、タイムライン設定からルーム別・タグ別にAI付加情報の表示を選べます。人の付加情報とは分けて扱います。設定を開くたびに最新のAI対象タグを取得し、改名後もタグIDで選択を保持します。[表示と保存の仕様](docs/spec/frontend/screens/Timeline.md#ai対応タグと付加情報の閲覧)を参照してください。

## 必要な環境

Node.js、npm、MongoDB、FFmpeg／ffprobeを使用します。バージョンは[運用事例の稼働環境](docs/deployment/production.md#稼働環境)を参考にし、Node.js・npmの対応範囲は各`package.json`の`engines`で確認してください。メール送信などの外部機能は、利用する場合に接続先と設定を用意します。

## タブの初期表示と投稿タグ

共有URLの `initialTab` と `colN_postTagMode` で、最初のタブと投稿開始時のタグを別々に指定できます。[共有URLの手順](docs/manual/features/timeline-query-parameters.md#最初に開くタブと投稿開始時のタグ)と[タグ選択・連続投稿・投稿確認の仕様](docs/spec/frontend/tag-selection.md)を参照してください。

投稿編集・返信でも、タグ操作ボタンの選択元を色とテキストで示します。個別のタグ変更で強調を解除します。編集前のタグと返信先のタグの区別は[タグ選択仕様](docs/spec/frontend/tag-selection.md)を参照してください。

投稿編集・返信も同じ5個のタグ操作ボタンを表示します。「このタブ」は操作した列のタグ条件を明示的に適用し、列を特定できない場合は無効になります。初期値の規則は[タグ選択仕様](docs/spec/frontend/tag-selection.md)を参照してください。

文字起こしで発話が検出されない場合は、日英の案内を表示します。空結果と外部サービス障害の区別は[AI解析仕様](docs/spec/ai-analysis.md#発話が検出されない場合)を参照してください。

音解析は、波形で確認した無音・一定音・短い電子音の繰り返し・極めて低い録音レベルを外部モデルに推測させず、環境変数でOpenAIとGemini（Google）を切り替えられます。Gemini経路では同じ音声を2回解析して分類が一致しない場合に確度が低い旨を添え、説明を生成できない場合は日英の案内を表示します。手順と環境変数は[AI解析仕様](docs/spec/ai-analysis.md#音解析の流れ)と[バックエンド環境変数](docs/spec/backend/environment-variables.md#gemini音解析)を参照してください。

投稿・返信は400文字、付加情報は人・全AI種別とも2000文字までとし、長文は折りたたみます。会話AIはタグ接頭辞込みの保存上限に揃え、長すぎる回答だけ1回短縮します。生成できない場合は日英の案内を表示します。[会話の長さ制限と失敗表示](docs/spec/ai-analysis.md#会話の長さ制限と失敗表示)を参照してください。
